# V3.1.13 更新说明

V3.1.13 / versionCode 20261220；arm64-v8a。本地交付，尚未上传 GitHub。

## 当前主题全局字体

设置 → 外观 → 主题键盘字体与字号，顶部增加“当前主题全局字体”。

- 优先级：单项字体设置 → 当前主题全局字体 → 主题原始字体。全局只提供默认值，不清空单项配置；字号仍按单项设置。
- 每个 YAML 主题单独保存全局字体，可使用有序多字体链。主题切换与后台预加载使用该主题的实际 ID，避免读取上一主题的默认字体。
- 整体备份包含设置和导入字体文件；资源目录迁移同步改写全局字体路径。从主题导入自定义键盘时可带入当前有效字体。
- 自定义布局的独立字体设置继续保留。

## 五色键盘与七列布局

薄荷绿、樱花粉、浅天蓝、杏子橙、薰衣紫保持原有颜色和布局，加入浅层渐变、细底边及短促按压缩放/下沉。默认不增加动态模糊或持续动画。

七列一、七列二的 Shift、删除、数字页入口使用同色功能键底色，回车使用强调色，补齐图标和 Shift 锁定态颜色。

内置模板升级至 V9：匹配旧模板的默认按键和特效自动更新；用户编辑过的按键、绑定与特效保留。希望完整使用新外观，可先导出备份，再到布局管理 → 恢复内置键盘 → 重置内置键盘的布局与外观。

## 三套特效键盘

| 键盘 | 质感 | 配套 |
| --- | --- | --- |
| 月白·瓷光 | 浅色瓷面、柔和高光、细阴影与轻微下沉 | 数字、英文、9/14/18 键、七列等次级布局 |
| 曜石·微光 | 石墨深底、冷色渐变描边、微光与按压波纹 | 完整次级布局及深色悬浮候选窗 |
| 暮金·缎光 | 暖灰棕底、香槟渐变描边、内阴影与缎面高光 | 完整次级布局及暖色悬浮候选窗 |

每套 15 个主/次级布局，新增 45 个，全部内置共 120 个布局。新套装在后台一次性补入；未出现时可重新进入布局管理。整体菜单、字体、外观仍可自行修改。前景图标新增“图标颜色”，留空时保留图片原色。

特效以现有缓存绘制与短促交互为主；本轮没有测量功耗或输入延迟，不能据此承诺性能不变。

## 编辑器拖动

- 长按后显示放大的描边拖影，原位置淡出。
- 指向目标处时，相邻按键平滑让位，显示插入竖线和“第几行 · 第几位”，位置变化有轻触觉反馈。
- 直接拖至目标位置松手插入，可跨行、移到行尾；靠近边缘可持续滚动。
- 落位后滚动到目标按键并显示入位动效。取消拖动恢复显示，松手前不修改布局；若拖动期间布局已经变化则取消本次移动。
