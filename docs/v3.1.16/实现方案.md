# V3.1.16 实现方案

- 键盘样式入口按主题、自定义、内置三类过滤。主题保留原加载器；后两类共用现有独立布局加载器，内置归属从随包 YAML 的 ID 自动识别，不按用户皮肤的 `custom_` 前缀猜测。
- 分类切换只切换列表；点具体按钮才应用布局。分类记忆纳入键盘库；皮肤按钮统一打开同一动态选择器，自定义/内置两列显示，未来新增根布局自动出现。
- 加载目标布局时传入明确 ID，在后台准备完成后，才在主线程提交模式、活动布局与主题；异常恢复原模式和布局，避免预先修改活动 ID。
- 九键底行改为 16/12/45/12/15，最右列对齐；只迁移旧标准宽度组合，保留用户自定义几何。
- 内置工具栏图标使用统一矢量源、透明底及克制线条，使用新文件名安装。迁移应用自带旧图标引用后清理旧自带图标，不删除用户其它素材。
- 用户造词仅变更显示标注为小号“造”，不修改已保存的词与编码。
- 外部 `trime-kb` 同步修复生成器及两份 YAML，返回使用 `.default`，中英使用 `Mode_switch`，增加制作规范。
- 主题工具栏限制字体/图片外观读取范围，明确字体置于通用回退字体之前；图标大小与文字字号分开处理。

工作区开始时已有符号输入、绑定复制及测试文件修改，已单独保存差异，继续保留。后续用户要求真机回归，已补充 debug 专用回归入口；检查范围和结果见检查记录。

## 本轮真机发现与追加

- 修复皮肤 `FUNCTION/theme` 命令误走外部 Intent 导致崩溃，外部动作增加找不到应用/无权限保护。
- 图标安装标记升至 `.builtin_v3`，重绘更宽的衣服和带移动箭头的悬浮键盘。
- 启动时单独重试未完成的内置扩展升级，避免主模板版本已更新后剩余模板永远漏载；任一资源解析失败不标记整批完成。
- 输入统计分享提供“仅分享热力图”，直接复用当前热力网格进行 PNG 渲染，保留当前方案、周期和热度显示模式，不纳入其它统计内容。
