# V3.1.16 更新说明

## 键盘样式三分类

功能菜单和工具栏皮肤按钮共用键盘样式弹窗，顶部提供主题布局、自定义布局、内置布局三类。切换分类只浏览列表，点击具体按钮才应用布局。内置和自定义采用两列按钮，内置归属读取应用资源，新增主布局无需手工维护选择列表；导入/创建的主布局自动出现在自定义分类。删除过的内置布局仍可通过已有恢复功能补回。

继续使用主题和独立布局两套加载机制；内置只是独立布局的一种来源，不引入第三套运行模式。目标布局在后台准备好后才一次性提交活动布局和加载模式，失败回到原键盘。第一次打开列表会等待后台补齐内置页面，避免只显示五色而漏掉四套特效键盘。

## 九键及内置工具栏

九键“确定”改为与右侧同列其它键相同的 15% 宽度，底行调整为 16/12/45/12/15。升级只匹配旧标准宽度组合，保留其它自定义尺寸和绑定。

新工具栏图标使用统一矢量网格、圆头笔画和透明底，参考提供的简洁单色风格。安装新图标后迁移应用自带旧图标引用、清理旧内置文件；旧导出里的路径保留别名兼容。用户自行命名的其它素材不删除。符合原皮肤按钮命名的自定义工具栏也升级为动态选择器，不再固定显示旧颜色页。

## 造词标注

用户造词的候选注释由“用户造词”改为小号“造”。紧凑候选栏放在词后，悬浮候选窗也按较小字号显示；不修改保存的词、编码或词序。

## 外部皮肤与主题兼容

`trime-kb` 的六风格、清新四色生成器和 YAML 同步修复：返回用 `Keyboard_default`，中英切换用 `Mode_switch`，工具栏皮肤按钮打开动态选择器，九键最右列对齐。原目录已留下制作规范；交付包提供修复后的文件，重新导入时选择合并覆盖同 ID 页面。

主题工具栏未指定图片大小时恢复按原始尺寸居中显示，避免被放大铺满按钮。主动设置的图片大小及自定义键盘图片调节继续有效。矢量图标尺寸不随主题的文字字号设置一起变大；主题指定字体在通用字体回退之前加载。没有反馈用户的实际主题/字体文件，未做该第三方主题的逐像素复现。

## 整套复制按键绑定

复制来源只列主键盘，一次匹配整套中的主页面和所有次级页面。通过同一子页 ID 后缀或唯一页面名称匹配，不按页面序号硬套；预览显示匹配页/键数及未匹配数量。不匹配的页面或按键保留，不自动新建目标页面。即使从次级键盘的编辑页进入，也作用于它归属的整套键盘。

复制保留目标布局、外观、字体与宽度。套内键盘跳转映射到目标套内对应页面，弹出备选里的跳转也同步处理；宏动作使用独立命名，避免改掉来源键盘或其它键盘的功能。全部页面先校验再一次性保存，操作期间键盘变化则拒绝旧计划。此功能复制整套的按键绑定，不覆盖工具栏的按钮列表。

## 自定义编码区 emoji 与字体补缺

自定义编码区按完整 Unicode 组合处理 emoji、变体选择符、肤色和连接序列，为标准 emoji 使用系统显示字体；普通文字继续使用用户选择的字体。缺字时才查询辅助字体与 `rime/fonts`，按字符缓存结果，避免每次绘制重新扫描字体目录。保留实际编码文本，不通过替换字符来显示 emoji。

编码选择高亮和点击光标不拆分 UTF-16 代理对，显示时移除不必要的光标分段重拼。主题导入为自定义布局时补充保留拉丁/扩充字集辅助字体链。旧导入若原辅助字体已经被移除，仍需重新导入完整主题或补回字体；不能凭截图恢复缺失的私用字符字形。本轮未取得反馈者的具体字体，未复现其逐像素效果。

## 真机回归补充

- 修复皮肤按钮的 `FUNCTION/theme` 被误当作 Android `THEME` Intent、点击即崩溃的问题，兼容已导入的相同动作。外部动作无处理应用或无权限时提示失败，避免输入法退出。
- 皮肤图标加宽衣服轮廓；悬浮键盘改为键盘配移动箭头，提升辨识度。安装标记升至 `.builtin_v3`，已有图标会更新。
- 输入统计分享增加“仅分享热力图”，只导出当前方案/周期/热力模式的键盘热力网格 PNG，不包含统计报告、标题或其它卡片；图片选项不再提供误导性的复制文字操作。
- 修复紧凑候选自绘控件忽略文字样式的问题，确保“造”实际按小字号绘制；普通候选保留原来的快速绘制路径。
- 悬浮按钮从旧的单手图标切换到带移动箭头的悬浮图标，保留长按单手功能；热力图导出底色随设置页面深浅模式变化。

## 包含既有审查修复

- 复制绑定时，歧义判断同时比较绑定、弹出备选和绑定发送开关，避免选错同名按键。
- 升级保留用户编辑后仍存在的旧符号页入口，只对已移除的内置页面转向对应符号分类。
- 导出保留当前暂时缺失的英文/横屏目标布局引用，避免备份丢失配置。
- 输入符号时，先提交 Rime 正在组字的内容，再通过同一消息流提交符号原文，避免残留组字或提交次序混乱。

这些修改与相关测试代码均保留在本版源码中。此前审查会话的最终横屏/性能测量未完成；不将其算作本版已完成的全部性能验证。
