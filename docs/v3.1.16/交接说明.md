# V3.1.16 交接说明

基点是 V3.1.15 提交 `f8ece2d41d1d77f348d1be693f13927ed727b3e9`。本版使用 `v3.1.16` 标签标记，发布附件源码与该标签对应。开始前已有的符号输入、绑定复制及测试文件修改已保留，详见交付元数据及原有差异文件。

## 关键路径

- ThemePickerDialog：三分类、独立内置/自定义两列、异步列表与一次性应用。
- KeyboardLayoutCatalog：从生成的随包 YAML 顶层 `custom_` ID 识别内置布局，不用整个前缀分类用户皮肤。后续新增内置资源文件时将新文件纳入资源列表；现有文件中新增布局自动显示。
- ThemeManager.selectTheme(customLayoutId)：先准备目标布局，提交失败恢复原活动 ID/模式。CustomKeyboards.standaloneTheme(selectedId) 不需要提前改活动 ID。
- BuiltinToolbarAssets：版本化图标安装、旧引用升级、旧文件清理、旧导出路径兼容。CustomKeyAssets 同时支持旧相对路径和素材根目录内的旧绝对路径。
- tools/generate_builtin_icons.py：矢量源/PNG 及图标 ZIP 生成器，支持 --preview 输出设计图。
- tools/update_builtin_picker.py：更新随包样式按钮、图标路径和九键几何。重新生成其它内置模板后要再次运行。内置模板版本已升到 12。
- CandidateProto.CREATED_WORD_COMMENT / CandidateItemUi / LabeledCandidateItemUi：造词小号标注，不改保存数据。
- ToolButton：主题图片无显式大小时保持原始尺寸；图标与文字字号分开。ThemeFonts 保证声明字体优先。

- KeyboardFamilyBindingCopy：主键盘来源列表、整套页面匹配、内部目标重映射、宏别名隔离和批量保存。单页 API 仍保留供既有调用；界面使用整套 API。
- PreeditFontFallback：只对自定义编码区缺字/emoji 建立字体 span，按完整 Unicode 组合处理并缓存，不改变输入文本。ThemeKeyboardImporter 保存辅助字体，PreeditTextView 避免光标拆分代理对。
- 后续换图标时必须同步升级安装标记；更改文件名前缀时还需保留旧路径兼容，不能仅替换 ZIP 而沿用旧安装标记。

## 皮肤按钮崩溃

用户日志明确为 `ActivityNotFoundException: android.intent.action.THEME`。`CommonKeyboardActionListener.handleFunctionCommand` 已增加 `theme` 内部命令分支；外部应用启动路径捕获 ActivityNotFoundException/SecurityException。真机回归入口包含实际工具栏触摸，避免只测对话框构建而漏掉命令分发。

## 新增分享与绘制

- InputStatsActivity 分享列表增加“仅分享热力图”，调用 StatsImageShare 的同一 PNG 渲染器，但内容仅传 stats_heat_grid；复制文字按钮仅在文字选项下可用。
- AutoScaleTextView 只在文本存在 CharacterStyle 时使用缓存 StaticLayout 进行测量/绘制，普通候选继续 Canvas.drawText；更新文字样式时同步使测量缓存失效，保证 RelativeSizeSpan/ForegroundColorSpan 真正生效。
- 热力图导出画布使用页面 colorBackground，避免深色模式浅字落到白底。悬浮按钮的自带 onehand 图标引用按动作迁移为 float，长按单手动作保留。
