# V3.1.16 检查记录

## 环境与隔离

2026-11-02 在 .33 手机（PKX110，API 36）独立咩2 `com.osfans.trime.debug.v2` 执行 instrumentation 回归。正式版 `com.osfans.trime.mie` 未覆盖安装。后续按用户授权发布 `v3.1.16`，不改变本记录的测试范围。安装前备份咩2私有 files/shared_prefs、外部键盘配置及素材；测试后恢复原默认输入法、启用列表、旋转设置、配置和图片资源，并按文件内容哈希复核。

## 真机回归

- Mie3116Runner：九款内置根布局动态分类、用户布局隔离；九键确定键宽度；实际触摸皮肤图标打开内部选择器；三分类多次切换只过滤列表，内置/自定义两列。
- 通过选择器连续三轮切换主题/自定义/内置，共九次实际布局切换，无崩溃、模式串用；选中了手机已有的第二个旧主题。
- 整套绑定复制由次级页定位整套，覆盖主/次两页、乱序匹配、套内跳转重映射、默认返回及陈旧计划拒绝。
- 新图标 11 枚安装、旧自带图标删除、用户文件保留、旧相对及绝对路径兼容。
- 自定义编码区生产组件显示 💕、ZWJ、肤色、旗帜及 keycap，文本与完整代理对保持；回退字体确实具有字形。截图已查看，造词“造”为候选文字 60% 字号。
- 热力图单独导出 PNG 的尺寸与热力网格一致，不含其它统计卡片/标题；图片完整解码，并核对页面底色，避免深色文字导出到白底。当前测试数据为零频次网格，不代表已覆盖所有热度分布。
- Mie3115Runner 回归：26/9/14/18/两款七列从数字/布局/主题页面返回、英文返回及显式选择 26 键；全部九款主题选择页；未指定主题字体维持系统基线，明确指定字体可加载；主题菜单编辑独立保存。

## 发现并修复

1. 用户崩溃日志的根因是 FUNCTION/theme 误走外部 Android THEME Intent。补上内部命令，外部动作找不到处理应用或缺少权限时提示失败。
2. 内置主模板升级中断后，扩展模板未重试。启动时独立补偿，资源解析失败不提前标记完成。
3. 小号“造”的 span 在自绘控件中被忽略。为含样式的候选增加缓存 StaticLayout；普通候选保留快速绘制路径。
4. 分类标签换行及深色卡片过亮。改为紧凑分段选择和深色回退配色。
5. 深色热力图导出背景固定白色导致对比度不足。改为页面背景色。

测试脚本调试期间曾有初始化等待、滚动/窗口重排点位和断言问题，均修正后重跑；最终结果以随包两份 Mie3116Runner / Mie3115Runner 的 PASS 输出为准。
