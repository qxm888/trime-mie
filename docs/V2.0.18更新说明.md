# V2.0.18 更新说明

- 悬浮候选窗去掉“候选窗 / 收起”标题控制，保留输入编码与候选内容。
- 上一页、下一页按钮分居底部左右两端，触摸区域各为 44dp；不可用时禁用并淡化。
- 悬浮球默认关闭。开启后仅在状态栏隐藏、悬浮候选栏启用且没有候选内容时显示；恢复状态栏后立即隐藏。
- 键盘菜单中，“单手键盘模式”移动到“悬浮候选栏”之前。
- 按住空格录音时，整个状态栏显示居中话筒及两侧动态曲线，曲线振幅来自麦克风 PCM 音量。松开、取消、失败或超时后停止并恢复原状态栏显隐设置。
- 版本 V2.0.18，versionCode 20261120，正式安装包 trime-mie-v2.0.18.apk。
