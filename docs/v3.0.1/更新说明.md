# Trime Mie V3.0.1

正式包 `trime-mie-v3.0.1.apk`，`com.osfans.trime.mie`，版本码 `20261129`。

## 阴影与美化

工具栏外阴影改由整条状态栏在所有按钮下层绘制，柔化边缘可以越过单个按钮边界；背景、噪点、内阴影和波纹使用一致的圆角区域，修正旧背景内边距叠加和文字阴影偏移未按密度换算的问题。尺寸不变时继续复用特效缓存；原排列不会额外创建另一套隐藏工具栏按钮。

## 空标签透明键

修复预置动作的 states 列表只支持读取、导致绑定选择器写入动作时崩溃的问题，补齐JSON读写并保留原有YAML兼容。字体与工具栏尺寸列表一并支持双向转换。打开自定义绑定时不再强制读取主题文件；绑定名称显示也可在主题尚未加载时工作。自定义空标签按键即使有动作也保留空标签，不自动变成动作文字。占位空间与已绑定的透明触摸键继续分开处理。

## 按钮排列

- 每行编辑卡片的“排列”：靠左、居中、靠右、分散。与行高并排显示，减少纵向长度。
- 当前自定义布局的工具栏编辑：“按钮排列”，同样支持上述四项；旧布局保留“原排列”。
- 调整的是剩余空间，不会把每个按键强制拉满；仅有一个按钮时分散按居中处理。宽度合计超过100时仍按原规则等比例缩放。
- 配置随当前布局保存，预览、JSON备份及YAML导出/导入一致。修改百度原坐标布局的行排列会转换为自由行布局，并保留按键素材。

## 设置页与搜索

首页搜索改为圆角搜索框入口，仅显示“搜索”。实际搜索页也使用“搜索”提示及清除按钮。修正工具栏 include 缺少完整尺寸导致布局约束不生效的问题；列表首项与工具栏之间增加留白，已有安全区域处理同时包含屏幕切口。顶部测试输入按钮继续保留。

## 语音入口与腾讯接口

“便捷功能 → 语音输入”直接打开识别服务与模型；不再提供首选系统语音输入法选项。选择服务商后自动关闭选择列表。密钥使用真正的密码输入框编辑，修复把“已设置”圆点占位文字误保存为密钥的问题。

腾讯云支持标准流式、大模型1.0流式、大模型2.0流式、大模型极速文件和标准极速文件五类引擎。填写自己的 AppID、SecretID、SecretKey，选择已开通的服务。流式支持普通 result 分片及新版 sentences 返回，部分结果按句序号合并，避免重复或丢失前句；极速文件在松手后上传录音并返回结果。

音频为16kHz/16bit单声道。流式按200ms音频包、1:1速率发送；队列有界，支持连接尚未完成时松手、取消、超时和业务错误。日志记录帧形态、错误码、会话结果长度，不记录签名URL、密钥或语音正文。SecretID/SecretKey 默认不进入“不含密钥”的整包备份。

上游参考：[说点啥 PR #134](https://github.com/BryceWG/BiBi-Keyboard/pull/134)、[修正 #135](https://github.com/BryceWG/BiBi-Keyboard/pull/135)。官方协议：[实时](https://cloud.tencent.com/document/product/1093/48982)、[实时V2](https://cloud.tencent.com/document/product/1093/131127)、[极速文件](https://cloud.tencent.com/document/product/1093/52097)。许可与改动记录保留在安装包内。

## 语音状态栏

居中话筒采用轻柔光晕，两侧各三根清晰可辨、相互交叉的细曲线由实际录音音量驱动，使用快起慢落的平滑过渡；安静时回到平线。松手后切换识别反馈，连接与模型加载使用各自状态标识，不用波形冒充录音。颜色跟随主题，遵守系统关闭动画设置；隐藏或离开输入法后停止绘制回调。绘制复用画笔、路径与渐变，不在每帧创建模糊位图。

腾讯的真实识别需配置用户自己的服务凭据。具体构建、实机检查与未覆盖范围见检查记录。
