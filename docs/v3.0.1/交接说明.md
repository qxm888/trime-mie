## 构建

使用 JDK21、Android SDK37 / Build Tools36，当前交付 arm64-v8a，最低API21。

```bash
JAVA_HOME=/usr/lib/jvm/java-21-openjdk ANDROID_HOME=/opt/android-sdk \
  ./gradlew app:assembleDebug -PvariantTag=v2 -PbuildABI=arm64-v8a --max-workers=2 --console=plain
JAVA_HOME=/usr/lib/jvm/java-21-openjdk ANDROID_HOME=/opt/android-sdk \
  ./gradlew app:assembleRelease -PbuildABI=arm64-v8a --max-workers=2 --console=plain
```

正式构建需要单独配置原有签名；交付包不含私钥或口令。继续使用此前证书，SHA-256：
`b22fc84964778b646c395c87d93a323d21655eaffd53718a814035adf476d5bf`。

源码包含构建所需的预编译 JNI、Sherpa AAR 和 Gradle Wrapper JAR；既有来源记录见 NATIVE_BUILD.md。

## 重点代码

- `ToolbarShadowAnimator` / `SurfaceDrawable` / `ToolButton`：工具栏外阴影绘制、圆角裁切、波纹和密度修正。
- `LenientListSerializers` / `MaybeStringListSerializer`：补齐动作和字体列表JSON写入，保留原有YAML宽容读取。
- `ButtonAlignment` / `CustomKeyboards` / `CustomKeyboardYaml`：每行独立排列、预览及持久化；`ButtonsBarUi` / `AlwaysUi` 为工具栏排列。
- `SettingsPageFragment` / `MainFragment` / 布局 include：搜索框、直接语音入口和顶部遮挡。
- `TencentModels` / `TencentProtocol` / `TencentAsrEngine`：上游目录与协议适配，队列、取消和业务错误处理。来源和许可见更新说明及安装包 NOTICE。
- `VoiceRecordingView` / `VoiceRecordingState` / `BuiltInVoiceController`：真实生命周期、RMS平滑和三线交叉动效。
