# V3.2.1 多格式导出与绑定复制

V3.2.1 / versionCode 20261226，arm64-v8a，沿用原正式证书。安装包为 `trime-mie-v3.2.1.apk`。

## 造词与候选调整导出

- “输入与候选 → 造词管理 → 更多 → 导出全部造词”：导出全部方案的造词，不受当前搜索和筛选条件影响。
- “统计与候选备份 → 候选调整 → 导出候选调整”：导出各方案、编码的固定位置、顺序、隐藏、造词及搜索范围。
- 两处均可选择 YAML、JSON、TXT，再选择保存位置。保留词句、标点、emoji、制表符和换行。
- “导入候选调整或造词”自动识别三种格式。完整候选备份替换现有规则；仅造词备份合并词条，保留已有排序和其它调整。写入前保留原记录备份。
- 完整 JSON 兼容旧版结构；仅造词 JSON 使用版本 2，避免旧应用将它当作完整备份而覆盖全部规则。文件上限 32MB。
- 词典草稿 ZIP 导出保留；原生 Control+Delete 忘词及 Rime 学习词频仍使用用户词典或整体备份保存。

格式说明见 [候选与造词导出格式](../候选与造词导出格式.md)。

## 复制整套按键绑定

- 同时复制主键盘和对应次级键盘的手势、弹出备选、发送开关，以及按键符号和注解的自定义文字、单键字号、位置、对齐与显示设置。
- 来源符号或注解为空时，对应目标内容同步清空；整套继承中的按键保存明确覆盖，避免后续共用值把复制结果改回去。
- 来源有多个同名或同动作按键而符号/注解不同的，纳入歧义判断，无法唯一匹配的按键保留原值。
- 保留目标主标签、布局、背景、颜色和字体；套内跳转仍映射到目标对应页面，不新建未匹配页面。
