# V3.2.1 源码交接

源码标签 `v3.2.1`；增量补丁基于已发布的 `v3.2.0`。正式 APK：`trime-mie-v3.2.1.apk`，versionCode 20261226，原证书，arm64-v8a。

新增 CandidateRecordFormats 保存/读取 YAML、JSON、TXT。CandidatePreferences 的原 exportJson 仍供整体备份使用；importJson 兼容入口转到自动格式识别。造词文件导入合并，完整候选文件替换。CreatedWordsActivity 与 PersonalDataActivity 共用 CandidateExportDialog。

KeyboardBindingCopy.Match 新增符号/注解快照，copyKey 统一处理单页及整套复制、继承覆盖。歧义比较覆盖所有复制字段，背景、颜色与主标签不在复制范围。

按 BUILD.md 构建；预编译依赖来源见 NATIVE_BUILD.md。源码包不含签名私钥、登录凭据、设备备份或 APK。正式附件不包含咩2。

当前完成编译与产物检查，未运行本轮自动化测试或真机验证。后续可针对三格式往返、仅造词合并、空符号/注解复制及继承覆盖做专项回归。
