# V3.3.2：UR 角色动作、猴哥与孵化

> 按键动作部分已被同日《V3.3.2-键灵踩键修订》取代：所有键灵现在使用脚踩键，底部多余掌托已删除；本文件保留上一轮素材、孵化及兑换设计记录。

## 角色动作

- 小咩重新制作无手臂的四表情本体和同画风完整手臂：白金衣袖、腕口、肤色手掌及五指。保留金发双丸子头、白金裙装、原人物比例。
- 模型本体、肩部、衣袖和手掌共用 128 单位的角色坐标及身体变换；UR 不再调用通用猫爪绘制，也不再单独在屏幕坐标里挂两只手。
- 小咩整条手臂长约 22.74 模型单位，猴哥为 26；固定衣袖和手掌整体转动，不拉伸贴图、不随目标距离改变长度。UR 也不使用非等比身体挤压，保持人物和肢体比例。
- 每位 UR 具有自己的肩部位置、手臂长度、衣袖和手型。小咩使用 imagegen 生成的衣袖 / 手掌，猴哥使用与战甲一致的矢量护臂和灵长类手指。
- 根据模型可达半径计算身体落点，够不到时沿跳跃弧线靠近目标键；键帽立即响应真实按下，角色在约 210ms 内靠近，快速点按的可见动作保留约 280ms。
- UR 跳到键盘前方时绘制完整人物，场景高度增加以保留腿脚；回位后恢复键盘后方层级，横竖屏拖动、缩放和边界钳制继续有效。
- 小窗轻点互动、挥手、比心、玩耍使用同一套角色手臂。纹理只解码一次，绘制复用矩形 / 矩阵，不在按键帧重新裁图或写盘。

## 猴哥优化

原素材位于用户的 output/键灵小屋-20261104/pets/premium。保留猴哥角色设定、红披风与战甲，重画暖棕毛色、奶油色猴脸、金箍、金箍棒、尾巴和护臂；去掉原素材中遮住眼睛的红色面罩与尖刺头型。新的头部、身体、背层与手臂分层保存，保留已有 monkey ID、等级、昵称、装扮与碎片。

母版与生成器：

- tools/generate_monkey_rig.py：生成 XML 与 SVG，可继续编辑路径和配色。
- tools/pets/ur/monkey-refined.svg、monkey-arm.svg：静态母版。
- ui/pets/PetUrRig.kt：角色肩部、长度和完整手臂绘制。

- ui/pets/PetMiniKeyboardView.kt：模型可达距离、跳跃落点和层级。
- tools/render_ur332_preview.py：静态装配示意，不是 Android 截图或真机结果。

## 孵化概率

| 品质 | 基础概率 | 重复碎片 |
| --- | --- | --- |
| 普通 | 60% | 3 |
| 稀有 | 28% | 5 |
| SR | 10% | 10 |
| SSR | 1.5% | 20 |
| UR | 0.5% | 50 |

小咩专属兑换，不入池。其余全部角色（含猴哥与后续新增 UR）进入常驻池，同品质内均匀抽取；当前池内 UR 为猴哥，所以猴哥基础概率为 0.5%。未来增加池内 UR 时平分 UR 的 0.5% 总概率。

- 连续 10 次必得 SR 或以上，连续 50 次必得 SSR 或以上。
- 新增连续 200 次 UR 保底，单次与十次共用进度；抽到 UR 后重置。
- 在高品质 / 低品质保底同时触发时优先满足 UR，再满足 SSR / SR。
- SSR 保底采用“至少 SSR”，自然抽出的 UR 会保留；UR 同时重置 SR、SSR 计数。
- 兑换不会消耗孵化次数或改变保底。UR 保底从升级后的孵化开始累计；旧 SR、SSR 进度不重置。
