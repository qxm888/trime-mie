# Trime Mie V2.1.3

版本：V2.1.3 / 20261126。正式版 `com.osfans.trime.mie`，arm64-v8a；文件名 `trime-mie-v2.1.3.apk`。

本轮为自定义键盘与主题键盘增加一整套按键美化特效。设置入口：

**设置 → 外观 → 全局按键与状态栏样式 → 自定义键盘全局外观 / 主题键盘全局外观 → 按键特效 · 阴影、渐变与按压**

自定义键盘编辑器菜单里的“自定义键盘全局外观”也可直接进入。两种键盘分别保存，互不影响。

## 1. 外阴影 · 投影 / 发光

- 开关、颜色、模糊半径（0–32 dp）、水平/垂直偏移（−16–16 dp）、扩散（−8–8 dp）。
- 默认是向下 3 dp 的柔和投影；把偏移归零、颜色改成低透明度亮色，就是霓虹发光。
- 阴影由键盘层统一绘制在按键下方，可以越过单个按键的 View 边界，不会被按键圆角裁掉。

## 2. 内阴影 · 凹陷质感

- 开关、颜色、模糊半径（0–24 dp）、水平/垂直偏移（−12–12 dp）。
- 从按键边缘向内渐隐，适合做内嵌、软键帽、凹陷玻璃效果。

## 3. 渐变与材质

- **叠加渐变**：线性 / 径向 / 扫描三种类型，起始色、结束色、角度（0–360°）、不透明度（0–100%）。
- **渐变边框**：起始色、结束色、角度、粗细（0.5–8 dp），开启后覆盖普通单色边框。
- **顶部高光 / 玻璃反光**：强度 0–60%，模拟光源从上方照到键帽。
- **磨砂颗粒**：强度 0–30%，配合已有的动态模糊背景做磨砂玻璃质感。
- **3D 键帽底边**：底边深度 0–8 dp、底边颜色；按下时底边会同步收窄。

## 4. 按压反馈

- **按下缩放**：0–10%，整个按键（含文字）围绕中心缩小。
- **按下下沉**：0–8 dp，整个按键向下位移。
- **按下变暗**：0–60%，在背景上叠一层黑色遮罩。
- **动画时长**：0–300 ms；按下减速、松开回弹。
- **按下波纹**：颜色可调，从触点位置向外扩散并渐隐。

## 5. 文字阴影

- 开关、颜色、模糊（0–16 dp）、水平/垂直偏移（−8–8 dp）。
- 使用 Android 原生文字阴影层，开销低，只影响文字/符号，不影响背景。

## 6. 一键美化 / 清空特效

“按键特效”抽屉顶部提供两个预设：

- **一键美化**：柔和外阴影 + 轻微内阴影 + 顶部渐变 + 渐变边框 + 高光 + 3D 底边 + 3% 缩放 + 1.5 dp 下沉 + 按下波纹。
- **清空特效**：恢复全部默认关闭。

预设只修改当前草稿，点“应用”后才写入；应用后仍可逐项微调。

## 实现说明

- 所有模糊阴影、内阴影都先在离屏小位图里用 `BlurMaskFilter` 生成，再按按键尺寸缓存；输入时只绘制缓存位图，不在每帧重复做像素模糊。
- 外阴影由 `KeyboardView` 中独立的阴影层绘制，层级位于视频背景之后、按键之前，因此阴影可以超出按键自身边界，又不会盖住按键和文字。
- 不依赖 Android 12 的 `RenderEffect`，Android 5.0（minSdk 21）即可使用；动态模糊背景仍沿用原有的低分辨率后台捕获方案。
- 新配置写在原有 `SurfaceAppearanceConfig` JSON 的 `effects` 字段中；旧版 JSON 缺少该字段时按默认值解析，不会丢失原有背景、边框、圆角和模糊设置。

## 限制

- 特效是纯软件绘制，按键很多、阴影模糊半径很大时会增加首帧生成缓存的时间；缓存完成后主要开销是位图绘制。
- 渐变、颗粒、高光叠加在原有背景图/背景色之上；如果原背景本身已经很花，建议降低不透明度。
- 本轮构建通过编译与单元测试，未连接真机做视觉验收；不同主题、字号、按键高度下的观感需在设备上确认。
