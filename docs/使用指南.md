# 使用指南

## 首次启用

安装正式版后，在 Android 的键盘管理中启用“同文输入法咩版”，切换为当前输入法。导入或配置自己的 Rime 方案、词库与主题并部署；安装 APK 不等于已经准备好所有个人方案。

## 使用旧的外部目录

在应用设置中打开“直接使用外部目录”，授予系统要求的文件访问权限，确认路径为 `/storage/emulated/0/rime`，再点“切换并使用此目录”。修改方案、主题、词库后重新部署。

Android 的“所有文件访问权限”是系统级共享存储权限，范围大于单独的 rime 文件夹；应用按所选目录操作数据。切换目录前备份已有文件，正式版与咩2需要分别授权。

## 切换悬浮或单手

打开键盘功能面板，在“输入统计”旁使用“悬浮键盘”或“单手模式”。两种模式互斥。

- 自由悬浮：左侧按钮收起工具图标后，按住空白状态栏移动；拖动两下角白底粉边条改变尺寸。
- 单手：在“设置 → 虚拟键盘”选择左边、右边或两边，并设置单手宽度。选择“两边”时，快捷按钮在左靠、右靠、正常之间循环。
- 普通手机横屏可使用自动悬浮策略；具体布局受设备屏幕和相关设置影响。

## 自定义键盘

选择主题覆盖编辑或独立自定义模式。前者保留原 YAML 主题文件，通过覆盖数据修改绑定；后者单独保存布局与外观。编辑行高、行间距、按键动作与背景后保存应用。

导出时选择需要的键盘，输出 YAML。图片、视频等资源不嵌入 YAML，迁移到其他设备时应同时复制资源并检查引用路径。

每个背景位置只能启用一种类型。视频只用于整体键盘背景，从本地选择，静音循环并在键盘隐藏时暂停。

## 候选与长注释

在设置的候选/注释相关选项中调整最多显示行数、单行自动缩小与长按完整显示。默认两行；可关闭行数限制。长内容可在完整显示窗口阅读，横屏时窗口也会受可用空间约束。

## 内置语音

1. 打开设置中的语音入口并选择在线或离线引擎。
2. 在线：填写自己的 API Key、接口地址和模型；预设不代表免费或已替用户开通账号。
3. 离线：选择模型和下载源，可先测速；也可导入匹配的模型 ZIP。等待“下载 → 解压 → 校验 → 安装 → 已启用”完成。
4. 授予麦克风权限，在输入框长按空格说话，松开等待结果上屏。主题若给空格设置了明确的长按动作，先调整该绑定。

模型保存在应用内部目录，与安装包分开；卸载应用会清除内部数据。首次加载大模型需要等待，设备性能与可用内存会影响体验。下载源和在线服务可用性由对应服务决定。

## 剪贴板与统计

剪贴板右侧菜单中可搜索、删除或临时保持面板展开，便于连续粘贴。收藏分类可编辑与调序。

输入统计按当前布局展示完整热力图，未按到的键显示 0%；分享图片会导出完整长图。
