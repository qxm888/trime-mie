# 宠物迷你键盘陪伴

在键灵小屋首版上，按用户提供的视频交互增加独立迷你键盘。视频仅用作交互参考，没有提取或复用视频中的宠物形象。

## 使用

1. 设置 → 便捷功能 → 键灵小屋，先领养一只伙伴。
2. 小屋主页点击“开启迷你键盘陪伴”；或右上角设置选择“迷你键盘陪伴”。
3. 回到任意普通输入框打开同文，迷你键盘默认显示在主键盘上方。
4. 点击工具栏宠物头像可展开 / 收起迷你键盘，长按头像进入小屋。
5. 在迷你键盘上直接拖动即可摆放位置。轻点宠物可互动；点按下方小键盘或长按小窗打开菜单，可挥爪、比心、逗它、收起、放大、缩小、重置位置、打开小屋。

展示方式：

- 仅在小屋：没有头像或小窗。
- 头像入口：默认收起小窗，通过头像点按打开。
- 迷你键盘陪伴：启用时展开小窗，随输入法显示；用户主动收起后会记住状态。

大小范围为 60%～150%，默认宽约 154dp；横竖屏位置分别保存，旋转或改大小后限制在屏幕内。关闭输入法 / 切换输入法 / 私密输入框会隐藏小窗，不申请系统悬浮窗权限。

## 按键动作

- 读取实际当前 Keyboard 的键位几何和短标签，生成当前布局的缩小版，覆盖主题、内置、自定义的普通按键布局。
- 按真实按键的身份对应小键帽，支持重复键码的不同位置、26 键、9 / 14 / 18 键、数字 / 七列等布局；切换布局后更新小键盘。
- 真实按下时，对应小键帽下沉，宠物左 / 右爪移动到那个键；中央宽键可由两只爪子一起按。松开后爪子回位。
- 直接连接 KeyView 的按下、松开、取消与视图拆除事件，独立于输入统计开关、键元计奖与上屏延迟。快速轻点保留约 90ms 的可见接触，取消事件立即释放，避免按键卡住。
- 实体键盘按键也按键码联动当前布局中相应的第一个键位。
- 迷你键盘是展示与拖动控件，不承担向宿主输入字符的第二套输入逻辑。独立符号/表情面板并非 KeyView 布局，不会复制为超大迷你面板；它显示最近的普通键盘。

## 性能与生命周期

- 停止了旧版“每隔几秒跳一下”的陪伴方式。动效由按键或用户互动触发；连续输入后停下，会有一次伸懒腰 / 哈欠，没有循环空闲定时动画。
- 对每只爪子复用一个短动画；用轻量 Canvas 绘制小键盘；每个布局最多复制 160 个键位，布局/Shift 状态不变时复用几何。
- 拖动位置按显示帧合并更新，松手后再异步保存，不逐像素写盘；实际按键联动不写文件、不存储输入文本。
- 小窗使用非焦点、非触摸模态的 IME 子窗口，触摸范围仅限小窗矩形；默认摆放在主键盘外，输入法隐藏或视图销毁时关闭。
- 收到取消、切布局、切主题、关闭小窗或输入法退出时，清理按下状态与动画；不复用旧视图的按键身份。
- 动画关闭设置下直接更新按下状态，仍保留键位对应；API 29 屏幕坐标接口有版本保护，旧系统按输入法窗口偏移转换。
- `miniExpanded`、`miniScale`、竖屏及横屏位置保存在原 `pet_house.json`，随整包备份恢复。旧宠物存档缺少字段时兼容默认值；原第 2 档陪伴升级为新迷你键盘陪伴。

## 实现位置

- `ui/pets/PetMiniKeyboardView.kt`：实际布局映射、键帽、双爪动作、拖动手势。
- `ui/pets/PetCompanionController.kt`：窗口、屏幕边界、缩放、位置保存及生命周期。
- `ui/pets/PetToolbarView.kt`：头像点按 / 长按入口。
- `ime/keyboard/KeyView.kt`：真实触摸按下 / 松开 / 取消身份。
- `ime/keyboard/KeyboardWindow.kt`：布局切换后的刷新。
- `ime/core/TrimeInputMethodService.kt`：输入法显示隐藏、私密输入、实体按键及释放。
- `data/pets/PetHouse.kt`：展示设置序列化与备份兼容。

窗口接口参考：[Android PopupWindow 官方文档](https://developer.android.com/reference/android/widget/PopupWindow)。

## 构建状态

本轮执行编译及原签名 Release 构建；不包含真机交互或自动测试结论。编译成功不能确认各手机窗口坐标、拖动及连续按键动作效果。用户参考视频保留在其原位置，不加入应用或导出包。

## 表情与小动作

- 打字交替触发微笑、眨眼、专注、惊讶、开心、吐舌；回车、退格、空格有对应的偏好反应。
- 歪头、点头、抖耳 / 摇尾、轻跳、扭身、伸展、轻摆与左右爪按键分别控制；表情最多约每 270ms 更换一次，爪子不受这个间隔限制。
- 轻点宠物做视觉互动；菜单里选择“逗逗它”“比个心”“挥爪打招呼”。小屋也有对应按钮，喂养、玩具和进化成功后有相应表情。
- 系统禁用动画时只显示短暂静态表情和真实按键状态，不播放位移动画。
- 关闭小窗、退出输入或切布局会取消未完成动作与待触发的哈欠。
