# V3.7.1 键灵打字战斗与句子发送修复

发布版本：V3.7.1，versionCode 20271115，包名 com.osfans.trime.mie。源码标签 `v3.7.1`，发布页面：https://github.com/qxm888/trime-mie/releases/tag/v3.7.1 。

## 使用变化

从键灵迷你键盘菜单进入“打字游戏”。通关永久解锁下一关，菜单每页10关，可直接点击已解锁关卡开始，起始选择会保留。旧版未写入 unlocked 的记录使用 bestLevel（最高到达关卡）恢复，不再被第10关限制。失败、退出或重玩低关不会额外解锁或降低进度。

上方落字、下方当前选择的键灵作战。正确输入时发射弹丸，约320ms后命中目标再消除、计分。词组和句子可逐字输入；已完成输入的目标会保留给弹丸，不会重复计分或被算作漏字。普通键灵发射浅蓝小圆球，小咩发射粉色爱心，同时抬手、轻跃并显示爱心碎片。

新增原创合成的发射与命中短音效。菜单、游戏及暂停界面均可切换音效，设置独立保存。音效最多4路、65ms节流，关闭立即停止现有声音；退出游戏或隐藏输入法会释放音效资源。音频生成脚本为 script/generate-typing-game-sounds.py，无外部素材授权依赖。

暂停同时冻结落字、弹丸和攻击动作；菜单不持续刷新，游戏使用统一帧时钟。最多4个落字、24个弹丸、32个命中特效，短音频约19KB，不新增后台定时轮询。表现可能受设备、主题和其他输入功能影响。

常用句修复说明和覆盖边界见《常用句验证.md》。QQ反馈设备尚待用户复测。
