# V3.3.2 · 键灵蹦跳踩键与 UR 伙伴

## 本次更新

- 全部 58 位键灵改为站立蹦跳、左右脚交替踩迷你键盘；手部做挥手、张手平衡等动作。小咩使用新的站立四表情素材，猴哥优化金箍、战甲、披风和完整护臂。
- 迷你键盘移除底部多余空白，脚底对准实际键位；同键连按重新跳跃，快速输入自适应缩短动作，支持拖动摆放、缩放及松键回位。
- 新增 UR 小咩与猴哥。小咩通过专属兑换获取；其它 UR 进入孵化池，UR 总基础概率 0.5%，增加 200 次 UR 保底。保留 SR / SSR 保底，并修复 SSR 保底覆盖自然 UR 的问题。
- 修复用过一个兑换码后无法再次打开兑换入口；不同兑换码独立记录，原宠物、等级、昵称与装扮继续保留。
- 横屏布局增加键盘透明度调节。
- 符号面板改为「英文符号、中文符号、常用符号、更多」四列导航。
- 输入统计增加合并的字词云，可与字云、词云分别选入分享图片。
- 内置与自定义键盘 YAML 采用分区说明、每键一行、行号注释的易读格式；保留原布局标识、导航、配色和恢复元数据。

## 验证情况

- 6 项本地专项测试通过。
- 在用户授权的 .33 手机 PKX110 上，使用同一主代码和素材的独立咩2调试包完成 10 项真机专项：58 位键灵各 3 个目标键，共 174 组起跳 / 落脚及绘制检查，以及真实触屏按键、同键连按、30 次快速跨键、回位、拖动、60%/150% 缩放、隐藏清理和密码输入抑制。
- 已人工查看站姿与真实输入截图。测试前配置和存档已恢复，文件哈希一致。
- 正式 APK 完成 Release 构建、包名 / 版本及原发布签名核对；本轮未在手机覆盖安装正式版。未覆盖长期耗电、所有机型或横屏专项。
