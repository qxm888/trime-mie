# V3.1.6 更新说明

功能菜单页跟随键盘配色做美化。

## 变更

- **菜单图块跟随当前键盘配色**：使用当前自定义键盘的强调色（回车键颜色）13% 淡底 + 16dp 圆角，
  图标与文字使用键面文字色；主题键盘模式下仍用主题的按键底色。
- **菜单底色**：整页背景改为当前键盘的背景色，四周留 8dp 内边距，不再是一片灰白。
- 图块与标签间距收紧到 4dp，配合上一版的字体缩放自适应高度，大字号下也不裁切。

数据来源：`CustomKeyboards.activePalette()`（背景 / 文字 / 回车强调色），
与候选栏美化使用同一套取色逻辑。

## 交付

- 版本 V3.1.6 / versionCode 20261213，正式包 `trime-mie-v3.1.6.apk`，与 V3.1.x 同签名可覆盖安装。
