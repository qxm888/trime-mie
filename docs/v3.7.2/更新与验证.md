发布日期：2026-11-14。版本 V3.7.2 / versionCode 20271116，arm64-v8a，包名 `com.osfans.trime.mie`。发布标签 `v3.7.2`，正式包 `trime-mie-v3.7.2.apk`，包含下方鸡哥补充；使用已签名验证的鸡哥构建，不是此前仅含全屏修复的原型包。

## 使用变化

从键灵菜单打开打字游戏后，游戏从系统状态栏下方一直铺到实际键盘顶部，覆盖中间的聊天区和应用输入框。键盘仍用于游戏输入，退出后回到原应用。

原来用可拖动迷你键灵的位置决定高度，位置尚未布局时回落到三分之一屏幕。现在独立读取键盘的屏幕边界，支持普通、左右单手模式。键盘区域变化会更新游戏窗口，保留分数、关卡、暂停状态及现有落字剩余时间。

落字采用随关卡增加的移动速度，并设置最短反应时间；不再因为场地变高而同步加快下落。首关至少约10秒，最后一关至少约5秒。保留通关解锁、旧记录迁移、选关、圆球/小咩爱心攻击、暂停和音效开关。

## SSR 鸡哥

按用户参考图制作银灰中分、黄色本体、红脸颊、黑底白背带的矢量键灵（内部ID `jige`）。图鉴增至59位，加入既有 SSR 孵化池，总品质概率和保底不变。入口为“键灵小屋 → 商店 → 兑换口”，输入 `qxm111` 可直领鸡哥，每个存档限用一次；已拥有则转为20同名碎片。该领取记录独立于原有三种兑换码，保存到 `jigeRedeemed`，旧存档默认未领取。

角色使用独立翅膀和鸟脚，支持原有互动表情、视线和迷你键盘踩键；游戏发射有翅膀、眼睛和嘴的黄色小鸡，动作分为收翅蓄势、侧身肩靠和回位，暂停沿用游戏时钟。原小咩爱心和其他键灵圆球保持原类型。音效沿用游戏现有短音效和音效开关，未加入音乐或人声。

原画可编辑源为 `docs/artwork/jige/jige.svg`；`tools/generate_jige_art.py` 生成三层 Android 矢量资源。预览动画是按相同分层原画和动作关键帧渲染的设计预览，并非手机录屏。本次鸡哥未做手机实测，不以此前全屏游戏的实测代替新增角色验证；本次最终 Release 构建和85项针对性回归通过，含兑换独立性、防重复、防伪造目标、旧兑换规则、弹丸类型及动作回位检查；0失败、0错误、0跳过。未重跑全仓库 lintRelease。
