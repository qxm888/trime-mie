## 完整性与编辑

每套沿用当前内置布局的 15 个页面：26、9、14、18、七列一、七列二、英文、数字、英文符号、中文符号、数学符号、更多符号、布局页、样式入口页、键盘中心。非七列统一为 251dp/8dp 行距；七列保持当前模板自己的几何。工具栏、悬浮候选窗、悬浮球颜色与整套配套。

采用现有“整套设置 → 布局/整套设置/复用”模式。按键材质是普通图片背景，用户可逐键、按角色或用全体背景功能替换；字号、圆角、边框、绑定仍由现有编辑器控制。字符没有烘焙进图片，沿用系统/用户字体设置。上方符号默认靠右，下方注解默认居中。

新主题加入现有内置资源，布局目录自动识别，现有“内置布局”两列选择及配色组可以选中。旧四套特效主题及五色主题的配置不被生成器改写。初始新增主题时模板版本为 V16；后续符号与注解范围调整为 V17，尺寸与 R 双击默认值调整为 V18，仅补未配置的内边距值。已有编辑按原有保守迁移规则保留，详见上一层的《符号排序与显示范围》。

## 素材与性能边界

- 108 张原创 PNG，打包约 3.3 MiB。键面区分窄键与宽键，避免将窄键高光硬拉到九键/空格上。
- 材质安装到 `.mie/键盘背景/内置材质/精雕一辑/<主题名称>/`，子目录与素材分类可直接读懂。
- 安装在布局后台任务中完成；成功后才注册新页面，失败保留当前布局并写日志。下次初始化仍会重试。
- 清单检查缺少的文件，AtomicFile 写入，不覆盖用户修改过的现有素材，不删除其它素材。
- 图片沿用 BitmapAssets 的异步解码和缓存；光影预先烘焙，按下仅使用原有短缩放/下沉，不增加持续动画、视频或每帧 AI 处理。
- 该辑路径为不可变素材命名空间。以后更换出厂素材时新建下一辑/修订目录及标记，不用同名文件覆盖用户编辑。

## 可重复制作

作者端依赖：Python、numpy、Pillow、PyYAML、librsvg 的 rsvg-convert；均不作为 Android 运行依赖。

```sh
python tools/generate_premium_themes.py
python tools/render_premium_themes.py /tmp/premium-five-preview
python tools/render_premium_themes.py /tmp/premium-nine-preview --layout _9
```

- `tools/premium/palettes.json`：五套色板及光影参数。
- `tools/premium/materials.py`：材质、折光、云朵与图标的原创生成源。
- `tools/generate_premium_themes.py`：从现行樱花粉布局生成五套完整家族，只替换这五套生成结果。
- `tools/render_premium_themes.py`：读取同一套布局和打包素材生成设计预览；不是 Android 渲染器。
- `mie_premium_materials.zip` / `mie_premium_materials_manifest.txt`：应用内素材与清单。
- `BuiltinPremiumAssets`：受清单限制、原子写入的安装器。

### 后续 AI 必须保留的行为

1. 根 ID 与所有 secondaryOf、内部 Keyboard_ 目标一起重映射；不能残留 custom_pink/custom_frost 的跳转目标。
2. 返回用 Keyboard_default，不能写死回 26 键。工具栏中英动作使用 Mode_switch，交由现有中英来源记忆处理。
3. 工具栏皮肤与主题辅助页调用 __mie_theme_picker，共用布局/配色选择页；不得另外建立一份固定主题清单。
4. 不用动作名或标签决定用户编辑后的按键颜色，不改已有角色外观、单键覆盖及整套绑定规则。
5. 不另加全局字体，不能安装新版本时覆盖用户字体。不改部署、候选排序、输入统计或语音代码。中英切换必须实测 reset_ascii_mode=false 的七列来源，不能只测 26 键。
6. 新增出厂布局须增加 BUILTIN_VERSION；新增素材同步更新清单，目录仍受 CustomKeyAssets 安全根约束。不要在绘制或点击事件中解压素材。

## 测试方法与修正

- `PremiumBuiltinThemesTest` 检查五套完整家族、15 页目标、108 张素材、资源引用、配色、工具栏和绑定继承。
- 仅调试版本注册 `PremiumThemesRunner`，在已备份的咩2数据上检查实际皮肤按钮、75 页加载、六种中文布局中英/数字页往返、菜单重绘、连续按键及悬浮模式。该脚本会重置五套测试主题，运行前须备份调试包的文件、偏好和外部链接资源，运行后恢复。
- 真机发现七列布局保存了进入英文后的状态，切回中文时会再次跳到英文。`KeyboardWindow` 现在在明确切回中文时更新来源页的记忆值，保留其它布局的状态恢复规则。
- 修正了只读标题继承源樱花粉颜色的问题，符号和辅助页也使用各套自己的材质与文字色。
- 预览脚本统一处理数字/字符串行号，第二行按旧布局居中；模型与真机均检查高度、间距和对齐，旧布局的行边距不会因新材质改变。
- 候选测试使用应用专属临时根目录中的五词测试方案，仅显式部署该临时目录，测试后恢复位置并删除。

- 编码高亮直接绘制在候选面板上，不应使用深色候选选中块的白字。`highlight.text` 与面板正文同色，另有普通/高亮编码对比度检查；不影响选中候选的强调色。
