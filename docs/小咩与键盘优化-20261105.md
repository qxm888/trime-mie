# 小咩与键盘优化 · 2026-11-05

基于当前 V3.3.0（56 位伙伴）继续修改；本轮不上传 GitHub，不更改版本号。

## 1. 横屏透明度

“键盘 → 横屏布局 → 横屏键盘不透明度”，20%～100%，默认 100%。该设置独立于横屏尺寸开关，对横屏的主题、内置和自定义键盘统一生效，作用于整个工具栏与键盘容器。竖屏恢复完整不透明；不改变按键命中、绑定或布局。

## 2. 符号面板四列导航

共享符号面板顶部固定等宽四列：“英文符号 / 中文符号 / 常用符号 / 更多”。前三项直接切到相应分类；更多打开完整分类列表，保留表情、语言、数学等全部分类，保留分类拖动排序、分类内排序、删除和恢复。当前分类在下方计数行显示，所处导航项加粗。

## 3. 字词云

统计页面保留字云、词云，并新增字词云，将当前方案和周期的字词记录共同排布。图片分享增加独立“字词云”勾选项，可只选这项或与其它模块组合为一张图。保留旧分享勾选，新合并模块默认不勾选。

## 4. 文件可读规范

参考用户提供的《夜澜听雨·十列_咩版.trime.yaml》，统一三份当前内置模板与自定义 YAML 导出的布局区：

- 顶层按样式、配色、工具栏、预置功能、键盘布局分区，保留原主题标准字段。
- `preset_keyboards` 下每个布局有名称；`keys` 按键每项一行流式映射，行间留白并标注行号。
- `click / long_click / swipe_* / label / hint / popup / width / height` 等可直接阅读修改。
- 自定义导出的复杂皮肤、动效、绑定继承信息移至布局末尾 `mie.keyMetadata`；按键内只保留 `mie.row / mie.ref`，`ref` 随按键移动，避免依赖位置索引而错配。
- 导入兼容原每键嵌入完整 `mie` 的旧格式。绑定仍以标准字段为准；原 ID、跳转、配色、字体及资源路径不改。
- 工作数据库仍是 `rime/.mie/键盘/键盘布局.json`，以后保存时增加缩进；没有将数据库强行改成主题 YAML。手动编辑、互传布局可用新版导出的 YAML。
- 后续生成内置模板后运行 `python3 tools/format_keyboard_yaml.py`，避免脚本再次生成难读的逐字段按键。

## 5. UR 小咩

新增第 57 位伙伴“小咩”，品质 UR。参考视频的金色双丸子头、白色服装、Q 版人物方向，使用 imagegen 生成四姿态透明图集，保留普通、开心、眨眼比心和专注姿态。资源位于 `res/drawable-nodpi/pet_xiaomie_atlas.png`，生成记录在 `tools/pets/ur/`。

商店 → 兑换口，输入 `qxm520`，直接确认领取小咩；每份存档限用一次，单独的 `xiaomieRedeemed` 字段随存档和整包备份保存，不占用原 `qxm888` 的次数。小咩为专属兑换伙伴，不进入随机孵化池；原概率和保底保持原规则。原兑换码继续选择原 56 位伙伴。

## 6. 固定长度手臂

全部伙伴的迷你键盘手臂改为 18 + 20 单位的两段关节，使用逆运动学弯曲，不随距离拉伸。远处按键会带动身体平移并沿短跳跃弧线靠近；松手后回位。超出当下可达范围时，手臂保持固定长度并等待身体靠近，真实按键的键帽仍立即响应。快速轻点的可见动作保留约 180ms。

UR 使用白色衣袖和肤色小手；迷你模式只切换头部表情，手部由相同关节模型驱动，避免图集中挥手与真实按键同时出现重复手臂。

## 构建与限制

本轮仅编译、打包和核对产物签名，没有运行自动测试或安装手机。此前其它版本记录的测试数不代表本轮测试结果。需要后续真机确认横屏半透明的系统合成、窄屏四列文字、YAML 导入和角色跨键跳跃的视觉效果。

## 兑换入口补充修复

此前商店用 `redeemed` 标记隐藏了整个输入按钮，导致使用 qxm888 后无法输入 qxm520。现改为始终显示输入入口，并分别展示两类领取状态；输入已用过的码只提示本码不可重复使用，仍允许继续输入其它码。旧存档的两个兑换标记均不重置。后端先校验码是否有效，再校验对应使用标记。
