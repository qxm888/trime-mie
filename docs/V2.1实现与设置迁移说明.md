# V2.1.0 设置界面实现与交接

## 实现范围

在稳定 checkout `codex/v2.1.0-local` 上实现，原起点为 `7f20536`。没有操作原开发目录、提交代码、上传 GitHub、签名或安装正式包。版本为 V2.1.0 / 20261123。

- 首页统一为输入与候选、键盘、外观、便捷功能、数据与备份、高级与关于六项；搜索在顶部，试打保留工具栏入口，部署收进更多菜单，删除首页标语。
- `SettingsCatalog` 同时定义导航、页面说明、搜索路径与键归属。搜索页顶部常驻 Material 输入框，输入即更新页面和设置结果；结果可以打开真实页面，并滚动到具体偏好项。搜索词在返回、重建时保留。
- `SettingsPageFragment` 从原 `PreferenceDelegateUi` 按键选择设置，保留原默认值、存储、枚举与依赖；订阅原 provider 的变更，返回时再次刷新启用状态。没有迁移或改名 SharedPreferences 键。
- 声音、触感、播报与气泡分卡片；悬浮候选窗按窗口显示、行数、悬浮球分卡片。悬浮键盘高级参数和实体键盘组合键可以展开；分组有稳定 key，交给 Preference 保存展开状态。
- 全局视频与整体背景开关集中到外观背景页；背景选择弹窗移除整体背景即时开关，避免取消弹窗后全局开关已被改写。
- 两个按键编辑器中的全局外观均跳到同一外观页面；主题视频菜单跳到同一背景页。返回编辑器时刷新预览并保留滚动位置，布局和单键覆盖仍由原编辑器管理。
- 字体与语音页面共用设置行样式，保留原选取、导入、下载、取消和实时状态流程；字体导入的目标区域在 Activity 重建时保留。
- 设置页沿用现有 Material 3 配色，分组卡片 20dp 圆角、16dp 页面边距、20dp 组间距；分组标题允许随字体增大，字体/语音设置行至少 56dp 且支持换行。

## 兼容与状态

旧 General、VirtualKeyboard、CandidatesWindow、Clipboard、Advanced 路由继续存在，进入后重定向新归属页；SchemaList、UserDict、Profile、Theme、Developer、About、License 保留原功能页面。IME 菜单和外部 ACTION_RUN 的路由参数不变。

按键编辑器的单键覆盖、当前布局默认外观、原保存与撤销逻辑不变。全局样式仍使用 SurfaceAppearanceEditor 草稿，取消不保存；即时开关仍立即保存。音效选择与视频选择仍通过原业务方法和生命周期注册的 ActivityResult 调用。

没有修改 Rime、ASR、IME 渲染、动态模糊机制、正式包名、配置目录规则或加载策略，没有启用嵌套 rime-mie 或万象渠道。

## 限制

- 字体、语音模型和复杂布局/单键参数编辑继续使用现有 Activity/弹窗，保留原业务流程；本次统一导航和外层交互，没有重写这些业务表单。
- 搜索索引覆盖目录页面、默认设置委托以及主题委托的标题/摘要。模型名称、所有单键动态参数和文件内容不建立全文索引。
- 搜索结果对默认设置可定位到具体行；独立主题设置和业务 Activity 打开对应页面。诊断在主题页保留同页快捷入口。
- 设备检查覆盖深色显示与明暗切换；全部字体倍率、窄屏机型与横屏组合尚未完整回归，见检查记录。
