# Trime Mie V2.1.4

版本：V2.1.4 / 20261127。基于用户提供的 V2.1.3 源码；本轮不合并目录重组实验，不上传 GitHub。

## 操作路径

| 功能 | 入口与行为 |
| --- | --- |
| 外观工作室 | 外观 → 键盘与工具栏样式；分“按键、工具栏、整体”页，顶部预览，参数折叠，应用后保存 |
| 独立布局配置 | 自定义键盘编辑 → 当前布局外观；每个布局保存自己的外观和共用背景开关，旧布局继承原自定义默认值 |
| 材质预设 | 按键 → 按键特效，柔光 / 通透 / 磨砂 / 清空；通透与磨砂同时启用背景模糊，随后可调透明叠加与高光颗粒 |
| 菜单按钮 | 工具栏编辑列表首项“最左侧菜单按钮”；可改功能、显示内容、图标大小、背景、边框、手势、特效及启停；位置固定在最左侧 |
| 工具栏整体 | 外观 → 工具栏 → 整条状态栏：背景、圆角、边框、模糊和背景材质；共用背景下可开启“叠加原工具栏背景” |
| 工具栏按钮 | 工具栏页可统一设置，也可跟随按键；单个按钮编辑 → 按钮特效可独立覆盖或恢复跟随 |
| 字体字号 | 自定义键盘编辑 → 字体与字号（当前布局）；按键、符号、注解、候选、候选注释、序号、编码、弹出预览、工具栏共9类。可导入字体，字号0为默认，单键字号优先 |
| 键盘跳转 | 按键 / 工具栏绑定 → 键盘跳转：现有自定义布局、返回主键盘、上个键盘、上/下个键盘、锁定键盘；移除关联键盘编辑及其自动跳转路径 |
| 符号与注解 | 按键外观 → 文字：符号、注解及各自字号；绑定 → 窗口与候选栏 → 符号/注解显示开关，使用原“键盘显示”开关 |
| 命名组合功能 | 键盘 → 布局管理与按键编辑 → 自定义功能，或布局编辑菜单 → 自定义功能；新建名称，添加 / 替换 / 删除 / 上移动作。名称支持中文、英文、数字及组合 |
| 绑定功能名 | 绑定 → 自定义功能中选择，或“自定义输入”填已保存的名称；保存为稳定ID，重命名后原绑定仍有效 |
| 翻页排布 | 输入与候选 → 悬浮候选窗 → 窗口显示 → 翻页按钮放在底部左右两侧；关闭则保持上方小箭头 |
| 两步造词 | 长按候选 → 造词，输入单字、词、句子、标点或emoji，再输入当前方案可输入的编码；保存不隐藏原候选，新词在对应编码候选中显示 |

菜单页标题栏中多余的悬浮候选切换图标已移除，功能面板中的原开关保留。

## 自定义功能范围

绑定选择器按类提供窗口和输入模式、键盘跳转、字母数字符号、常用快捷键、全部 Android 按键、全部已映射 Rime 按键、主题动作、同文命令、方案选项开关及内置语音控制。需要参数的命令会要求输入参数；自定义命令 / Intent 可手动填写。

每个功能1–64步，总计最多128个定义；展开后最多256步、8层嵌套。循环、缺失定义和超限链在执行前拒绝，Rime键操作通过队列衔接。打开应用、切换主题、语音等异步任务按顺序触发，不等待外部任务结束。

## 保存与兼容性

- JSON和YAML布局导出包含外观、字体选择、字号、工具栏及自定义功能定义。导入遇到同名不同ID功能会提示冲突，需先重命名。
- 图片、视频、字体沿用路径引用，布局文件不打包素材。换设备时需另行复制素材或重新选择。专属函数由咩版执行，普通同文未实现这些命令。
- 造词保存于候选偏好，可通过“数据与备份 → 统计与候选备份”导出JSON并完整恢复。词典草稿导出不自动修改方案；含制表符或换行的词条以JSON保存为准。
- 旧关联键盘字段仍可解码，但自定义键盘不再依它们自动切换，需重新绑定明确的跳转动作。

## 半透范围

参考源码使用Xposed和隐藏接口。本版独立实现背景采样模糊、半透明染色、渐变高光、细边框和缓存颗粒；文字图标不参与模糊。效果面向本输入法的图片、颜色和视频背景，未接入跨应用窗口背景模糊，也不要求安装Xposed。因此不能声称与参考方案逐像素一致。参数越轻，材质越通透；“柔光”为低强度阴影，避免重叠厚重投影。
