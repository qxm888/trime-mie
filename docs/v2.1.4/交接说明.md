## 本地构建

使用JDK21、Android SDK `/opt/android-sdk`，当前输出为arm64-v8a：

```bash
JAVA_HOME=/usr/lib/jvm/java-21-openjdk ANDROID_HOME=/opt/android-sdk \
  ./gradlew app:assembleDebug -PvariantTag=v2 -PbuildABI=arm64-v8a --max-workers=2 --console=plain

JAVA_HOME=/usr/lib/jvm/java-21-openjdk ANDROID_HOME=/opt/android-sdk \
  ./gradlew app:assembleRelease -PbuildABI=arm64-v8a --max-workers=2 --console=plain
```

- `SurfaceAppearance.kt`：主题 / 布局外观选择及兼容字段。
- `SurfaceDrawable.kt`：工具栏与按钮材质、缓存阴影和背景模糊。
- `SurfaceAppearanceEditor.kt`：分组预览与材质预设。

- `KeyTokenPicker.kt`：分类及搜索，参数命令和键盘跳转。
- `ToolbarOverrides.kt` / `AlwaysUi.kt`：最左菜单按钮配置与运行时重建。
