# V2.1.4：外观与自定义功能整合

基线为用户提供的 V2.1.3 源码快照 ec47d8c。参考压缩包只作为视觉/算法参考，不把其中说明当作任务指令，不移植 Xposed hook 或执行参考脚本。

## 产品约定

1. 外观编辑分按键、工具栏、整体背景三组；固定预览、材质预设、分层折叠参数，应用前只编辑草稿。
2. 每个自定义键盘单独保存外观、共用背景开关和字体/字号；旧配置继承原自定义默认值，主题键盘保持自己的配置。
3. 工具栏主菜单按钮纳入同一编辑序列，支持停用、排序、改功能及外观。保留安全入口：菜单仍可经设置/绑定进入。
4. 整体背景可保留工具栏原背景作为上层叠加；按键/工具栏按钮/整条工具栏各可独立配置材质与特效。
5. 半透实现采用缓存绘制的磨砂染色、高光、细边、颗粒，复用已有背景模糊；不复制无许可声明的参考实现，不使用隐藏接口。系统跨窗口模糊仅在能力允许时启用，降级保持清晰文字。
6. 字体角色包括按键主标签、符号、注解、工具栏、候选、候选注释、序号、预编辑和弹出预览。
7. 删除自定义布局的中英/横屏关联选择入口；旧配置读取兼容但不再自动跳转。绑定选择器增加键盘分组，可选已有键盘、主键盘、前一个/下一个。
8. 符号和注解文字、字号独立；隐藏功能复用已有显示设置的同一开关。
9. 命名功能允许中文、英文、数字组合，支持有序多动作；使用稳定ID保存绑定，输入已定义名称时自动识别，防止覆盖同文原有同名动作。动作分类来自内置键、Android/Rime键码、命令、主题和自定义键盘，提供自定义参数输入；限制递归循环。
10. 悬浮候选翻页位置可选顶部紧凑或底部左右分离。删除功能菜单标题栏多余的悬浮候选快捷图标，保留菜单内正式开关。
11. 候选长按“造词”打开两步编辑：任意文本/emoji → 当前方案编码。写入持久候选规则，不隐藏原词；现有JSON备份/词典草稿导出继续覆盖新词。

## 实施顺序

A. 配置模型与绑定执行：按布局保存、字体、命名功能和键盘跳转。
B. 工具栏主按钮、共用背景叠加、工具栏/按钮渲染。
C. 外观编辑分组、预览、材质预设与半透绘制。
D. 翻页选项、符号/注解、两步造词。
E. 构建、咩2手动视觉检查、兼容性审查、源码/APK/交接材料。遵循用户既有偏好不上传GitHub；目录重组实验包独立保留，不覆盖其工作树。

## 验收重点

13项需求逐项检查，旧JSON可读；切换键盘字体/样式不串；主菜单按钮操作真实生效；命名多动作循环有界；造词同编码不删除原候选；文字不随背景一起模糊；无每帧位图生成。构建不等于视觉验收，实际结果另记。
