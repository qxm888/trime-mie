# Trime Mie V2.1.2

版本：V2.1.2 / 20261125。正式版 `com.osfans.trime.mie`，arm64-v8a；文件名 `trime-mie-v2.1.2.apk`。包含 V2.1.1 的独立外观、完整状态栏按钮编辑和当前布局全体按键背景功能。本轮本地交付，由其它 AI 发布 GitHub。

## 悬浮候选窗翻页指示

按用户最后调整，撤掉底部翻页条，将两个小箭头集中放回悬浮窗右上方，与编码处于同一行。箭头各10×20dp，整体20dp宽，主要用于显示前后页是否可用，保留原有翻页动作；不再额外占用底部高度或强制144dp最小宽度。无编码时在顶部保留小指示行，候选区下方不再预留翻页栏。

## 1. 键盘四角圆角

设置 → 外观 → 全局按键与状态栏样式 → 主题键盘全局外观 / 自定义键盘全局外观 → 键盘整体 · 四角圆角。

可分别调节左上、右上、右下、左下四个角（0–64 dp）。裁切键盘整体，包括背景、状态栏、视频与按键；候选浮窗和按键气泡保持独立。两种键盘的设置分别保存。关闭自定义四角时，普通键盘保留直角，悬浮键盘继续采用原有悬浮圆角。

## 2. 背景共用开关归位

“状态栏与键盘共用背景”移入各自的全局外观 → 整条状态栏 · 背景与模糊抽屉。自定义布局编辑器菜单可直接进入自定义键盘全局外观。应用或恢复默认仅影响当前模式。原背景页面改为“主题视频背景”，不再混放自定义键盘开关。

## 3. 初始 Rime 公共基础配置

内置附件 `基础配置.zip` 中的 `default.yaml`、`key_bindings.yaml`、`punctuation.yaml`、`symbols.yaml`，保持原始字节。引擎启动和部署初始化时将缺失文件补到当前 Rime 用户目录根部，不覆盖用户已有同名文件。原有传统 rime 目录模式不变。

这四份文件补齐公共 include/patch 依赖，不包含各方案的 schema、词典、Lua 或模型；缺少这些方案专属文件时仍须补齐对应方案。附 Rime Prelude 上游 LGPL-3.0 与来源声明。

## 4. 状态栏图片图标大小

设置 → 键盘 → 工具栏 → 主题键盘状态栏 / 自定义键盘状态栏 → 编辑或添加按钮。

新增“图片图标大小 dp”：0 自动适应按钮区域，或指定 8–96 dp，最大受按钮实际宽高限制。图片按比例放大，不再只按原始小图尺寸显示。尺寸随按钮 JSON 和布局 YAML 一起导入导出。

## 5. 候选调整备份与词典草稿

设置 → 数据与备份 → 统计与候选备份。输入统计页菜单和原导入导出页面也提供入口。

候选调整 JSON 完整保留各方案、各输入编码的固定位置、前后调序、隐藏、忘记与自定义编码。可导出文件、导入文件，也可写到 Rime 目录的 `mie_candidate_order.json` 后在另一设备恢复。恢复替换已有调整，不重复累加，恢复前在应用目录保留带时间戳备份；重新输入后生效。

“生成词典草稿”按方案生成 `.dict.yaml` 并打包 ZIP，同编码候选按顺序赋予递减权重。草稿记录的是输入编码；双拼、拼写运算、Lua 等可能使输入编码与词典编码不同，接入前需人工核对、必要时转换，再加入方案词典的 `import_tables` 后部署。用户词频和过滤器也可能改变实际显示顺序。因此不自动修改方案、不承诺仅靠词典可精确还原所有规则。隐藏规则与再次学习行为用 JSON 完整备份。

## 6. 统计保存在 Rime 目录

空闲约2秒后保存（持续输入时最长30秒检查一次），保留应用本地副本，并将数据镜像到当前 Rime 用户目录的 `mie_input_stats.json`。外部同步目录沿用原同步机制，跨设备前可在备份页点击“立即保存到 Rime 目录”。

新设备数据为空时，引擎启动会尝试恢复 Rime 目录中的统计。已有数据时必须通过“从 Rime 目录恢复”或“导入统计文件”明确替换，避免合并后字数翻倍。恢复前保留本地副本备份，跨日、周、月、年按原规则结转，累计字数保留。

咩2等 Debug 包使用带包名后缀的独立统计和候选备份文件，不覆盖正式版记录。跨设备正式版保持同一文件名；向不同渠道迁移可使用文件导入。

## 7. 连续输入开销与日志

统计日期边界每分钟缓存，避免在每个按键的多处回调反复计算日、周、月、年。保存任务在一次输入期间复用，不再每个按键取消再新建。候选调序用线性稳定排列，普通新调整只保存所需前缀，初始搜索范围从512降到64；长按定位按128项分段，避免首页候选就一次获取20000项。取投影分页使用列表区间，避免复制整个候选前缀。候选设置写盘与序列化移到 IO，备份编码在输入锁之外执行。

引擎处理或响应超过48ms时记录 `input/slow`（引擎/响应耗时、方案ID、是否调序），触摸事件排队超过100ms记录 `input/touch_queue`，均限流每5秒最多一条并进入诊断日志，不记录输入文字。实际收益与方案、Lua、词库、皮肤、视频和设备有关，本轮不能据此宣称所有卡顿已解决。

## 8. 忘记候选

候选长按菜单新增“忘记这个候选 · 再次选择可提升”。候选保留在当前编码可搜索候选范围的后部，不写入删除列表；再次选中后清除忘记状态并提升至前部。它是咩版独立的候选规则，不直接修改 Rime 用户词库的原始词频；可随候选调整 JSON 迁移。原来的删除和恢复默认功能保留。
