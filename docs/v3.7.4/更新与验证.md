# V3.7.4 游戏候选浮窗修复

日期：2026-11-14。版本 V3.7.4 / versionCode 20271118，arm64-v8a，包名 com.osfans.trime.mie。正式发布标签 `v3.7.4`，安装包 `trime-mie-v3.7.4.apk`。经用户授权发布，保留 V3.7.2 撤回状态。

## 问题与修改

V3.7.3 为游戏补上了真实输入框，但场地仍使用 INPUT_METHOD_NOT_NEEDED 的独立 PopupWindow，可能排在输入法窗口上面，遮住候选浮窗。此前只检测 Rime hasMenu 并用空格选字，没有确认系统合成画面上的浮窗可见性。

移除游戏的独立弹窗，将场地直接放入游戏 Activity 的布局，位于输入框下层、输入法窗口后方；候选显示和触摸继续由原输入法处理。保留状态栏到输入框之间的全屏场地、键盘边界跟随、暂停、尺寸变化与攻击逻辑。只有尺寸或位置改变时才更新布局，退出移除场地并释放音效。
