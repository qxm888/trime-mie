# V3.2.4 更新说明

2026-11-03。正式包 `trime-mie-v3.2.4.apk`，包名 `com.osfans.trime.mie`，versionCode 20261229，ARM64，沿用原发布证书。

## 默认尺寸与绑定

内置非七列布局默认高度改为 **251dp**、行间距 **8dp**。升级更新旧 260dp/10dp 默认值，七列和其它自定义尺寸保留。取消 R 键双击输出日期；仅清理同一日期动作，其它双击功能不变。

## 五套新主题

霁银·柔光（珠光银白）、深空·钛影（钛灰冷光）、云汐·软屿（奶油软陶）、墨绒·格调（黑白织纹）、竹月·青釉（青瓷细边）。每套保留 26/9/14/18/两种七列、英文、数字及辅助页面，共 15 页。第二行居中，普通布局按既有 251dp/8dp 规格，七列保留原尺寸。

## 符号与注解

默认上方靠右、下方居中，各自新增横向、纵向内边距。数值越大越向键内收缩，允许 0–48dp；整套默认和单键覆盖均可设置。按实际字形及圆角计算可用区域，偏移也受边界限制。内置模板 V18 对五套新主题补齐未设置的默认值，保留其它编辑。

符号/表情面板的分类可长按拖动；单项点击“排序”后长按拖动，点击“完成”回到输入。顺序保存，支持重置，并进入整体备份。主题液态面板调序后仍按原分类 ID 打开内容。

主题按键编辑新增“长按滑选符号”，每行一个备选，或选常用符号组。长按弹出、滑动高亮、松手输入，支持完整 emoji；可关闭或恢复主题默认。该新增入口只对主题布局开放。

## 主题导入包

`BuiltinThemes-Individual-v3.2.4.zip` 为全部 14 套、210 页的单套包合集，包含图片与图标。解压后从咩版“键盘管理 → 更多 → 整套导入”任选一个 `.mie-keyboard.zip` 导入。

手机将 210 页一次合并导出时发生内存不足，因此本次提供单套合集，按需导入。

建议使用 V3.2.4 或更新咩版。导入生成独立自定义整套，原布局不会被覆盖；在自定义布局中选择使用。此为咩版整套格式，原版同文不支持这些美化扩展。
