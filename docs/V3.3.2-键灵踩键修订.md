# V3.3.2 键灵踩键修订（2026-11-05）

本说明取代上一轮《V3.3.2-UR动作与猴哥》的按键动作部分。版本仍为 V3.3.2 / 20270103，正式包 com.osfans.trime.mie；本轮只提供本地安装包。

## 本轮修改

- 所有迷你键盘伙伴统一用脚踩键，不再把手掌对准按键。键帽即时响应真实按下，角色随后起跳、收起另一只脚、落脚并轻压键帽。
- 左右脚交替，手臂在张手平衡、单侧举手、轻摆手三组动作间交替；小咩和猴哥继续使用各自的衣袖 / 护臂，不再使用通用猫爪按键。
- 小咩新增专用于迷你键盘的站立四表情图集，裙下可以看到向下伸展的腿和分开的鞋；收藏页素材不替换。运行时将腿部独立绘制，空中的另一只脚抬起。
- 其它矢量角色的迷你姿态替换原坐姿下半身，改为站立双腿和脚掌；保留头部、表情、纹样、背层与装扮。
- 脚底是模型变换原点。表情点头不再带着落脚点上下漂移，手臂动作不会改变踩键目标。左右脚切换时补偿身体位置，连续按键从当前位置接下一次跳跃。
- 同键重复按下也会重新跳；跳跃时长依据近期按键间隔收敛到 110–280ms，减少快速输入时来不及落地的情况。极快输入会合并到最近目标，不排队回放过时按键。
- 最后一次松键约 700ms 后跳回键盘上沿。清空布局、关闭窗口和退出输入时取消动画及回位任务；系统关闭动画时立即到位。
- 键盘底边统一为模型坐标 152；删除 UR 从 152 延伸到 186 的空白掌托。最后一行下方仅保留 6 单位内边距。
- 两侧添加透明的角色活动空间，并补偿窗口宽度，正常尺寸下键帽大小与原来接近。最左、最右按键的角色身体可以完整显示。

## 代码与素材

- `PetMiniKeyboardView.kt`：真实按键映射、跳跃时序、落脚点、压键与回位。
- `PetMiniStance.kt`：统一场景尺寸、脚底坐标、站姿腿脚与平衡手臂。
- `PetMiniPalette.kt` / `tools/generate_pet_standing_palette.py`：读取各角色身体原色用于新增肢体，避免误用亮色 UI 点缀色。
- `PetPortraitView.kt`：仅迷你键盘启用站姿，收藏页继续使用原姿态。
- `PetUrArtwork.kt`：四表情站姿图集注册、腿部分层；不在每一帧生成新位图。
- `PetUrRig.kt`：站姿肩部位置，保持固定长度完整衣袖。
- `PetCompanionController.kt`：紧凑窗口尺寸；保留拖动、缩放及横竖屏位置。
- `drawable-nodpi/pet_xiaomie_standing.png`：新增透明站立图集，内置 imagegen 编辑模式生成，原素材保留。
- `tools/pets/ur/小咩站姿生成记录.md`：输入、提示词与输出记录。
