# V3.1.17 悬浮球中英切换修复

## 原因与处理

悬浮球临时工具栏在创建时固定读取主键盘按钮，且默认按 `default` 读取。切换到英文次级键盘后，普通工具栏已使用英文键盘的返回绑定，悬浮球仍保留原先“前往英文”的动作，导致重复点击不能回中文。

- 键盘完成挂接时，同步通知候选悬浮球按明确的当前布局 ID 更新工具栏。
- 每次展开悬浮球工具栏时重新核对当前布局和按钮配置；同布局、同配置直接复用。
- 监听方案选项变化，刷新中英文字/图标状态；异步选项结果用代次校验，避免旧状态覆盖新按钮。
- 配色刷新同步重建悬浮工具栏外观。沿用原有中英来源布局记忆和返回动作。
