# V3.7.3 游戏真实输入修复

日期：2026-11-14。V3.7.3 / versionCode 20271117，arm64-v8a，包名 com.osfans.trime.mie。正式发布标签 `v3.7.3`，安装包 `trime-mie-v3.7.3.apk`。V3.7.2 保持撤回草稿，不再用于公开升级。

## 问题与修改

用户反馈全屏游戏中按键没有编码和候选。此前全屏窗口直接依赖被遮住的应用编辑器；原回归直接调用游戏上屏回调，未覆盖真实键盘焦点和候选链路。

现在从键灵菜单打开独立游戏页面，自带可见输入框并主动取得键盘焦点。全屏场地铺到游戏输入框上方，输入框按真实键盘与候选顶部定位。游戏内容只留在自己的编辑器，退出回到原应用。隐藏键盘暂停游戏，点击输入框重新唤起；区域变化沿用原有状态与剩余时间保持逻辑。

攻击从 Rime 底层提交回调移至输入服务成功写入游戏编辑器后触发，校验包名和编辑器 ID，一次选字只发射一次。保留原有统计/键灵引擎提交回调。修复单手模式已隐藏的编码视图仍加入边界，避免编码收起后错误移动输入框。

## 实机验证

PKX110 / Android16（API36），独立 Debug 包、合成编辑器及临时合成 Rime 方案；未使用用户聊天、词典或真实键灵存档。

- 普通、左单手、右单手均通过系统触屏注入实际 H 键，取得原始编码 h 与候选菜单，再触屏空格选字。
- 游戏可见输入框收到“的”，黄色小鸡发射1次、命中1次、加分1次，原编辑器合成草稿保持不变。
- 右单手带未提交编码退出，原草稿仍保持不变；游戏输入框与键盘不相互遮挡，画面不遮住输入框。
- 选关、通关解锁、旧第37关恢复、暂停/尺寸变化、普通圆球/小咩爱心/鸡哥小鸡、音效开关与资源释放回归通过。
- 测试后恢复原默认输入法和启用列表，卸载独立测试包。截图已人工检查。

此前测试工具的继承/委托属性读取与键盘容器坐标错误记录单独保留，不计为通过。最终真实输入日志和游戏回归日志为本次实机证据。

最终 Release 构建通过，85项相关单元测试全部通过（0失败、0错误、0跳过）。正式包使用原证书，签名与16KB ZIP对齐验证通过。本轮不重复验证用户反馈设备的 QQ 常用句，也未重跑全仓库 lintRelease；既有问题见 V3.7.1 记录。
