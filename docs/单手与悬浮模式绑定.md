# 单手与悬浮模式、整套尺寸更新

## 造词导出

“输入与候选 → 造词管理”列表上方直接提供“导出造词 · YAML / JSON / TXT”按钮，导出全部方案的已造词条。数据格式和导入规则沿用 V3.2.1。

## 模式绑定

进入“键盘 → 单手与悬浮键盘”，分别设置“单手键盘绑定方案与布局”和“悬浮键盘绑定方案与布局”。可以只绑定方案、只绑定布局，也可以二者同时绑定。

方案列表使用已经启用的方案；不触发部署。布局可选择内置或自定义整套中的具体页面；在传统主题模式下，也可绑定当前主题的布局。

例如单手模式绑定方案 A 与十四键：开启单手模式后切换到 A 和十四键，退出后恢复进入前的方案、布局和中英状态。单手切换为悬浮模式时，使用悬浮模式的绑定，最终退出后仍回到最初的键盘。横屏自动悬浮也使用悬浮模式绑定；单手在横屏不生效，按实际展示模式处理。

恢复点保存在应用偏好中，输入视图重建和服务重启不将绑定目标误记为原布局。无绑定时沿用原来的模式行为。配置已删除或方案未启用时提示失败、尝试恢复原键盘并记录诊断日志。

## 整套尺寸

“整套键盘 → 整套设置 → 尺寸与间距”包含竖屏总高度、横屏总高度、行间距和行左右边距。高度包含工具栏，0 表示自动/跟随原设置。独立页面优先，页面可按尺寸类别恢复跟随整套；尺寸也可按类别复制或保存为共用方案。

内置非七列模板采用 260dp 总高度、10dp 行距。七列模板不改默认尺寸；新建/补入七列页保留模板独立尺寸。升级迁移未指定高度以及旧 4/5dp 默认行距，已有其它自定义值保留。

## 英文功能继承与外观修正

同一套中的英文页按按键身份跟随中文二十六键的长按、滑动、双击等非点击功能，并跟随弹出备选及发送开关。英文点击输入、ASCII 和页面返回动作保留。英文页明确单独编辑的功能保存为覆盖；恢复跟随绑定时可重新继承。

英文继承基线与覆盖信息进入原布局 JSON/整套 ZIP，传统 YAML 导出也保存页面角色及对应继承信息。

角色强调色优先于旧的统一按键默认色，修正雾凇回车变浅。菜单窗口切换会结束前一动画、在挂接与动画结束后刷新背景和键盘；移除按压缩放及波纹残留，避免等到再次按键才恢复。

## 绑定复制、对齐与内置默认动作

整套绑定复制包含主标签文字、字号、偏移、前景图标，以及符号/注解的文字、字号、位置、显示开关和独立对齐。按键背景及配色保持目标设置。无法唯一匹配的按键保留，套内跳转仍重映射至目标整套。

“布局与切换行为”分别设置上方符号、下方注解的对齐，单键外观也可分别覆盖。旧布局缺少独立注解字段时保留原位置；通过编辑器保存后两项互不跟随。逗号与句号采用字形视觉居中，显式偏移仍有效，测量结果随字体/字号变化缓存刷新。

内置八种主要布局的默认动作来自用户提供的“雾凇·半透键盘.trime.yaml”。提取数据在 `app/src/main/res/raw/mie_builtin_bindings.json`，不依赖用户原文件路径或自定义功能 ID。“隐”“清空”以等效组合动作嵌入。所有内置配色使用同一动作模板，前景图标和底色仍属于各套。升级按旧默认字段比较，已修改绑定、符号和注解保留。

整套布局入口显示键盘内两列主布局按钮，不再弹出包含内部符号页、主题页的长列表；返回不切换当前主布局。

## 英文关联与刷新

布局选项编辑器保存符号、注解对齐时保留已有英文键盘关联。历史版本已保存为空的同套中文页，会查找同套英文页作为运行时回退；内置布局升级时补回有效的默认关联。

编辑页退出时的后台刷新等待主动主题/布局切换结束，按最新已提交模式刷新，避免旧刷新抢占新布局。
