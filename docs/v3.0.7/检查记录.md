# V3.0.7 构建与检查范围

## 代码检查

- 普通启动、updateConfig、daemon重新启动与进程重建使用无维护启动桥；只有显式deploy()路径调用原JNI完整部署。
- 备份恢复不再设置自动部署标记；遗留标记不被启动读取。
- 主题加载只读已有build；原生主题编译只由显式deploy()调用。
- 用户词典同步消息在native回调处标记操作来源；部署/同步等待器分别过滤，通知、日志清空及OpenCC重编不再响应同步消息。
- 启动桥仅使用公开版本化C API，保留原SO，注册部署/同步任务类型不执行任务；16KiB页面链接设置明确。

## 构建结果

构建结果与安装包签名、版本、Manifest及原JNI完整性记录随交付目录提供。新增桥源码、BSD头文件与许可证、构建入口均包含在源码归档中。

本轮没有运行自动化测试、手机输入法切换回归或关机开机验证，也没有安装或替换手机应用。构建成功和包元数据核对不等于真实设备行为验证。

方案列表保存和选择外部同步目录也不再自动部署；保存/导入完成后提示用户到设置菜单手动部署。
