## 构建

JDK21、Android SDK37、Build Tools36；本次 arm64-v8a，最低API21。源码归档包含预编译 JNI、Sherpa AAR、Gradle Wrapper JAR，不包含签名私钥和口令。原生依赖来源边界见 NATIVE_BUILD.md。

```bash
JAVA_HOME=/usr/lib/jvm/java-21-openjdk ANDROID_HOME=/opt/android-sdk \
  ./gradlew app:assembleDebug -PvariantTag=v2 -PbuildABI=arm64-v8a --max-workers=2 --console=plain
JAVA_HOME=/usr/lib/jvm/java-21-openjdk ANDROID_HOME=/opt/android-sdk \
  ./gradlew app:assembleRelease -PbuildABI=arm64-v8a --max-workers=2 --console=plain
```

正式构建需接手者配置原签名。生成 APK 后核对包名、版本、非 debuggable、ACCESS_LOCAL_NETWORK 声明、签名证书和 SHA256SUMS。不要用调试兼容开关代替正式运行时授权。

## 主要实现

- FloatingCandidateStyle / Renderer：布局独立配置与共享绘制；CustomKeyboards / CustomKeyboardYaml 保存和往返。
- FloatingCandidatesEditActivity / Preview：分组编辑、暂存、实时预览；未保存不修改布局。
- CandidatesView / LabeledCandidateItemUi / PaginationUi / PreeditUi：运行时背景、字体、布局与翻页。
- TouchEventReceiverWindow：裁剪球的输入窗口并转换坐标。InputBarVisibility / InputView / InputDeviceManager：临时显示策略与独立球开关。
- KeyView / KeyboardView / ToolButton：阴影失效、缓存位图所有权和动画同步。
- KeyReorder / CustomKeyboardEditActivity：插入移动、编辑位置跟踪、拖动。
- CandidatePreferences / CreatedWordsActivity / WordCreationActivity：旧版 aliases 列表、原子编辑、重复检测与管理入口；沿用候选备份格式。
- LocalNetworkAccess / ClipboardSync / ClipboardSyncActivity：SDK37 授权、地址检查、权限提示、同配置保存重试。
- Mie303Runner / Mie303LanRunner 仅出现在咩2，正式包没有 instrumentation。
