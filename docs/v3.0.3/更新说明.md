# V3.0.3 更新说明

正式版本 `V3.0.3 / 20261201`，正式文件 `trime-mie-v3.0.3.apk`。

## 自定义键盘的悬浮候选窗编辑

入口：键盘 → 布局管理与按键编辑 → 选择布局 → 右上角菜单 → 悬浮候选窗编辑。

每个布局独立保存，顶部提供实时预览和“保存”；下方分为窗口、候选、文字、辅助四页，各组参数使用折叠抽屉。退出未保存时可保存、放弃或继续编辑。

- 窗口：纯色、透明或图片背景，圆角、边框、整体透明度、宽度、内边距、投影、背景柔化。
- 材质：渐变、高光、磨砂颗粒、内阴影、渐变边框、立体底边。
- 候选：普通与高亮背景分别设置，候选留白、行距、投影，以及按下缩放、下沉、变暗和波纹。
- 文字：候选、注释、序号、编码分别选择字体与字号、普通与高亮颜色；可隐藏序号、注释、编码，设置候选文字阴影。
- 辅助：翻页按钮继承全局、上方集中或底部分开；箭头尺寸、颜色和背景；悬浮球尺寸、字符、颜色、背景与边框。
- 原有布局未保存此配置时继续继承原外观；关闭当前布局自定义外观也可恢复继承。设置进入 JSON、整包备份及 YAML 的 mie 元数据。单独 YAML 仍引用素材路径，跨设备使用整包备份携带图片和字体。

柔化只处理悬浮窗自身背景，不采集聊天内容；纯色背景上不明显。投影颜色需 Android 9+，旧系统使用系统投影色。未加入悬浮球背景模糊或浮窗视频背景。

## 美化残影和闪烁修复

- 阴影关闭时仍刷新旧阴影层；按键阴影超出单键边界时同时使父背景失效，清除旧帧。
- 工具栏投影随按下缩放、下沉及外观替换刷新，结束/取消动画时同步清理。
- 内外阴影缓存不再主动回收仍可能被 HWUI 显示列表使用的位图。
- 关闭按压特效前取消上一段动画，避免旧参数继续驱动新外观。
- 自定义布局编辑预览改为读取本布局的全体按键背景及自定义外观，避免误用主题键盘背景。
- 修正自定义默认候选背景与文字颜色混同、悬浮窗编辑首次预览为空白、图片异步加载后柔化未更新等问题。

保留按需模糊、背景参数和着色器缓存优化。本次处理了已定位的失效路径，特定皮肤、GPU及长时间输入仍需观察，不能据此保证所有显示异常均已覆盖。

## 悬浮球及悬浮键盘

悬浮球保持默认关闭，可随时独立开关，不再受“隐藏状态栏”限制。空闲球使用实际可见范围作为触摸窗口，不再留下候选窗大小的透明触摸层；候选、球和临时工具栏切换时移除旧触摸窗口，并正确转换触摸坐标，修复旁边 Q 键可能被拦截。

已隐藏状态栏时，进入悬浮键盘临时显示附着在键盘上的候选/状态栏；回到普通键盘恢复隐藏。只计算当前显示状态，不改写用户的隐藏开关。单手模式保留自身显示规则；用户主动开启的悬浮候选窗/悬浮球仍按其开关工作。

## 按键移动

移动后编辑框跟踪按键的新位置，再点确定/删除不再覆盖或删除原位置上的其他按键。长按结构区按键可拖动，同一行或跨行插入，支持空行和边缘滚动；拖动取消不改数据。按键宽度、素材、外观和所有绑定一起移动。

## 造词管理

新增 输入与候选 → 造词管理，可新建词条、查看所有已保存的应用内造词、搜索词条/编码/方案并按方案筛选。点击词条编辑文字、编码或所属方案，也可删除；删除仅移除应用内造词，不删除 Rime 原有词典。已保存的旧版造词直接从候选规则的 aliases 字段读取，无需重新添加。

编辑采用一次原子写入，同时更新旧编码和新编码，保留其他词条的顺序和隐藏规则；目标存在重复词条时拒绝覆盖。保存后重新输入相应编码即可参与候选。单字、词、句子、标点和 emoji 均可，词条上限1024字符，编码上限128且不能含空白。沿用候选调整 JSON 与整包备份；仍属于应用内候选扩展，不宣称已写入原生用户词典。

## Android 17 局域网剪贴板同步

正式与咩2共用 Manifest，均声明 ACCESS_LOCAL_NETWORK；API37 且 target37 时，在同步页面为局域网地址申请原生权限，并提供重新授权和应用权限入口。域名解析到私有 IPv4、IPv6 ULA 或链路本地地址时也检查权限。普通公网及旧系统保持原访问方式。

缺少权限时明确提示授权，日志记录权限状态和错误类型，不记录账号、密码或剪贴板正文。允许权限后重试；每次点“保存设置并重试连接”都会重启连接并重置退避，即使配置未变。重试相同配置保留尚未上传的内容与已接收标记；关闭自动同步不要求先授予局域网权限。

依据：[Android 官方本地网络权限文档](https://developer.android.com/privacy-and-security/local-network-permission)。只声明权限不够，须经系统运行时授权。
