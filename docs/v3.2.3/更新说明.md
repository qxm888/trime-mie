# V3.2.3 日夜配色组与键盘样式选择

## 更新

- 新增配色组管理，可为每组分别指定日间与夜间主题。传统主题、内置整套、自定义整套均可选择，支持新建、改名、编辑、启用、停用和删除。
- 启用配色组后，开启“跟随系统夜间切换”即可自动切换；关闭后使用日间主题。配色组设置纳入整体备份。
- 键盘样式和皮肤按钮共用新选择页：顶部“布局 / 配色”；布局下分“主题布局 / 内置布局 / 自定义布局”；配色只显示用户建好的组，未建立时为空。
- 浏览分类不改变当前键盘；手动选布局退出配色组。内置、自定义列表动态列出新增整套。
- 配色组切换按页面角色保留当前布局，并映射英文、数字页返回记忆；目标没有相应页时使用其默认页。
- 失效或已删除目标不替换当前键盘；过期选择不能覆盖新请求，锁屏前不自动加载用户配色组。

- 修复日夜切换和后台外观刷新时，英文/数字页被重置、旧键盘回调覆盖当前页面的问题。
- 修复内置句号仍使用旧的右上补偿偏移：现在按可见字形居中；升级同步清理内置旧默认值，保留不同的自定义偏移。
- 上方符号默认靠右，下方注解默认居中，两个位置独立；适用于新建布局及内置各次级布局，单键设置仍可覆盖。

## 入口

外观 → 主题与配色 → 配色组。为日间和夜间分别选择主题，保存后点组并启用。也可在工具栏皮肤按钮或菜单“键盘样式”的“配色”页启用已有组。

本功能切换完整主题/整套，不将一个主题的按键素材复制到另一个主题。传统主题跨主题时沿用目标主题的布局规则。
