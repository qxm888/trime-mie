# V3.2.3 源码交接

标签 v3.2.3，补丁基于 v3.2.2。正式包 trime-mie-v3.2.3.apk，versionCode 20261228，arm64-v8a，沿用原证书。

KeyboardColorGroups 保存日夜主题引用，ThemePrefs 的隐藏字符串偏好进入整包备份及开机偏好镜像。自动切换等待已有主题选择，锁屏前跳过；手动布局选择退出组模式，失败恢复组标记。ThemeManager.requireExact 在目标失效时不提交回退主题，在请求过期时取消，默认调用行为不变。

ThemePickerDialog 为皮肤、菜单、设置共用入口，增加布局/配色分段；pickTarget 仅选择编辑目标，不激活主题或改变浏览来源。KeyboardColorGroupsActivity 管理组。KeyboardWindow.restoreFamilyNavigation 只迁移新套合法页面 ID，不转移旧主题实例。

配色刷新保留当前英文/数字页与对应主页面，KeyboardWindow 的旧 owner 延迟回调不得改写当前页面/原生中英状态。KeyboardNightPolicy 对明确的系统日夜模式优先取 UiModeManager，自动模式才参考 configuration，避免配置更新的短暂旧值。

内置模板 V15 清理主句号的旧偏移 (5,-5)，BuiltinPunctuationDefaults 兼容已采用整套设置的键盘中记录的同一旧默认差异。仅匹配内置句号、点击 . 和旧默认成对偏移，不清空其它样式或不同偏移。KeyView 的按字形居中逻辑不变，真机用独立透明画布只绘制主标签、检查可见像素边界，防止上方符号干扰测量。符号/注解默认值独立，复制也保留各自选择。

ColorGroupsRunner 与 ModeBindingsRunner 仅在 debug 源集，正式包不含测试入口。构建见 BUILD.md；使用见 docs/日夜配色组.md。验证范围见检查记录，测试手机备份、私钥及登录凭据不进入发布附件。
