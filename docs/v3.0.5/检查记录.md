## 边界

这些检查验证转换模型、运行时动作表和保存格式，不等同于所有第三方主题的逐像素复刻或长期实打。多字体回退、九宫格拉伸、主题外侧留白和动态状态差异见更新说明。没有验证真实语音或剪贴板认证服务。
