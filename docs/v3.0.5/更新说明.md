# V3.0.5 主题键盘导入

正式版本 V3.0.5 / 20261203，正式包 trime-mie-v3.0.5.apk。

## 使用

设置 → 键盘 → 布局管理与按键编辑 → 从主题键盘导入。主题模式和自定义模式均可找到该按钮，右上角菜单也保留入口。

默认选择当前主题及当前可识别布局，否则选择 default 或首个布局。可以改选主题、布局和新键盘名称，再点“导入为新键盘”。生成完成后可选择“编辑新键盘”或“立即使用”。点“完成”保留生成结果，不切换当前键盘模式。

## 转换内容

- 行、按键宽度和高度、空白占位、符号与下方注解、弹出备选、字体字号、圆角、边框、常态及按下颜色。
- 点按、长按、双击、延迟双击、四向滑动、输入状态等绑定；主题动作别名和行内动作保存为独立动作。
- 宏中的主题动作引用使用独立命名空间，避免切到自定义模式后丢失或与其他导入结果冲突。
- 工具栏菜单及普通按钮、动态图标样式、背景、原生形状、尺寸和可编辑绑定。
- 原主题按键跳转需要的布局自动生成新的自定义布局，跳转改为新ID。因此一个主题可能生成主键盘和若干数字、符号等关联布局，完成提示会显示数量。
- 当前配色与主题模式美化设置作为快照保存，不再读取原主题。图片、视频和可用字体复制到独立素材目录，整包备份包含这些文件。JSON及咩版YAML元数据保留导入动作和工具栏模板。

每次导入都创建新ID，不覆盖已有自定义键盘。失败或取消时清理尚未提交的素材；最终布局整体保存。导入工作在后台完成。自定义键盘零横向键距也已修正，不再回退到默认4dp。

## 兼容边界

当前自定义模型不保留完整主题运行环境：自动关联英文／横屏键盘不启用，保留显式按键跳转；配色固定为导入时解析的配色，不随原主题自动切换。主题外侧留白、动态修饰键状态和部分主题级细节可能不同。液态键盘符号表、候选窗等主题其它区域不属于按键布局复制范围。

多字体回退链使用首个可用文件，缺字由系统回退；九宫格图片使用现有自定义背景缩放方式，拉伸细节可能不同。遇到这些情况完成提示会列出说明。缺失必需素材、无效布局或循环引用会明确报错。单素材上限128MB，整组素材上限512MB；最多128个关联布局。

整包备份可带走素材；单独YAML仍按文件路径引用素材，跨设备请使用整包备份或同时复制素材。
