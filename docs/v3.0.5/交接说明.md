## 实现

ThemeKeyboardImporter负责后台复制、布局分行、动作与宏命名空间、跳转依赖、配色解析、素材复制和原子提交。ThemeKeyboardImportDialog提供主题/布局/名称选择；管理页有直接按钮和菜单入口。

CustomKeyboard.importedActions保存宏依赖，standaloneTheme注入运行时；CustomKeyboardYaml保留该字段。ToolbarOverrides.Entry.template保存原生工具栏定义，用户编辑的动作、外观、尺寸等优先。绑定显示使用可读文字，避免把内部JSON显示给普通用户。

素材位于已有custom_kb_bg类别内的独立theme-UUID目录，继续纳入整包备份及路径重写。单独YAML不嵌入素材。导入失败不留下半份布局或素材。

## 构建与发布

JDK21、SDK37、Build Tools36，arm64-v8a，最低API21。源码含JNI、Sherpa AAR及Gradle Wrapper JAR；不含签名私钥或口令。原生依赖来源边界见 NATIVE_BUILD.md。

```bash
JAVA_HOME=/usr/lib/jvm/java-21-openjdk ANDROID_HOME=/opt/android-sdk \
  ./gradlew app:assembleDebug -PvariantTag=v2 -PbuildABI=arm64-v8a --max-workers=2 --console=plain
JAVA_HOME=/usr/lib/jvm/java-21-openjdk ANDROID_HOME=/opt/android-sdk \
  ./gradlew app:assembleRelease -PbuildABI=arm64-v8a --max-workers=2 --console=plain
```

正式构建配置原签名。发布前核对SHA256SUMS、包名版本、非debuggable、无instrumentation及ACCESS_LOCAL_NETWORK声明。同步README、CHANGELOG、docs/v3.0.5与必要二进制依赖。不要把有限的导入检查称为全部主题完全兼容。
