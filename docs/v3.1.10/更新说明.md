# V3.1.10 更新说明

2026-11-01，基于 V3.1.9 debf490。版本 V3.1.10 / 20261217，arm64-v8a。

## 使用

内置五色工具栏显示顺序：菜单 → 主题 → 布局 → 悬浮键盘 → **表情** → 中英文 → 剪贴板 → 收起。新增透明底灰色线条笑脸，148px 素材、18dp 显示，与现有图标一致。

表情与符号使用同一个滑动面板，顶部下拉选择分类，内容上下滑动，底部返回键盘、空格、删除、回车。点击完整条目直接输入；长按查看原字符及编码，可再次选择输入。组合附加符号用虚线圆辅助显示，实际输入不带辅助圆。

内置各符号入口和分类入口也接入完整面板。人物肤色组合独立成类，常用基本人物优先浏览；“全部 Emoji”仍包含所有条目。

## 覆盖与性能

41 类、11998 个不重复条目，包含 3972 个官方完整 Emoji 序列（Unicode Emoji 18.0 快照），不拆开肤色、连接符、旗帜等组合。保留旧库所有非 Emoji 条目，补充数学、箭头、几何、全角标点、序号、上下标、单位、货币、音乐、棋类、制表线、注音、假名、韩文字母、希腊和西里尔字母、国际音标等。

数据来自固定的 Unicode 官方文件及既有符号表，来源、许可和数量记录在 tools/data/unicode/。这不是 Unicode 全部文字库；新表情能否显示取决于手机字体与系统支持，库内存在条目不代表系统一定有对应图形。

旧生成器把分类限制在最多三页，“全 Emoji”只有前 114 项；现在取消分页截断，统一目录在打开面板时后台读取，RecyclerView 只创建可见格子。五色共享数据，新装内置布局 65 核心 + 10 辅助页，共 75 页。

## 升级

内置模板版本升至 8。在保留已有按键、外观、字体及用户工具栏设置的基础上插入表情入口、升级符号绑定。仅当旧分类页与随包旧模板完全一致时清理；编辑过的旧页面保留。旧自定义绑定引用已清理分类页时转入同一完整分类面板。

V3.1.9 的七列布局、多字体和主题增量刷新机制保留。完整部署仍只在用户手动选择时执行。本轮不上传 GitHub。
