# Trime Mie V3.0.2：输入性能优化

正式包 `trime-mie-v3.0.2.apk`，版本 `V3.0.2 / 20261130`。沿用 V3.0.1 的功能、图标及原生引擎。

## 按键与工具栏

原先每次绘制纯色按键都会再次设置圆角和边框，Android Drawable 随即要求宿主重画。现在参数不变时跳过设置，尺寸、颜色、按下状态和皮肤变化时正常更新。纯色圆角背景避免额外重复圆角裁切；图片、模糊及叠加效果继续保留裁切。

渐变、渐变边框、高光、3D底边与波纹复用着色器，动画仅更新矩阵或透明度；内外阴影避免每帧创建比较对象。工具栏背景也缓存高光和圆角路径。不启用外阴影时跳过阴影层遍历，不启用按压变换时不启动空动画。

普通按键无动态行为时跳过相关输入法状态查询；标签和点按动作在同一次调用内复用结果。字体名称列表按主题保存，降低重复绘制时分配。移除普通按键的两条逐键文字调试日志，保留慢触摸队列、语音生命周期和错误诊断。

## 候选刷新

候选内容、总数、排列和高亮都相同时，不再向列表提交相同数据。只有高亮改变时刷新旧、新高亮项；总数和布局改变继续重新计算。候选背景仅在高亮或配色改变时重建，字体和字号相同则保持原测量；修改字体或字号时明确使文字几何缓存失效。

## 背景模糊

静态图片、纯色背景只在背景、布局尺寸或重新显示后更新模糊。视频通过真实帧更新请求刷新，合并到既有约10Hz采样，不按每个按键单独捕获。键盘隐藏后停止捕获，重新附着时重新生成；切换背景、配色和布局会标记缓存过期。

## 范围与限制

本轮针对应用界面和按键处理路径，未修改 Rime 任务顺序、原生引擎或用户方案。没有通过丢弃按键、减少候选数量或关闭用户选择的外观来优化。复杂 Lua 方案、词典处理和设备GPU仍可能造成卡顿。

性能记录是同机隔离组件中的重复调用、刷新计数和缓存检查；不能据此宣称整段打字提速固定百分比。实际输入延迟和长时间打字表现还需用户使用常用方案观察。具体记录见检查记录及交付目录JSON。
