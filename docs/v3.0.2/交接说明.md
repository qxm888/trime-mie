Release单独配置原签名。源码包含构建所需JNI、Sherpa AAR及Wrapper JAR，不包含签名材料。原有来源限制见NATIVE_BUILD.md。

## 主要代码

- KeyBackgroundStyle / KeyView / KeyEffectShaders：避免重复背景设置，复用材质和路径；Key / KeyboardView减少状态查询和扫描。
- CandidateItemUi / CompactCandidateViewAdapter / AutoScaleTextView：候选复用与正确的文字样式失效；ThemeFonts复用主题字体名列表。
- BackdropBlur / VideoKeyboardBackground / InputView：按背景变化及视频帧更新共享模糊，配色和重新附着仍触发更新。
- SurfaceDrawable / ToolButton：复用高光和圆角，跳过空按压动画。
- BuiltInVoiceController：空闲取消不重复发布UI状态；正常会话结束仍恢复状态栏。
- Mie302Runner：隔离刷新计数与局部耗时，正式包不含此检查组件。
