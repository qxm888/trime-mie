# V3.0.2 检查记录

## 方法

按此前授权，仅使用咩2 `com.osfans.trime.debug.v2`，不切换系统默认输入法、不修改真实布局、方案、词典或统计。性能入口 Mie302Runner 使用生成的Drawable、局部候选视图及无输入框的临时页面，不采集用户输入。

- 原路径与缓存路径同机比较：2000次背景参数设置；检查回调次数，缓存后修改圆角和边框仍生效。
- 渐变重复创建与复用同机比较，固定尺寸下对象身份不变；尺寸和配置变化后重建，固定渐变像素与原路径一致。
- 1000次相同候选提交无列表通知；高亮、总数、布局、配色和文字样式改变正常生效。
- 静态模糊空闲700ms无重复捕获；背景变化重新捕获；100次连续请求合并刷新；重新附着后恢复捕获。
- 既有 Mie301Runner 覆盖空标签绑定保存、动作/字体转换、排列和YAML、阴影边界、腾讯协议、设置页。

## 边界

局部耗时为debug包微型测量，包含设备运行状态和JIT影响，不能当作打字延迟或全应用帧率。没有运行需要切换默认输入法的PerformanceRunner，没有模拟用户实际长时间输入，也未连接真实语音或剪贴板服务。多机型、特定复杂Lua方案、不同字体和皮肤需要继续覆盖。

最终测量值、日志、构建和安装状态见交付目录。
