# 36 位伙伴与表情互动

基于 V3.2.5-2 的本地功能扩充。来源为用户放在 `output/键灵小屋-20261104/pets/` 的 GLM 设计；保留原 12 位，合入新 24 位，素材原目录不改写。视频只作交互和画风参考，不提取其中宠物。

## 使用

1. 设置 → 便捷功能 → 键灵小屋，领养或选择伙伴。
2. 图鉴已扩为 36 位，可筛选全部 / 普通 / 稀有 / SR / SSR。新伙伴进入常驻孵化池。
3. 小屋里的“挥爪、比心、逗逗它”随时可玩，不消耗键元，也不增加每日摸摸奖励次数。
4. 开启迷你键盘陪伴，真实按键仍对应小键帽和左右爪；轻点上方宠物互动，点按下方迷你键盘或长按小窗打开菜单。
5. 菜单新增“逗逗它、比个心、挥爪打招呼”，原拖动、缩放、横竖屏位置记忆继续可用。

## 表情和动作

- 五官独立绘制：乖巧、微笑、眨眼、专注、惊讶、开心、吐舌、爱心眼、困倦。
- 打字依次切换表情，物种拥有不同起始顺序；回车偏开心，退格偏专注 / 惊讶，空格偏眨眼 / 微笑。
- 点头、歪头、后层耳朵 / 尾巴摆动、扭身、伸展、轻跳、轻摆与双爪分开控制，手动互动增加挥爪、合爪、拍爪和举爪。
- 选中伙伴成功使用食物 / 玩具或进化后，在小屋中分别出现吃东西 / 开心玩耍 / 庆祝动作。
- 迷你键盘连续按 5 次后停约 1.8 秒，播放一次伸展哈欠。继续打字会取消待播放动作。
- 动作有限时，不循环空闲刷新；键位与爪子立即响应，表情最多约每 270ms 更换一次。关闭系统动画时只短暂切换静态表情。

| 品质 | 数量 | 基础品质概率 |

| 普通 | 15 | 60% |
| 稀有 | 9 | 28% |

同一品质内均匀抽取。沿用 10 次 SR、50 次 SSR 保底；重复伙伴按品质转为碎片。旧 ID、等级、装扮、键元、物品、每日计数和保底不清空。存档数量上限由图鉴大小决定，整包备份 / 恢复自动包含新增伙伴。

## 素材与后续制作

- 原始设计副本：`tools/pets/source/svg/` 和 `tools/pets/source/species.json`；记录输入的形状、颜色、名称、稀有度和描述。
- 生成器：`python3 tools/generate_pet_art.py`，只读 SVG 路径与 JSON，不执行来源目录程序。无需联网。
- 生成结果：每个物种 `tools/pets/{id}.svg`，以及 `app/src/main/res/drawable/pet_{id}.xml`、`pet_{id}_back.xml`、`pet_{id}_body.xml`；另生成 `PetArtwork.kt` 明确资源引用供 R8 保留。
- 一致画风：柔和三段渐变、彩色轮廓、眼睛高光、暖色腮红和细线；涂山额外改为九尾扇形及狐耳，保留金色、名称和额心宝石。
- 后层容纳耳朵、尾巴、角，身体保留皮毛斑纹、鸟喙和特殊鼻子；眼睛、鼻孔及嘴由 `PetPortraitView` 绘制，不在动画层保留第二套静态五官。
- 蛙类眼睛位置单独适配；鸟喙、猪牛口鼻及考拉鼻子保留识别特征。羊毛、鹿角等后层小幅摆动，避免破坏轮廓。
- 新增物种需同时更新 source JSON / SVG、`PetCatalog.species` 和必要的五官特例，再生成资源；图鉴数量、筛选、各品质抽取与存档上限从 Catalog 自动读取。
- `tools/pets/catalog.svg` 为全图鉴素材预览，`expressions.svg` 为静态表情示意；它们不是手机截图。

## 性能和边界

- 同一物种的矢量和眼睛着色器在绑定时加载，不在绘制帧解析 SVG 或访问文件。
- 动画使用独立有限轨道；切主题、换布局、关闭输入或销毁窗口时清除按键、动画及回调。
- 计奖继续只记录数量；表情只消费按键身份与码值，不存储用户输入内容，也不发起网络请求。
- 本轮执行 Kotlin 编译及原签名 Release 构建，没有运行自动测试、安装或真机检查。构建通过不代表已实测窗口、连续按键和 36 种伙伴的全部动画。
