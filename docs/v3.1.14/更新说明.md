# V3.1.14 更新说明

## 自定义键盘全局字体

入口：**自定义键盘 → 编辑 → 字体与字号（当前布局） → 当前键盘全局字体**。

全局默认值为“系统当前字体”，跟随手机系统字体，不写死某个字体文件。支持选择多个字体及排列补字顺序，也可显式选择“系统当前字体”。各位置仍可单独指定字体和字号。

字体优先级：**单项指定 → 当前布局全局字体 → 主键盘全局字体（次级键盘继承）→ 系统当前字体**。字号仍由各项设置决定。每个布局分别保存；导出 YAML、整包备份及恢复包含全局字体。键盘编辑里的“恢复默认”清空本布局字体设置，主键盘回到系统字体，次级布局回到继承。

## 雾凇·半透

新增第四套完整特效键盘“雾凇·半透”：低饱和雾蓝背景，半透明键面、细描边、轻量磨砂与短促按压反馈。包含英文、数字、九键、十八键、两种七列等共 15 个主/次级布局。

工具栏与键盘默认共用背景，浮动候选窗使用同色系浅底，保留阅读对比。磨砂使用现有低分辨率背景采样并共享结果，静态背景不持续动画。不模糊文字或图标。

内置图片补齐到 `rime/.mie/键盘背景/backgrounds/frost.png`，布局保存相对素材路径，目录移动和整包恢复无需写死设备路径；原文件存在时不覆盖。内置模板升级到 V10，现有用户编辑设置保留，只补充新布局。需要手动找回时可使用内置键盘恢复入口。

四套特效键盘共 60 个布局，五色及扩展共 75 个，合计 135 个。设计预览由模板生成，**不是手机截图**；已在 .33 手机的咩2中检查图片加载、共享磨砂和字体优先级，实际截图随交付包提供。

## 横屏布局

入口：**键盘 → 横屏布局**。一套设置统一应用所有主题键盘与自定义键盘。

- 开启“独立设置横屏尺寸”后生效，默认关闭以保留原尺寸行为。
- 宽度为屏幕宽度的 40–100%，初始值 70%。
- 按键区高度为屏幕高度的 20–70%，初始值 40%；工具栏、手柄及系统边距另计。超出实际可用空间时自动压到安全高度，避免与工具栏或系统底部区域重叠。
- 左右位置 0 为靠左、50 为居中、100 为靠右。
- 实际横屏时适用，停靠与悬浮呈现均可；不随“强制横屏布局”误改竖屏尺寸。
- 横屏悬浮拖动、缩放写回横屏参数；竖屏悬浮参数保留。独立横屏尺寸下宽高分别调整，不使用竖屏“保持比例”。

横屏布局模式、空格分割选项仍在同一页的折叠分组中。

实测发现横屏 70% 高度时停靠按键区与工具栏、底部各重叠约 25px。已根据实测 InputView 高度、工具栏、底部留白、导航边距计算高度上限，并烘焙到按键几何。普通高度不重建视图，只有确实超过上限才刷新按键；移除旧视图时取消延迟回调。修复后主题/自定义、停靠/悬浮四种组合复测通过。
