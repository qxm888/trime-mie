# V3.3.0 更新说明

## 典藏 20 位伙伴（图鉴扩至 56 位）

- 珍奇 SR：雪鸮、银霜、青珮、踏雪、朱砂、星屑、岚烟、琥珀、珠露、紫电
- 星耀 SSR：夜阑、烛龙、冰璃、雷霄、幽萤、玄武、白泽、沧溟、曜金、梦泽
- 精修渐变画风：体积渐变、白色边缘光、发光纹饰与瞳孔、金饰、光斑粒子与脚下光池；每位虹膜配色专属。
- 与基础批共用同一套分层与代码脸规范：打字随机表情（乖巧/微笑/眨眼/专注/惊讶/开心/吐舌/比心/犯困）、视线追踪、点头/歪头/抖耳/扭身/伸懒腰/蹦跳/摇摆动作；摸摸、喂食、玩具、升级各有专属反应。
- 物种旗标：喙类（曜金/紫电/踏雪/雪鸮）、短鼻（梦泽）、獠牙（烛龙）、龅牙（星屑）。
- 孵化概率与保底逻辑不变，池子按稀有度自动扩大；原存档完全兼容。

## 商店兑换口

- 商店页新增「兑换口」卡片：输入兑换码并确认后，从全图鉴任选一位伙伴直接带回家，并设为陪伴伙伴。
- 每个存档限用一次；选择已拥有的伙伴会转化为同名碎片 ×20；兑换写入键元账本并纳入整包备份/恢复。
