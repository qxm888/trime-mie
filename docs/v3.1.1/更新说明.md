# V3.1.1 更新说明

本版是 V3.1 的修复版，不新增界面功能，集中解决真机使用中暴露的五个问题，并顺带修复一处闪退与一处后台耗电。

## 修复清单

1. **开启悬浮球后切换候选栏模式不生效**
   - 原因：偏好系统的枚举型工厂 `PreferenceDelegateOwner.serializable()` 没有像整型/布尔/字符串那样注册变更监听，
     `candidates.mode` 改变后候选视图不会重建，悬浮球状态停留在旧模式。
   - 修复：补上注册。所有枚举偏好（候选模式、内嵌预编辑模式、单手侧、横屏模式、候选位置、存储模式、应用深浅色）一并恢复变更通知。
   - 实测：切到“禁用”球立即消失，切回“始终显示”立即恢复。

2. **修改主题后刷新不了效果（切换主题、部署都不生效）**
   - 原因：V3.0.7 改为手动部署后，主题只读 librime 编译产物；而产物是否重建由 librime 比较源文件 mtime 决定。
     不少编辑器/同步软件保存时保留修改时间，librime 判定“文件未变”就永远不重编。
   - 修复：
     - 切换主题（含重选当前主题）：先把源文件标记为已修改，再强制重编译，恢复 V3.0.6 的“切一下就生效”。
     - 刷新当前主题：同样强制重建。
     - 手动部署：在维护开始**之前**标记全部主题源文件，保证部署一定重编译。
     - 兜底：直接编译失败时自动改走完整维护，完成后刷新键盘；切换时引擎未就绪则记录待重建，键盘下次弹出自动补齐。
   - 实测：保留 mtime 的改动在切换、刷新、部署、键盘弹出四条路径下均能编译生效。

3. **部署失败导致应用闪退**
   - 部署（引擎被占用或维护出错）抛出的异常原先无人捕获，会直接结束进程。
   - 设置菜单部署、广播部署、键盘命令部署三处改为捕获异常并提示失败。

4. **按键上方符号对齐**
   - 靠左/靠右不再贴边，留 4dp 间距。
   - 自定义键盘每个按键可单独设置符号对齐（跟随全局/靠左/居中/靠右），优先级高于键盘级设置，随 YAML 导出导入。

5. **自定义键盘行边距只在一侧生效**
   - 原实现只收窄右侧，左侧仍为 0；现在左右两侧同时收进，背景仍铺满不动。
   - 行编辑器“行高 / 边距 / 排列”三个按钮文案缩短为单行，不再被裁掉第二行。

## 性能与耗电

- 剪贴板同步：开启后不再在键盘收起时每 5 秒轮询服务器，只在键盘可见时同步；本地剪贴板上传仍为事件驱动。
- 输入统计：关闭开关后的保存循环隐患修复（`syncEnabled` 复用安全的开关路径）。
