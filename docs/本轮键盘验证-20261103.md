## 修复原因

1. 对齐编辑器保存时曾清空 asciiKeyboard / landscapeKeyboard，导致改符号后无法进入英文页。现保留两者；历史空英文关联按同套英文页回退，内置模板迁移补回有效关联。
2. 旧统一底色优先于角色样式，导致雾凇回车、樱花粉功能键强调色丢失。现由角色样式覆盖旧统一默认色，仍保留页面/单键显式覆盖。
3. 编辑页退出后的异步刷新可能抢占主动主题切换。现等待主动切换提交后，使用最新模式刷新。
4. 整套布局入口改回键盘内两列按钮页，过滤英文、数字、符号等内部辅助页；修正按钮高度单位，避免标签裁切。
