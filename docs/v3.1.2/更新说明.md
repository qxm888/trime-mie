# V3.1.2 更新说明

本版新增“按键级锁定态颜色”：自定义键盘可以让单个按键在锁定状态（长按大写、双击 Shift 锁定、Caps Lock）下换成另一套背景/文字/边框颜色。

## 背景

自定义键盘模式只有一份内置色板（`StandaloneKeyboardTheme.base()`），YAML 里既没有按键级 `on_*` 色字段，也改不了色板；`Key.getTextColor()` 在自定义键盘下更是直接跳过 on 态文字色。所以此前“锁大写变强调色”只能靠主题色板，自定义键盘做不到。

## 新增字段

按键外观（`appearance` / 主题 YAML 按键）新增三个字段，和现有颜色字段同级：

| 字段 | YAML 名（自定义键盘 / 主题 YAML） | 说明 |
| --- | --- | --- |
| `keyOnTextColor` | `key_on_text_color` | 锁定态文字/图标颜色 |
| `keyOnBackColor` | `key_on_back_color` | 锁定态背景颜色或图片 |
| `keyOnBorderColor` | `key_on_border_color` | 锁定态边框颜色 |

留空 = 继续用色板的 `on_key_*` 颜色（主题键盘行为不变）。

## 生效规则

- 只在**锁定态**（`Key.isOn`：长按大写、双击 Shift 锁定、Caps Lock）生效；单击一次性 Shift 不变色。
- 自定义键盘在未设置锁定色时，锁定态保持按键自身背景，不再套用内置色板的浅灰 `on_key_back_color`。
- 设置 `keyOnTextColor` 后，前景图标（PNG）也会按该颜色着色，便于“深绿底 + 白色箭头”。
- 编辑器：按键外观里新增“锁定态颜色（长按大写等）”分组，背景色字段沿用颜色/图片选择器。
- YAML 导入导出、按键外观合并、主题 YAML（SnakeCase）同步支持。

## 五色方案键盘

`output/keyboard-mint/gen_kb_yaml.py` 生成的薄荷绿五色方案，Shift 键自动带上各自方案的回车强调色与白色图标：

```yaml
- label: ""
  click: "Shift_L"
  key_back_color: "#E2F2E7"
  icon: "icons/mint_shift.png"
  key_on_back_color: "#72C99B"
  key_on_text_color: "#FFFFFF"
```

## 验证

- JVM：`MintKeyboardYamlTest` 校验新字段解码、外观合并到 `TextKey`、导出文本映射与解析往返。
- 真机：等 .33 解锁后按“单击 Shift 不变色 / 长按锁大写变绿且箭头转白”复验。

## 本轮追加（菜单、候选菜单、状态栏规则、内置键盘）

1. **键盘菜单页**
   - “悬浮候选栏”切换后自动返回键盘，并提示“候选栏已开启/已关闭”，不再停留在菜单页看不出变化。
   - 新增“浮动球”开关（菜单页直接开/关悬浮球，带提示并返回键盘）。
   - “隐藏状态栏”同样返回键盘；停靠模式下会提示“停靠模式不隐藏状态栏，切换到悬浮键盘后生效”。

2. **长按候选菜单精简**
   - 改为：调至首位、调至次位、调至三位、上移一位、下移一位、造词编码、忘记候选、删除候选、恢复默认；
     设置开启“长按菜单允许完整显示”时额外保留“完整显示”。

3. **状态栏硬性规则**
   - 停靠的候选栏模式**不再允许隐藏状态栏**；只有悬浮窗模式（含单手、横屏自动悬浮）可以隐藏。
   - 旧行为（悬浮时临时恢复状态栏）取消。

4. **内置五色键盘（默认樱花粉）**
   - 五色方案（薄荷绿 / 樱花粉 / 浅天蓝 / 杏子橙 / 薰衣紫）内置进应用：首次安装自动写入并切到“自定义布局”，默认使用**樱花粉**；
     图标（Shift/退格/回车/工具栏）随首次启动解压到 `.mie/键盘背景/icons`，已存在的不覆盖。
   - 移除内置“同文风”主题：安装后不再显示“标准”主题；用户自己放在 rime 目录的 `tongwenfeng.trime.yaml` 不会被删除。
   - 没有可用主题时用独立键盘外观兜底，不再抛异常导致设置页/键盘无法显示。
   - 工具栏图标支持相对路径（相对 `.mie/键盘背景`），官方五色 YAML 与内置版本都使用相对路径，换机不用改。

> 注意：内置键盘只在**全新安装**（无 `custom_keyboards.json`）时播种，已有用户的自定义键盘与选择保持不变。
