# V3.0.8 检查记录

日期：2026-10-30。基线：V3.0.7（源码归档提交 294ba4d7，versionCode 20261205，手动部署与新启动桥）。

## 合并与构建

- 本批功能基于 V3.0.5 工作树开发，逐文件并入 V3.0.7；唯一双方都改过的文件 `CustomKeyboards.kt` 经三方合并，无冲突。
- JDK21、SDK37、NDK 28.0.13004108、CMake 3.22.1、arm64-v8a；启动桥由 Gradle 自动编译，原 librime_jni.so 字节未改动。

## 功能实测（咩2/测试包，2026-10-30）

1. 键盘高度：编辑器显示“键盘高度：自动 N dp”，改为 360 dp 后按钮与预览同步，状态栏包含在总高度内。
2. 状态栏高度：状态栏编辑页默认 44 dp，改为 56 dp 后运行时状态栏变高。
3. 图片剪裁：导入 2400×1600 测试图，剪裁框比例正确，拖动后剪裁，背景立即变为剪裁区域。
4. 次级键盘：新建“shuzi”后主列表不显示，次级键盘页可管理。
5. 主题键盘悬浮窗美化：设置 #DDE8CC 后悬浮卡片变绿。
6. 主题键盘悬浮候选窗编辑：入口可进入完整编辑器，样式写入 `theme_floating_candidates` 并持久化。
7. 夜间配色：夜间打开配色选择器不再闪退，选择“碧水/Aqua”后重新打开保持。
8. 小屏：`wm size 720x1600` + `wm density 320` 下外观对话框三页签完整显示“按键 / 工具栏 / 整体”。
9. 验证中发现数值输入框会被系统自动填充回填旧值，已对键盘高度、行高、行间距等数值框禁用自动填充。
10. 主题重复：外部目录与内置资源各有一份同 ID 主题导致“标准/預設”重复。已按 ID 去重，删除内置“預設”，默认主题改为“标准”，旧选择自动迁移；实测主题列表只剩一份“标准”。

## 范围与限制

- 本轮未对 V3.0.7 的手动部署路径做完整实机回归（首次安装部署、杀进程重建、主题切换、用户词典同步），沿用其交付说明的边界。
- 图片剪裁的视觉细节、悬浮窗素材边框等仅检查了代表性用例；主题键盘悬浮候选窗样式为全主题共用一份。
