# V3.0.8 更新说明

正式版本 V3.0.8 / 20261206。沿用 V3.0.7 的手动部署行为：普通启动只加载已有部署结果，首次安装、修改方案词典或恢复数据后需在设置右上角菜单手动“部署”。

## 键盘高度改为直接设置 dp

自定义键盘编辑页“整体实时预览”上方新增“键盘高度”，与行高设置一致，直接填写 dp（80–800，留空自动）。

- 填写后为**状态栏 + 键区的总高度**，各行行高按比例缩放填充；横屏可单独设置。
- 留空时按行高之和自动计算；从主题键盘导入、原先使用百分比高度的键盘继续沿用原比例并显示为自动。
- 整体实时预览顶部加入状态栏示意条，预览高度与运行时一致。

## 状态栏高度

自定义键盘的状态栏编辑页新增“状态栏高度”（24–120 dp，留空使用主题默认 44 dp）。键区高度自动让出状态栏，总高度保持为设定的键盘高度。

## 导入图片实时剪裁

自定义键盘导入键盘背景图片时，选图后弹出剪裁窗口：

- 剪裁框按当前键盘比例（屏宽 : 键盘高度）生成，拖动选择位置，右下角圆点按比例缩放。
- 剪裁结果直接作为键盘背景，运行时按居中裁切铺满键盘，所见即所得。
- 可“使用原图”跳过剪裁；取消会清理临时文件。

## 次级键盘分组

一套自定义键盘可以带多张跳转用键盘（数字、符号等），主界面只显示主键盘：

- 点键盘 →“次级键盘…”进入该套键盘的次级键盘管理页，可新建、编辑、重命名、删除。
- 主键盘删除时其次级键盘一并删除；从主题键盘导入产生的关联布局自动归为该主键盘的次级键盘。

## 主题键盘悬浮窗美化与悬浮候选窗编辑

- 主题键盘 · 外观 → 整体 新增“悬浮窗美化”：可给悬浮键盘设置背景颜色、透明或图片，以及边框颜色与粗细；留空跟随主题键背色。
- 悬浮候选窗编辑同步支持主题键盘：设置 → 输入与候选 → 悬浮候选窗 → 悬浮候选窗编辑，主题模式下可像自定义键盘一样编辑面板背景、圆角、边框、渐变材质、尺寸留白、投影、候选文字与颜色等。主题键盘共用一份样式；自定义键盘仍按布局分别保存。

## 修复

- 夜间模式下打开配色/主题选择器会闪退的问题（缺少名称的配色导致列表渲染异常）。夜间选择配色现在会单独记住，不再被配色自带的明暗链接覆盖。
- 自定义键盘模式下隐藏无意义的主题/配色全局设置行。
- 小屏手机上键盘全局外观对话框的“工具栏”页签被截成“工…”的问题。
- 数值输入框（键盘高度、行高、行间距等）关闭系统自动填充，避免对话框被旧值回填。
- 内置主题只保留“标准”（tongwenfeng），移除“預設”（trime）并作为默认内置主题；主题列表按 ID 去重，外部目录与内置资源同名时不再重复显示。
- 候选视图重建时键盘尚未挂载导致的 `No keyboard is attached` 崩溃。
