# V3.1.15 更新说明

## 返回原布局

内置数字页、布局页、主题页等“返回”原来写死了该颜色的 26 键。现在使用 `Keyboard_default` 返回最近选中的主布局；26/9/14/18 键及两种七列均保留。布局列表中显式点击“26键”仍切换到 26 键。中英返回来源布局记忆继续保留，主题模式 `.default` 语义不变，不恢复曾导致 Q 数字页返回失效的锁定逻辑。

## 复制绑定

入口：**自定义键盘 → 编辑目标键盘 → 从其它键盘复制绑定**。

选择来源后预览可匹配/跳过数量，再点击“复制”。按相同点击动作或唯一标签匹配，不按行列覆盖位置，所以 A 键盘长按 C 的粘贴可复制到 B 键盘的 C。复制全部手势、弹出备选与发送绑定开关，并携带来源的主题动作定义；目标背景、字体、宽度、行与外观保留。空占位键跳过，歧义键不猜测；已有同名但不同定义的主题动作会报错。本次复制后两套键盘仍独立，不建立持续同步关系。

## 主题功能菜单

主题模式的工具栏功能菜单也增加标题栏编辑按钮。“主题键盘状态栏 → 功能菜单显示项目”同样可编辑。按主题 ID 保存，和自定义布局、其它主题互不影响。支持内置功能与当前方案开关，并可全部显示；设置在工具栏状态文件中，随整包备份恢复。

## 主题字体与上标

没有声明字体的主题继续使用系统当前字体，`rime/fonts` 中任意文件不会自动顶替为主字体。声明的主题字体继续优先，目录字体只在已声明字体之后补缺字。用户主动设置的主题全局/单项字体不清空，更新不会改写主题文件。

对照用户项目里的原版 `drawSymbol`：上标基线和 YAML 偏移算法一致。本轮不添加统一下移偏移，修正可能改变字体度量与位置的字体回退路径。没有截图作者的实际主题与字体文件，不能保证逐像素复现该第三方主题；用户已确认按现有代码大致排查即可。

## 九主题入口与长页

五色及月白·瓷光、曜石·微光、暮金·缎光、雾凇·半透均加入各套内置主题选择页。全新/未修改页为三列；用户编辑过的旧页保留原项目并追加四套新主题。修复竖屏长页面误按屏幕短边限制高度、最后一行无法点击的问题；横屏原有安全限制保留。
