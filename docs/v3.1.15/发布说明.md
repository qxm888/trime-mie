# V3.1.15 · 布局返回、绑定复制与主题兼容

## 更新内容

- 修复数字页、布局页和主题页“返回”总回到 26 键的问题：保留最近使用的 26/9/14/18 键和两种七列布局，中英切换返回记忆继续有效。
- 自定义键盘新增“从其它键盘复制绑定”。按相同按键匹配，复制点击、长按、滑动、弹出备选和绑定发送开关，保留目标布局与外观；复制为一次性操作。
- 主题键盘支持编辑功能菜单的显示项目，按主题独立保存。
- 修复未指定字体的主题被 fonts 目录字体替换的问题，保留系统默认或主题指定的字体。沿用原版上标绘制算法，修正可能改变字形度量的回退路径。
- 内置主题选择入口补齐九套键盘，修复竖屏较长选择页最后一行被裁切的问题。已编辑的旧页面保留原项目并补充新主题。
