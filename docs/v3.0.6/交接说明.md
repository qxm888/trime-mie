## 实现

BootStorage/storageContext集中处理直接启动与上下文归属，数据/语音模块的init使用它；AppContext按启动阶段取上下文。TrimeApplication、DirectExternalStorage、UserDataManager和DataManager分别处理解锁前目录、引擎路径、存储门禁和每个资源根的校验。

BackgroundSyncWork及Application调度入口都延后锁定阶段的任务，WorkManager初始化幂等；CrashJournal同步保存有限异常，LogView导出历史崩溃；DiagnosticLog同时导出正常和直接启动的日志。未更改JNI、依赖版本或用户目录设置。

## 构建/发布

JDK21，SDK37，Build Tools36，arm64-v8a，最低API21。源码包含预编译JNI、Sherpa AAR和Gradle Wrapper，不含签名私钥或口令；原生来源边界见NATIVE_BUILD.md。

```bash
JAVA_HOME=/usr/lib/jvm/java-21-openjdk ANDROID_HOME=/opt/android-sdk \
  ./gradlew app:assembleDebug -PvariantTag=v2 -PbuildABI=arm64-v8a --max-workers=2 --console=plain
JAVA_HOME=/usr/lib/jvm/java-21-openjdk ANDROID_HOME=/opt/android-sdk \
  ./gradlew app:assembleRelease -PbuildABI=arm64-v8a --max-workers=2 --console=plain
```

正式版需配置原签名。核对SHA256SUMS、包名版本、非debuggable、无instrumentation及ACCESS_LOCAL_NETWORK声明，同步README、CHANGELOG及docs/v3.0.6。不得把隔离DE上下文检查写成实际整机重启通过。手机正式应用未替换；源码构建提交和归档提交见校验与先读我。
