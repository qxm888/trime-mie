# V2.0.19 更新说明

## 按键与状态栏统一外观

设置 → 键盘 → **按键与状态栏外观**。自定义键盘编辑页面菜单也可进入。

四组折叠抽屉：

1. **按键**：纯色 / 透明 / 图片背景，边框粗细与颜色、圆角、动态模糊。
2. **状态栏图标**：独立设置背景、边框、圆角和模糊；可开启“跟随按键外观”统一设置，关闭后保留原独立样式。
3. **整条状态栏**：独立背景及动态模糊开关。
4. **磨砂效果**：模糊强度 2–32dp、背景叠加强度 0–100%。

所有选项在点击“应用”后保存；取消不保存，支持恢复默认。主题键盘和自定义键盘均生效，不改写主题文件或单键定义。

## 动态磨砂背景

模糊采样输入法自身的背景图片 / 视频，文字和图标保持清晰。希望状态栏与按键使用同一张完整底图时，可同时开启“状态栏与键盘共用背景”。背景叠加强度越低，磨砂层越通透；选择透明背景可突出下方画面。

动态模糊默认关闭。所有按键和状态栏共用一份低分辨率背景采样，像素模糊在后台处理并复用缓冲区，刷新上限约 10 次/秒；键盘不可见时停止采样，全部关闭后不创建采样器。不会把文字或图标一起模糊。
