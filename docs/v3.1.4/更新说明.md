# V3.1.4 更新说明

修复内置五色键盘的工具栏图标不显示。

## 问题

内置键盘的工具栏图标之前写的是绝对路径
`/storage/emulated/0/rime-mie/.mie/键盘背景/icons/tb_*.png`。
只有数据目录正好是那个路径的机器才能显示，其他用户（尤其是把 rime 目录换到
`/sdcard/rime`、`/sdcard/rime-v3081` 等位置的）工具栏只能回退成文字标签。

## 修复

- **工具栏图标改为相对路径**：统一写 `icons/tb_*.png`，由 App 按当前生效的数据目录解析
  （直接外部存储时是 `<用户选择的目录>/.mie/键盘背景/icons`，应用存储时是
  `filesDir/custom_kb_bg/icons`）。按键图标本来就走相对路径，这次工具栏与它们一致。
- **旧数据自动刷新**：内置键盘版本号 `builtinVersion` 2 → 3，升级后自动替换内置键盘
  （只替换内置 id，自建键盘不动），把绝对路径换成相对路径。
- **图标补解压**：图标解压标记存在但关键文件缺失时会重新解压一次，避免早期解压失败后一直缺图。

## 说明

用户自己导入的 YAML 也可以直接用相对路径：`icon: icons/xxx.png` 会相对
`<数据目录>/.mie/键盘背景` 解析；需要固定位置时仍可用绝对路径。
