# V3.7.8 更新与验证

2026-11-15 经用户授权正式发布，标签 `v3.7.8`。V3.7.6 / V3.7.7 本地修复一并收录。

## 来源

对照 [BiBi Keyboard / 说点啥](https://github.com/BryceWG/BiBi-Keyboard) 正式版 4.6.1，并固定上游 2026-11-14 提交 `271f77786bdae6aa6b40bc9a3c76293821745c2b`。该提交包含正式版之后的 ElevenLabs v3 更新。源码、模型元数据与许可证均来自上游公开部分。

## 已同步

- 新增阿里千问非流式语音识别：Qwen-Audio 3.1 / 3.0、Qwen3-ASR、Fun-ASR 和 Omni；支持大陆、国际、自定义主机，以及 3.1 的方言保留和口语整理。
- 新增 DeepSeek 文件语音识别；更新 ElevenLabs 默认 Scribe v3、Soniox 默认异步 v6，Soniox 模型可手动设置。
- SiliconFlow 增加星辰、Qwen3-ASR、Qwen3-Omni 模型预设，Omni 自动使用 chat/completions 音频协议；MiMo 增加区域 Token Plan 接口，StepAudio 增加 3-ASR-Max 与 Coding Plan 预设。
- 新增 GigaAM v3 俄语离线模型家族，沿用完整 SHA-256 校验与 sherpa Nemo transducer 引擎。
- 新增 AI 润色服务配置：SiliconFlow、DeepSeek、智谱、Kimi、火山方舟、阿里千问、OpenAI、Gemini、Groq、Cerebras、Fireworks、OhMyGPT、自定义兼容服务，共 13 项；每个服务独立保存自己的 Key、接口、模型。
- 润色提供整理口语、正式表达、自然表达、提炼要点及自定义提示词；可开启语音识别后自动润色、自动翻译，均默认关闭，两项同时开启时先润色再翻译。
- 功能菜单新增“AI 润色”和“翻译”。手动入口只读取用户选中文字，先预览、确认后才替换；同样可绑定到工具栏或按键。改变输入框、选择位置或取消后，旧结果不能写入新位置。
- 翻译支持微软、腾讯、火山、Google、哔哩哔哩 Index 与自带模型的 AI 翻译。
- Foxlet 0.5.0 离线翻译：语言包下载、删除、已安装列表，缺少直达模型时通过英语中转；支持 Android 9+ arm64，其他设备保留在线功能，键盘 minSdk 21 不变。翻译不会自动下载、不会发送文本到服务器；单线程推理，结束后卸载模型。
- 语音界面区分识别中、润色中、翻译中。网络异步执行，连接复用、请求取消、超时、响应大小限制；处理失败保留前一阶段文字，取消不触发回退上屏。
- AI Key 遵循整包备份原有“包含密钥”开关，默认排除。选择包含模型时一并备份离线翻译语言包，并兼容旧备份缺少翻译根目录的情况。
- 保留 V3.7.6 季灾兑换码 `qxm222` 与 V3.7.7 按主题保存工具栏的修复。

## 使用

设置 → 语音输入 → AI 润色与翻译，选择服务商并填写自己的 Key、模型。可在页面直接输入测试文字确认配置。在线翻译接口无需 Key；AI 翻译沿用 AI 配置。Foxlet 须明确选择原文语言并先下载语言包。

手动处理：先在应用输入框选中文字 → 键盘功能菜单 → AI 润色 / 翻译 → 预览 → 替换选中文字。

## 验证

- 协议、取消、回退、翻译分块、离线语言包路由及已有语音 / 主题 / 按键 / 宠物单元回归，共 427 项通过，0 失败、0 跳过。
- 五个公开在线翻译接口以固定无个人信息测试句“你好，很高兴认识你。”联网核验，全部 HTTP 200 且返回正确英文译文；微软 611 ms、腾讯 351 ms、火山 598 ms、哔哩哔哩 705 ms、Google 389 ms。这只是当前网络的一次测试，不代表所有网络与时间都可用。
- Android 16 独立包 15 组真实输入流程回归通过：默认关闭、手动预览确认、手动翻译、取消、光标移动、切换输入框、自动润色、临时语音替换与取消恢复、先润色后翻译、HTTP 失败回退、处理中取消、Foxlet 初始化、密钥备份排除、设置页渲染。AI 返回由进程内 HTTP 拦截器模拟，未使用真实密钥。
- Foxlet 手机完整流程通过：官方中文→英文模型 54,556,676 字节，下载约 2.528 秒；测试句得到 “Hi, glad to meet you.”，单次推理 230 毫秒（不代表其他设备或长文本耗时）。推理前 PSS 84,141 KB，卸载后 88,638 KB；已验证删除语言包及空安装列表。
- 修正手机测试发现的弹窗替换竞态：旧弹窗异步关闭不再清空当前结果弹窗引用。
- 手机默认输入法与完整启用列表已恢复，独立测试包已卸载。
- 正式优化 Release 构建与同证书签名、16 KB ZIP 对齐、API 兼容 DEX 审计通过；新增 Foxlet ELF LOAD 段对齐为 0x4000。
- 全量 Debug Lint 未通过：原有主代码 62 项错误、既有调试工具 28 项错误，合计 90 项；本轮新增功能未引入 Lint 错误。已将初次发现的三处 API 级别保护问题全部修正。

## 范围与限制

- 在线 AI、千问、DeepSeek 等付费接口未使用真实账户密钥做计费识别测试；请求结构与响应解析通过固定上游协议和模拟响应验证。具体账号权限、模型可用性与费用由用户的服务商决定。
- 本轮千问接入为完整录音后识别，未移植上游 Java SDK 的实时流式模式。语音识别服务中原有火山 / 腾讯 / X-ASR 流式输入继续保留。
- 上游自动选择提示词、公益密钥、Pro 服务、录音历史与后台长录音等未打包到本次同步；重点同步咩版可直接使用的服务商、润色与翻译功能。
- GigaAM 完整模型推理及全部语言方向需要相应模型和设备；本轮验证范围以实际报告为准。
- GitHub Release 提供原签名 APK、与 `v3.7.8` 标签完全对应的源码 ZIP、V3.7.5→V3.7.8 增量补丁、验证记录及 SHA-256 校验值。签名私钥、手机输入法列表与真实账户凭据不随发布分发。
