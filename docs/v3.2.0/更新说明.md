# V3.2.0 整套键盘管理

版本：V3.2.0，versionCode 20261225。正式版，原发布证书，arm64-v8a。

## 使用方法

进入“键盘 → 布局与整套键盘”，使用自定义布局模式后，可在“自定义整套”和“内置整套”之间切换。

### 创建

点“新建整套键盘”，选择从内置样式开始、复制已有整套或空白创建。从内置样式开始时，一次勾选所需的 26/9/18/14/七列一/七列二/英文/数字布局。九键需要相应 Rime 输入方案。符号、表情使用现有分类面板。

### 编辑

顶部为简略外观预览，横屏自动收紧高度；完整视频、特效和真实输入效果可用顶部“测试输入”查看。打开整套后有三个页面：

- 布局：两列布局卡片，点击编辑按键；长按设置默认中文页、调整顺序和名称、管理跟随状态或删除。可补充模板布局或空白页。
- 整套设置：背景、普通/功能/强调三类按键外观、字体、工具栏、功能菜单、候选窗/悬浮球外观、常用绑定。
- 复用：按类别复制其它整套设置，或引用命名共用方案。一次复制默认保留目标独立项；持续共用需主动选择，更新前显示使用中的整套。

“更多”提供启用、复制/另存、重命名及撤销。内置整套还提供“恢复本套内置默认”。可先另存保留微调。

### 独立与跟随

新建整套的页面默认跟随整套。页面编辑器右上角“跟随整套”可按类别恢复跟随或保存为当前页独立。平时修改某个字段，只把该字段记录为独立覆盖；其余字段继续跟随。

单键保存自己的外观和绑定覆盖，并可分别恢复跟随。显式透明、空工具栏、关闭开关、空绑定都有独立含义。全体按键背景是强制覆盖，优先于单键背景。

九键 ABC 等组合键与单字母 A 分开匹配，不会把常用 A 键长按同步到组合键上。对已有逐键手势的整套复制，仍可使用“复制整套按键绑定”查看匹配数量。

### 现有数据与内置整套

旧自定义布局的独立设置保持原状；可在“整套设置”中选择“整理已有布局为整套共用”，相同值转为跟随，差异保留。

内置整套首次进入编辑器时，将当前外观分解为整套默认值及页面/单键差异；微调保存在用户布局文件内，继续沿用原有升级时保留用户编辑的规则。

传统 YAML 主题布局仍使用原来的主题设置。工具栏悬浮球中英切换修复继续包含在本版。

### 导入导出

布局管理右上角“导出整套（包含资源）”生成 `.mie-keyboard.zip`：包含布局、共用方案的独立快照、引用的图片/视频/字体/图标，以及使用到的自定义功能依赖。

“导入整套键盘包”会校验文件大小、资源 SHA-256 和引用，生成新的布局、宏动作、功能 ID；同名自定义功能自动加导入后缀，避免覆盖原功能。不自动切换当前输入布局，也不引用接收设备上的同名共用方案。

原有 YAML 导出继续保留，导出的是当前有效外观/绑定的独立兼容快照；完整继承关系与资源请使用整套 ZIP。整体设置备份仍包含本次新增配置。

## 实现与检查边界

- 整套元数据保存在原布局存储内，共用方案与布局在同一次提交中保存；不改变 `.mie` 资源存储结构。
- 合并配置按存储版本缓存；常规按键绘制不解析整套 JSON。数字、英文语义跳转只查页面索引。
- 整套操作保存前校验继承数据，失败恢复内存旧值；撤销有后续编辑检查，避免覆盖后来的修改。
- 全部 JVM 单元测试 443 项通过，其中新增 8 项整套继承、清空、绑定和身份匹配回归。
- .33 手机（API 36）独立咩2回归通过：八页整套新建、字体字段覆盖/恢复跟随、共享方案更新与解除、整套资源 ZIP、内置模板共用工具栏、补页和撤销、三个编辑页。
- 26/9/14/18/七列一/七列二从数字/英文页精确返回通过；悬浮工具栏使用当前动作切换中英并返回九键/十八键通过。
- 既有皮肤按钮真实触摸及主题/自定义/内置三类布局连续九次选择通过；emoji、小号“造”和热力图回归通过。
- 启用 R8 与资源压缩的独立包重复整套回归通过，设备安装包与本地构建 SHA-256 一致。
- 手机正式包未被覆盖；测试前备份，结束后恢复原默认输入法及布局、资源文件并核对哈希。测试包只用于本地实测，不作为 GitHub 附件发布。

## 验证边界

未进行长时间压力测试；资源包已检查图片与配置往返，未在第二台手机覆盖所有视频、字体、命名功能的组合。预览只展示简略外观，真实特效请用顶部测试输入查看。
