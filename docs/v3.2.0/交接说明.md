# V3.2.0 源码交接

源码标签 `v3.2.0`，增量补丁基于已发布 V3.1.16。正式 APK：`trime-mie-v3.2.0.apk`；versionCode 20261225，原正式证书，arm64-v8a。

本次包含先前未单独发布的 V3.1.17 悬浮球中英修复，以及整套键盘管理。更新说明记载具体使用方式，检查记录记载实际覆盖范围。

主要代码：KeyboardSets（按字段继承/单键覆盖）、KeyboardSetOperations（整套操作）、KeyboardSetArchive（带资源导入导出）、CustomKeyboards（存储与解析缓存）、KeyboardSetActivity/Dialogs（管理界面）。新增字段保存在原布局文件，不迁移用户资源目录。

内置键盘只在用户进入编辑器时整理为整套元数据，保留现有独立差异。资源导出生成独立快照；导入重映射布局/功能标识。整套操作原子保存并提供一次受后续编辑保护的撤销。

构建依照 BUILD.md；签名私钥、登录凭据、手机数据备份不在源码包。测试入口只在 debug 源集，禁止把咩2 APK 作为 Release 附件上传。

发布页：https://github.com/qxm888/trime-mie/releases/tag/v3.2.0
