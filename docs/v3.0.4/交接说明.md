## 构建

JDK21、Android SDK37、Build Tools36，本次 arm64-v8a，最低API21。源码含预编译JNI、Sherpa AAR及Gradle Wrapper JAR；私钥与口令不包含。原生依赖完整来源边界见 NATIVE_BUILD.md。

```bash
JAVA_HOME=/usr/lib/jvm/java-21-openjdk ANDROID_HOME=/opt/android-sdk \
  ./gradlew app:assembleDebug -PvariantTag=v2 -PbuildABI=arm64-v8a --max-workers=2 --console=plain
JAVA_HOME=/usr/lib/jvm/java-21-openjdk ANDROID_HOME=/opt/android-sdk \
  ./gradlew app:assembleRelease -PbuildABI=arm64-v8a --max-workers=2 --console=plain
```

正式构建请配置原签名。发布前核对包名、版本、非debuggable、无instrumentation、ACCESS_LOCAL_NETWORK及原签名证书；按SHA256SUMS核对本次交付文件。

## 本轮实现位置

- ClipboardSync：Main线程状态快照、请求代次校验、成功后更新本地待上传状态、取消时附件清理。
- ClipboardSyncActivity：忙碌状态、重复提交保护、文件上传前核对配置、权限和取消处理。
- BackdropBlur：按需调度、可见性恢复、独立不可变发布帧。
- KeyBackgroundStyle：有界Drawable几何缓存；FontOverrides：锁外字体创建和失效代次。
- PaginationUi：宽高共同缓存；FloatingCandidatesEditActivity：可用高度与字体导入目标。
- CreatedWordsActivity / WordSchemas：取消旧任务、一次排序、方案名称刷新。
- Mie304Runner：仅咩2隔离定向检查。
