# V3.0.4 更新说明

本轮以修复同步边界和减少重复绘制为主，沿用现有设置入口与传统 rime 目录。正式版本 V3.0.4 / 20261202，安装包 trime-mie-v3.0.4.apk。

## 剪贴板同步

- 手动接收失败、远端为空或请求取消时，保留尚未上传的本地内容及已接收标记；接收成功后才更新本地状态。
- 请求期间复制了新内容时，保留新内容并提示跳过接收。更换配置、停止服务后，旧请求不再改写新连接的状态；未使用的下载附件会清理。
- 保存、权限检查和传输期间显示进度并暂时禁用重复提交；取消文件选择会恢复操作，上传前再次核对服务器配置。
- 关闭自动同步时给出准确提示；离开页面取消任务时不再弹出过期结果。

## 绘制与输入开销

- 静态模糊由背景、尺寸和可见性变化触发，取消固定100毫秒空轮询；视频变化仍合并刷新，最高每秒10次。
- 模糊工作位图和已发布画面分开：已交给界面绘制的帧不再被下一次模糊改写，降低闪烁、旧帧污染风险。
- 分别缓存按键常态、按下态及修饰状态的圆角和边框参数，反复按键不再重复触发相同 Drawable 的几何更新。
- 大字体创建移出共享缓存锁，避免加载一个新字体时阻塞其他已缓存字体；字体缓存清理后，旧加载结果不会重新塞回缓存。首次加载本身仍可能耗时。

## 界面细节

- 悬浮候选自定义翻页样式切回默认时，正确恢复按钮宽度。
- 悬浮窗编辑预览根据可用高度缩小，空间不足时隐藏预览，为横屏及软键盘打开时保留编辑区域。
- 导入悬浮候选字体时固定导入目标，避免切换字体区域后应用到错误位置。
- 造词管理取消离开页面后的旧加载任务，避免旧列表覆盖新列表；每次加载只排序一次，搜索直接筛选，方案名称变化也能刷新。

沿用原正式签名与JNI，不上传GitHub。提供正式APK、咩2检查包、完整源码、增量补丁和检查记录。仅安装咩2，不替换手机正式应用。局部组件检查不等同于真实输入整体提速，验证边界见检查记录。
