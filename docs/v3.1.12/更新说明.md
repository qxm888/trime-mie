# V3.1.12 更新说明

版本：V3.1.12 / versionCode 20261219；arm64-v8a。本轮本地交付，尚未上传 GitHub。

## 修复切换

- 工具栏从 18 键等中文布局进入英文页，再切回中文时恢复原布局。既记录 Rime 中英模式自动切页，也记录明确的英文页绑定。
- 悬浮候选模式中，隐藏工具栏自动开启悬浮球；重新显示工具栏时关闭球。候选栏输入仍不启用球；悬浮键盘强制显示工具栏的规则保留。
- 修复正式压缩包旧主题刷新时的 `RimeApi.deployThemeConfig` / `AbstractMethodError`：去掉多余接口委托代理，直接使用 Rime 实例。加载主题成功后再统一提交布局模式；失败恢复旧主题、配色和模式。
- 普通/悬浮键盘重建保留相同主题的布局、导航、中英返回位置和修饰键状态；不把旧主题状态复制到新主题。主布局变化时刷新工具栏与候选配色，避免蓝色键盘切悬浮后变粉色。

## 编辑与布局管理

- 自定义键盘的功能菜单页增加编辑按钮，可选静态功能和当前方案开关的显示项目；也可从当前布局的工具栏编辑菜单进入。按布局保存，隐藏全部后仍有固定编辑入口可恢复。
- 内置符号/表情分类列表改成两列按钮，长按拖动调序；顺序保存在整体设置备份中，并提供恢复默认顺序。
- 可编辑布局（包括内置键盘实例）保存到 `rime/.mie/键盘/键盘布局.json`，私有旧路径 `files/custom_keyboards.json` 使用软链接指向实际文件。系统不支持在模拟外部存储创建软链接，因此链接建在应用私有目录。
- 咩2单独保存到 `rime/.mie/键盘/咩2/键盘布局.json`，不混用正式版布局。其它开发包按包名分子目录。实际前缀以选择的 Rime 数据目录为准。
- 升级迁移原私有布局；私有目录保留恢复副本，目录不可写时先保存本地，后续成功保存时同步。APK 内的原始模板保留用于恢复内置键盘。
- 导出列表只显示主键盘名；选择后导出该主键盘及全部嵌套次级键盘。重名主键盘附来源或短 ID 以便区分。
- 自定义键盘管理页右上角增加“恢复内置键盘”：可补回缺失项，也可确认后重置所有内置布局；不删除用户创建的键盘。重置会覆盖对内置 ID 的编辑，应先备份。

## 字体

- Android 10 起，主题明确设置的字体或自定义键盘选用的字体之后，自动追加 `rime/fonts` 中的 TTF、OTF、TTC、OTC 字体作为缺字回退，最后由系统字体补缺。
- 没有显式排序的目录字体按文件名排列；显式字体优先，重复文件去重。受 Android 回退链数量上限约束，损坏/不可用字体跳过。
- 字体目录在初始化或刷新主题时扫描，不在每次打字或绘制时扫描。添加、更换字体后重新选择主题/布局使缓存更新。
- Android 9 及更早系统仍使用第一个可用字体和系统回退，无法提供同等的多文件回退链。
