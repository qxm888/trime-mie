# Trime Mie V2.1.1

## 状态栏按钮

修复现代内置动作（隐藏状态栏、单手、悬浮、候选窗口）被编辑器当作旧动作过滤的问题。只过滤已经停用的旧别名；自定义动作和同一功能的多个按钮都能保存与显示。按钮列表不再因为打开页面又返回而自动写成自定义列表。

设置 → 键盘 → 工具栏，分别选择主题键盘状态栏或自定义键盘状态栏。自定义模式选择具体布局，每个布局拥有自己的按钮列表和整条状态栏背景。布局编辑页里的工具栏入口也进入当前布局。

点击添加按钮，可创建自定义按钮或选择已有功能，再编辑显示文字、表情或图标图片、宽度、点击/长按/双击/四向滑动。按钮外观支持字号、常态和按下文字颜色、背景颜色/图片、边框颜色/宽度与圆角。点击已添加按钮的名称或动作行，可重新编辑。内置语音绑定保持按住录音、松开结束的交互。

## 两种键盘的外观隔离

设置 → 外观 → 全局按键与状态栏样式，分别进入主题键盘全局外观和自定义键盘全局外观。两种模式使用不同的配置键，保存或恢复一方不会改变另一方；“状态栏与键盘共用背景”也各有一个开关。系统输入行为、声音/振动和应用明暗等通用设置继续沿用已有设置。

升级时原来的全局外观保留在主题模式；自定义模式的全局外观从默认值开始，原布局、皮肤和单键配置保留，不复制主题模式的覆盖层。

## 当前布局一键设置全体按键背景

设置 → 键盘 → 布局管理与按键编辑 → 打开自定义布局 → 右上角菜单 → 全体按键背景 · 一键设置。

可选纯色、透明或图片。它只覆盖当前布局所有按键的背景，保留布局几何、绑定和各键的原背景数据；恢复继承后原背景重新生效。覆盖层优先于自定义模式的整体按键背景。状态栏选择跟随按键时也会使用当前布局的整体按键背景；单个状态栏按钮的显式外观仍可覆盖继承项。

新增状态栏按钮参数和全体背景覆盖层随布局JSON/YAML导出、导入。图片仍按路径引用，换设备须复制图片素材。
