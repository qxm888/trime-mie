# V3.1.5 更新说明

补全内置符号/表情键盘，并压缩内置键盘存档、避免首次启动卡顿。

## 变更

1. **补全内置符号与表情页**
   - 上一版内置只带了 55 套（26/9/14/18 + 英文 + 数字 + 符号×3 + 布局 + 主题），
     符号键盘里“更多”按钮指向的表情/符号分类页没有打包，点了没反应。
   - 现在内置完整 300 套（每色 60 套，含表情、符号表、常用符号等分类页）。
2. **首次启动不再卡顿**
   - 324 套键盘的 YAML 若在主线程解析会让冷启动停顿十几秒；现在拆成两份资源：
     核心 55 套同步播种（约 2 秒），扩展 245 套在后台补齐（首次启动约十秒内完成）。
3. **存档压缩**
   - 键盘存档 JSON 改为只写非默认字段：300 套的存档从 13.5MB 降到 3.4MB，
     实测常驻启动时间从 ~1.4 秒降到 ~0.64 秒。
4. **升级自动补齐**
   - 内置版本号 3 → 4，升级后自动刷新已有内置键盘并补齐新增的分类页；
     用户自建键盘不受影响。
