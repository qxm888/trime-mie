## BiBi 最新功能同步（V3.7.8）

固定参考 [BiBi Keyboard 提交 271f777](https://github.com/BryceWG/BiBi-Keyboard/tree/271f77786bdae6aa6b40bc9a3c76293821745c2b)（2026-11-14；正式版 4.6.1 之后的 ElevenLabs v3 更新也在此快照中）。

本轮适配了 `LlmVendor.kt` 的公开服务商元数据、`OnlineTranslationService.kt` 的五种匿名翻译协议、`DashscopeFileAsrEngine.kt` / `DeepSeekFileAsrEngine.kt` 的文件转写协议、`LocalModelIntegrity.kt` 中 GigaAM 模型清单，以及 Foxlet 翻译与语言包路由。咩版自行实现设置界面、选中文字预览与确认、输入框归属保护、异步取消、失败回退、响应大小限制与备份集成。所有在线 AI 凭据由用户配置，不携带上游公益密钥或商业功能凭据。

Foxlet 0.5.0 使用上游公开的 Kotlin 兼容 AAR；原始来源、固定提交、重建脚本和补丁保留于 `app/libs/foxlet/`，完整声明位于 `app/src/main/assets/licenses/Foxlet-LICENSE` 和 AAR 内的许可证资源。Foxlet 原创代码为 MIT，第三方代码和 Mozilla 模型保留各自许可证（含 MPL-2.0）。语言包按需下载，不随 APK 打包。该引擎仅支持 Android 9+ 的 arm64 进程；其他设备使用在线翻译，键盘最低支持版本仍为 Android 5.0。
