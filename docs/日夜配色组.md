# 日夜配色组

## 新建与使用

进入“外观 → 主题与配色 → 配色组”，点击“新建配色组”。输入名称，为“日间”和“夜间”分别选择主题。可选择传统主题、内置整套或自定义整套；选择过程只记录目标，不切换当前键盘。

点击组后可以启用、编辑或删除。开启“跟随系统夜间切换”后，已启用组根据系统日夜切换；关闭后使用日间主题。未启用配色组时，原有主题内部日夜配色规则保持原行为。配色组设置保存到应用偏好，包含在整体备份中。

配色组保留主题/整套引用，不复制其中的按键、背景或绑定。目标被删除时保留当前键盘，手动选择会提示重新配置，自动切换失败进入诊断日志。

## 键盘样式与皮肤入口

顶部“布局 / 配色”分段：

- 布局：下一级为“主题布局 / 内置布局 / 自定义布局”，底部列对应项目。内置、自定义为两列；新增整套自动进入对应分类。
- 配色：仅列用户保存的配色组；没有配色组时为空。选中即启用，按跟随系统设置决定当前日间或夜间目标。

浏览分类不切换键盘。手动选择布局退出配色组模式；切换失败恢复之前的组标记。配色切换时，内置/自定义套之间按页面角色尽量保持 9、14、18、英文、数字等页面，并将可用的返回记忆映射至新套。目标无相应页则使用其默认页。传统主题跨主题切换使用目标主题自身布局规则。

## 实现位置与当前检查

- KeyboardColorGroups：组存储、系统夜间监听、应用和失效目标处理。
- KeyboardColorGroupsActivity：组管理及日夜目标编辑。
- ThemePickerDialog：两个入口共用同一选择页；编辑配色组时复用只选目标的模式。
- KeyboardWindow.restoreFamilyNavigation：仅映射新套有效 ID，不传入旧主题实例。
