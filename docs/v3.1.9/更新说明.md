# V3.1.9 更新说明

日期：2026-11-01。基于 V3.1.8（e33e33e），versionCode 20261216。

## 布局

五色内置键盘的布局选择页增加「七列一」「七列二」。只参考用户提供的两份七列布局的按键排列，不复制完整主题、图片、字体或外部命令。新布局均含 26 个字母与基本控制键；保留原九键底行 52dp 和强调色设置。内置模板版本升至 7；V6 已有页面保留用户编辑，仅补新增页面、更新布局选择页的行。

## 候选与悬浮交互

| 输入方式 / 状态 | 工具栏 | 悬浮球 |
| --- | --- | --- |
| 候选栏输入 | 可以隐藏闲置工具栏；输入时保留候选栏 | 关闭并禁用开关 |
| 悬浮窗输入 | 可以隐藏 | 可随时手动开关；隐藏工具栏或在工具栏已隐藏时切入，会自动开启 |
| 悬浮键盘 / 单手卡片 | 临时强制可见，返回普通键盘恢复原偏好 | 仍遵守当前候选输入方式 |

悬浮窗的系统 / 输入设备 / 始终显示策略仍保留。开关归一规则也作用于工具栏绑定、设置页及恢复设置后的偏好变动。

## 多字体与样式弹窗

主题、自定义键盘各文字区域及悬浮候选窗支持添加多个字体、排序、移除，系统字体放在末尾兜底。Android 10 及以上使用真实有序回退链；旧系统使用第一个有效字体与系统回退。旧单字体存档可继续读取，多字体继续保存到原字体字段，并随布局导出 / 整体备份保留。

键盘样式弹窗左上角增加主题布局 / 自定义布局切换。弹窗先显示、后台加载名称、解析与字体；自定义列表只列主键盘，当前次级键盘高亮其主键盘。普通名称读取不解析整份大主题。

## 主题修改生效与部署

- 普通源主题与支持的 include / custom 补丁直接解析。实际内容哈希驱动缓存失效，修改时间、文件长度不变也能识别。
- 复杂 DSL 无法直接解析时，仅在当前主题或依赖内容变化时调用原 Rime 的配置编译 API，不部署方案或词典，不触发完整部署提示。
- 强制编译只清除原生配置缓存的构建标记；不修改源文件时间戳，使用空版本比较键避免旧 config_version 导致用户主题被丢弃。
- 原生 API 返回成功后还必须生成新的、可解析且含配色的产物；失败恢复上次可用产物，保留当前显示主题并报错。
- 设置中的「刷新主题配置」仍可手动强制刷新；完整「部署」也刷新主题，但普通切主题、重新打开输入法不自动完整部署。
