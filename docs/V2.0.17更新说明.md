# Trime Mie V2.0.17

## 外观与编辑

- 自定义按键的颜色字段提供 12 种预设色、透明色及预览；背景字段另有图片选择入口。手动颜色值继续可用。
- 键盘设置、主题按键编辑、自定义布局编辑均有「整体按键背景」，支持纯色、透明和图片；恢复继承后使用原键盘外观。
- 设置列表使用连续分组卡片，编辑抽屉使用独立卡片，保留夜间配色。自定义布局的整体预览移到结构编辑上方。

## 候选悬浮球

- 工具栏菜单新增「悬浮候选栏」「隐藏状态栏」，顶部也可开关候选窗。
- 设置 → 候选窗口 → 空闲时显示候选悬浮球，**默认关闭**。另可调节不透明度。
- 开启后：空闲显示悬浮球；点击临时显示工具栏，6 秒后收起；长按在键盘打开菜单页；开始输入时展开候选窗；候选窗顶部可收起为球。

## 热力图

- 修复按键热度只记录当天的问题，周、月、年同步累加并保存。
- 升级时，可将仍保留的当天热度补入空的长周期。过去没有记录的历史按键热度无法完整重建。

## 性能与语音诊断

- 避免同一键盘窗口重复拆卸、挂载和执行过渡；触摸接收窗口复用相同坐标，减少无效布局。
- 本地语音库加载在后台执行，补上加载完成、失败和超时处理；取消后的迟到结果不再上屏。
- 离线模型切换先释放旧模型；重复识别忙碌时给出提示，避免并行加载多份模型。
- 修复流式引擎取消和异常时的资源清理，限制积压音频。
- 导出日志新增持久化阶段记录：应用初始化、键盘重建/显示耗时、录音开始/回退、输入音频字节数、模型配置/加载/缓存、推理、完成、错误和超时。不保存音频、识别文本或访问凭据。
- 过滤用户日志中的无效虚拟按键值 0xFFFFFF，避免无意义的 Unicode 异常。

提供的旧日志可确认录音停止与无效按键异常，没有模型加载或推理阶段信息，不能据此确定该用户语音无法输入的具体原因。本机 Qwen3 0.6B int8 生成音频检查加载及推理通过，约 4.5 秒；不代表所有设备、模型或在线服务均已验证。
