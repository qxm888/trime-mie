# 符号排序、主题长按滑选与显示范围

日期：2026-11-03。随 V3.2.4 发布的功能。

## 符号与注解显示范围

在自定义/内置键盘的“按键默认外观”或整套外观编辑中，展开“符号与注解显示范围”。单键外观也可覆盖：

| 设置 | 作用 |
| --- | --- |
| 上方符号横向内边距 | 同时收紧左右边缘 |
| 上方符号纵向内边距 | 同时收紧上下边缘 |
| 下方注解横向内边距 | 独立收紧注解左右边缘 |
| 下方注解纵向内边距 | 独立收紧注解上下边缘 |

单位 dp，允许 0–48；留空继承。增加数值会把显示范围向键内收缩，与“位置偏移”不同。符号仍默认靠右，注解默认居中。

按实际字形边界排版，并计算圆角处的可用宽度；窄区域会自动缩小文字，最后按键帽路径裁切。位置偏移不能把字形推出范围。图标符号也遵守显示范围。旧主题未配置这四项时保留旧排版；自定义与内置键盘启用边界约束。

五套精雕主题的默认值：

| 主题 | 符号横向/纵向 | 注解横向/纵向 |
| --- | --- | --- |
| 霁银·柔光 | 8 / 4 | 6 / 4 |
| 深空·钛影 | 8 / 4 | 6 / 4 |
| 云汐·软屿 | 9 / 4 | 6 / 4 |
| 墨绒·格调 | 8 / 4 | 6 / 4 |
| 竹月·青釉 | 8 / 4 | 6 / 4 |

模板版本 V18，升级仅补这四个未设置的默认值；保留已设置数值和其它外观、绑定、字体、几何配置。整套与单页编辑、绑定复制、布局导入导出均包含这四项。主题 YAML 可在按键中使用 `symbol_inset_x`、`symbol_inset_y`、`hint_inset_x`、`hint_inset_y`。

## 符号/表情排序

- 内置符号面板：点击分类，长按分类按钮拖动；分类内先点“排序”，长按单项拖动，点“完成”退出。
- 主题液态符号面板：分类标签长按拖动；分类内点“排序”后长按单项拖动。
- 拖动有位移动效与选中反馈，松手保存。排序模式不输入符号。
- 提供恢复默认顺序；原来的 Unicode 说明长按在普通模式下保留。
- 主题分类以原始 ID 关联，调序后不会点错分类。新增项目追加到末尾，不丢重复条目。
- 顺序保存在偏好设置，纳入现有整体备份。

## 主题布局长按滑选

主题按键编辑 → 选择按键 → “长按滑选符号…”；每行填写一个备选，或选择常用符号组。

长按打开小窗，滑动高亮，松手输入；离开有效范围取消。主题原有 `popup` 配置继续可用；可单键清空禁用或恢复主题默认。配置随现有主题绑定备份导出。

仅为主题布局新增此入口及默认尺寸兜底。自定义/内置布局不新增此入口，其已有手工弹出配置沿用。主题弹出标签保留完整 emoji 与组合字符，不截取首个码点。
