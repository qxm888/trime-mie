2026-11-15，经用户授权正式发布，标签 `v3.7.5`。基于 V3.7.4（080c0a29d4f8f37af28dd68b074b4bbe5372baaf）。

## 常用句与学习数据清理

- 常用句从最后使用时间起保留30天；尚未成为常用句的学习记录从最后学习时间起保留7天。到达期限即过期。
- 手打完整句子并完成学习、成功点击联想补全，都会更新常用句最后使用时间。点击补全只续期，不增加学习次数；仅显示或查询联想不会续期。
- 过期常用句再次输入从第1次重新学习，仍需滚动7天内3次才能达标。过期待学习记录也重新累计。
- 数据库升级为版本3。旧版未记录点击补全的使用时间，因此已有常用句获得一次升级起算的30天保护期；未达标记录沿用原学习时间，无保护期。
- 清理在 IO 调度器执行，在启用学习的输入会话开始、查询、学习或打开管理页时触发。会话和查询清理最多每小时扫描一次；学习与管理读取即时清理，查询始终过滤过期句子。应用未运行时不额外定时唤醒。
- 保留前缀索引、待学习5000条和常用句2000条上限、密码/隐私编辑器限制及本地存储方式。

## Android 13 闪退

用户日志显示 `NoClassDefFoundError: android.view.ViewTreeObserver$OnWindowVisibilityChangeListener`，发生于输入界面构造。该接口及注册/注销方法从 API 34 起可用（[Android 官方文档](https://developer.android.com/reference/android/view/ViewTreeObserver.OnWindowVisibilityChangeListener)），旧代码在 Android 13/API33 上直接引用导致类加载失败。

改用兼容的绘制观察机制，不请求持续重绘；背景未变化时不重新捕获。最终 R8 优化后的签名 APK 的全部2个 DEX 均无该接口及方法引用，V3.7.4 对照包包含全部3项引用。可用 `script/check_blur_api_compat.py APK --baseline OLD_APK --report JSON` 复核。

尚无 Android 13 真机或模拟器，兼容性结论限于日志定位、API 依赖移除和优化包审计；需由原 Android 13 设备安装复测。提供日志还包含独立的万象 Lua LevelDB 缺失 MANIFEST 记录，本轮未修改用户词库或此类数据。

## 验证

- 针对宠物、迷你场景、外观、游戏、核心输入、句子和统计运行103项单元测试，全部通过。修正一个既有外观测试的过时预期：图片不透明度默认值一直为100，测试仍写70；生产默认值未改。
- 独立 Debug 包在 Android16/API36 手机完成六组回归：句子保留、季灾/背景捕获、游戏真实输入、游戏状态与攻击音效、常用句学习及性能、旧键灵踩键。测试使用独立应用与合成文本；未读写用户聊天/正式宠物存档。结束后恢复原默认和启用输入法列表，卸载测试应用。
- 句子保留：8组真实 SQLite 测试，包括版本2升级保护期、30天/7天准确边界及提前1毫秒、查询不续期、补全及手动续期、过期重新三次学习、陈旧浮窗不复活记录、扫描间隔内过期过滤和会话清理。使用注入时间，不修改手机系统时间。
- 常用句：三种内联预编辑模式实际触屏补全；把句子预置为29天未用，验证展示不续期、点击续期且频次仍为3。发送清空、隐私、禁用、删除与容量/索引回归通过。
- 季灾：真实 H 和空格按下/释放、触手、伙伴切换、缩放与窗口尺寸、隐藏停止/恢复重绘通过。背景捕获、静止帧合并、隐藏超过重试期后的恢复和重挂载通过。既有59个角色各3个目标键、连续按键、拖动、60%/150%缩放等回归通过。
- 游戏：普通/左右单手与右上/右下/光标跟随9组实际触屏输入，检查候选窗口像素并点击上屏，攻击命中计分、退出保留原草稿；全屏、选关与旧进度、暂停、圆球/爱心/小鸡攻击及音效开关回归通过。
- 初次测试中修正独立测试夹具的偏好初始化和弹窗异步销毁等待，再完整重跑六组通过；初次日志保留，不计为通过。
- 满容量5000条待学习+2000条常用句，查询中位1.32ms、P95 2.14ms、最大4.47ms；开关学习时各264个按键样本，P95约33.15/33.37ms，帧间隔P95约11.05/11.05ms，丢弃学习事件0。单设备短时测量不能保证所有设备无卡顿。
- 原签名、zipalign和 APK 包名/版本/arm64 内容检查通过。完整 Lint 仍有62项既有错误；相对先前65项移除3项 API34 调用错误，无新增错误，不能称为完整 Lint 通过。
