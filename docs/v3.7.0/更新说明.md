# V3.7.0 · 常用句联想与输入修复

## 更新内容

- 新增常用句学习：同一句在滚动7天内完成输入3次后加入常用句，输入句首时可点击联想补全整句。默认关闭，在“设置 → 便捷功能 → 学习与联想常用句”开启。
- 联想提示采用紧凑单行样式，宽度随内容变化，最大220dp且不超过屏宽55%；自动避让原候选悬浮窗，空间不足时隐藏。点击补全不会重复前缀，也不会把本次补全计入学习次数。
- 支持长按删除常用句、关闭本句提示，以及在设置中管理和清空学习数据。句子保存在本应用私有数据库；密码和禁止个性化学习的输入标志不参与学习。
- 修复自动顶字上屏时的码长归属，避免把触发下一字的编码错误计入前一字。
- 修复单手模式输入编码时应用输入框被顶起的问题：编码区作为浮层显示，保留触摸区域。

## 验证范围

58项针对句子规则、输入统计和键盘的本地回归通过；Release构建、Lint、原签名及16KB对齐检查通过。

在PKX110 / Android 16独立Debug测试包中验证了三次学习、三种预编辑模式的真实触屏补全、紧凑尺寸、候选窗避让、长按删除及关闭开关。密码和禁止个性化学习规则通过向真实控制器传入合成EditorInfo验证；未修改手机安全键盘设置。

5000条待学习、2000条常用句下，查询P95为1.70ms；同机合成输入开关前后按键处理P95为49.71 / 49.78ms，差约0.07ms。按键计时包含Rime任务及等待主线程空闲，不能等同于物理按键延迟。数据仅代表本轮设备与测试场景。
