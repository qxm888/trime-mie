# Trime Mie V3.0

正式包 `trime-mie-v3.0.apk`，包名 `com.osfans.trime.mie`，版本码 `20261128`。咩2检查包使用 `com.osfans.trime.debug.v2`。

## 设置页试打

所有应用内设置页面的顶部工具栏均保留原有 **测试输入** 按钮，包括字体、语音、工具栏、自定义键盘与备份等独立页面。点击时才弹出文本、数字、密码试打面板；关闭按钮或返回键可收起。没有底部固定入口，关闭时不占用内容空间。

## 候选词

长按候选 → **忘记这个候选 · Control+Delete**。先定位原生候选，再向 Rime 发送同文原有组合键，由方案本身处理。取消本应用的置后模拟和旧忘词投影，固定顺序中对应词的覆盖也会移除。应用内独立造词尚未写入原生用户词典时，会提示无法执行原生忘词。删除候选仍是另一个单独操作。

## 字体与字号

外观 → **主题键盘字体与字号**。按键、符号、注解、候选、候选注释、序号、编码、气泡及工具栏可分别选择字体和字号，字号0跟随主题。自定义键盘仍在各自编辑菜单中保存独立配置。

字体导入在后台完成，支持最高128MB的TTF/OTF/TTC文件。大字体不再因超过16MB缓存权重而立即被淘汰；主题字体保留解析结果，绘制时不再反复读取文件属性。损坏字体缓存失败结果并回退，减少重复尝试。按键字体度量对象复用，减少绘制分配。

## 流式语音

便捷功能 → 语音输入 → 识别服务与模型 → **流式输出：录音时显示识别文字**。

火山流式和本地X-ASR已有部分结果回调，本版接通输入框临时文字，最终结果替换同一段临时内容，避免重复追加。取消或错误时清理本次临时文字，切换输入框和手动按键会终止会话。日志新增首个部分结果耗时、字数和会话编号，不记录识别正文。

SenseVoice、FunASR Nano、Qwen3-ASR等本版使用的整段离线接口，以及先上传完整音频的服务，仍需松手后识别；开启流式输出开关不会把这些接口转换成流式模型。

## 剪贴板同步

便捷功能 → 剪贴板 → **剪贴板同步**。

对接 [SyncClipboard](https://github.com/Jeric-X/SyncClipboard) v3.1.1及以上版本的独立服务器、桌面客户端内置服务器或WebDAV目录。此处是协议兼容客户端，服务器由用户配置。[说点啥](https://github.com/BryceWG/BiBi-Keyboard)也使用该项目对接剪贴板同步。

- 填写地址、用户名和密码；优先使用HTTPS。局域网HTTP须主动打开对应开关，仍使用系统证书校验。
- 自动同步默认关闭。开启后在输入法服务运行期间每5秒检查远端，复制内容经防抖上传，网络失败逐步延长重试间隔。
- 支持UTF-8文本、大文本附件、图片及单个文件。文本上限256KB，附件上限32MB。更大文本可保存为文件，多文件可先打包成ZIP。
- 可手动上传当前剪贴板、选择图片/文件上传、接收远端剪贴板。
- 上传顺序为附件、清单；接收校验SHA-256，拒绝越界文件名，不跟随重定向，不自动打开接收文件。
- 接收后写入系统剪贴板，可到支持图片/文件粘贴的应用使用；本机剪贴板历史仍以文本记录为主。
- 共享存储已授权时，附件保存在 `rime/mie/剪贴板附件/`，否则保存在应用文件目录。接收回调做去重，避免来回重复上传。
- 系统标记为敏感的剪贴板条目不自动上传。切换应用或系统休眠后的持续性取决于系统是否保留输入法服务。

## 模型目录

本地模型安装至 **`rime/mie/语音模型/<引擎>/<变体>/`**。使用自选公开Rime目录时，`mie`跟随该目录。

需先授予共享存储权限。旧内部模型在进入语音设置后后台迁移，也可点击“迁移已有模型到用户目录”。复制校验通过后才启用副本，旧文件保留。迁移前仍可从旧路径加载，下载压缩包与安装临时文件继续由应用管理。清理模型会同时清理旧副本。

## 整包备份与恢复

数据与备份 → 导入导出 → **整包备份与恢复**，原剪贴板历史导入导出页菜单也有入口。

备份文件保存到 **`rime/mie/备份/trime-mie-v3.0-时间.zip`**。包含应用设置、主题按键覆盖、工具栏、自定义键盘及功能、字体、图片/视频背景、Rime源配置与用户词典、统计和候选记录。可选择包含本地模型及服务密钥；备份ZIP未加密，密钥默认不包含。剪贴板历史使用原有专用导入导出功能。

恢复时可直接选该目录的备份，或从系统文件选择器导入。先校验清单和文件哈希、在后台准备资源，再自动重启切换；记录回退信息以处理中断。字体/背景路径会重定位，不导入另一设备的目录授权或安装标识，保留当前存储选择；自动剪贴板同步保持关闭。输入引擎首次启动会完整部署恢复的配置。

先授予目标目录访问权限，再恢复。Android授予的输入法启用、默认输入法、麦克风等系统权限仍需在新设备上设置。应用专用的 `mie`、`mie_resources` 不纳入原生Rime文件镜像，避免复制模型和备份ZIP。

## 图标

使用原同文矢量标记，背景 `#FBE8EC`。Android 8+提供完整自适应前景/背景，Android 13+提供单色层，旧系统有5种密度的备用资源；最终外形由系统桌面裁切。
