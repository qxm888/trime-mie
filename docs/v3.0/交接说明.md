## 构建

使用JDK21和Android SDK：

```bash
JAVA_HOME=/usr/lib/jvm/java-21-openjdk ANDROID_HOME=/opt/android-sdk \
  ./gradlew app:assembleDebug -PvariantTag=v2 -PbuildABI=arm64-v8a --max-workers=2 --console=plain
JAVA_HOME=/usr/lib/jvm/java-21-openjdk ANDROID_HOME=/opt/android-sdk \
  ./gradlew app:assembleRelease -PbuildABI=arm64-v8a --max-workers=2 --console=plain
```

Release需要本机已有签名配置。源码和交付ZIP不包含私钥、签名口令或本地签名配置。正式证书应继续与此前版本一致：

`b22fc84964778b646c395c87d93a323d21655eaffd53718a814035adf476d5bf`

完整源码ZIP包含Git忽略但构建需要的 `app/prebuilt/arm64-v8a/librime_jni.so`、`app/libs/sherpa-onnx-1.13.4.aar`、Gradle Wrapper JAR。预编译依赖的既有来源记录限制继续见 `NATIVE_BUILD.md`。

## 主要改动

- `Rime.kt`：目标候选原生忘词和恢复后完整部署。
- `ThemeFonts.kt` / `FontOverrides.kt`：大字体缓存与主题字号；`FontSpec.kt`保持两种模式独立。
- `BuiltInVoiceController.kt`：部分结果组合文字、会话清理、首个部分结果诊断。
- `ClipboardSync.kt` / `ClipboardTransfer.kt`：默认关闭的协议兼容客户端、图片/文件传输与校验；没有新增服务端二进制依赖。
- `LocalAsrModels.kt` / `MieUserDirectory.kt`：公开模型目录和经过校验的迁移。
- `FullSettingsBackup.kt`：带清单的整包备份、预备文件、路径重定位与恢复回退。
- `RestartAfterRestoreActivity.kt`：独立短时进程只重启本应用；Application在该进程跳过正常输入法初始化。
- `UserDataManager.kt`：本应用的模型和备份目录排除出原生数据镜像。
- `SettingsTestInput.kt`：统一向各设置页顶部工具栏添加测试输入按钮，点击后临时弹出试打面板，关闭后不占布局空间；页面重建时补回按钮。
- `Mie30Runner.kt`：咩2独立检查入口，含七页顶部按钮与临时面板检查，正式包不含该组件。
