# 液态玻璃内置主题

V3.7.9 新增内置整套 `custom_liquid_glass`，界面名称“液态玻璃”。尚2026-11-15 经用户授权随 `v3.7.9` 正式发布。

## 使用

打开键盘工具栏的样式按钮 → 布局 → 内置布局 → 液态玻璃。也可以在设置的“布局 / 配色”选择。整套设置中仍可调整圆角、透明度、模糊和按键绑定。

包含十五页：26键、9键、14键、18键、七列一、七列二、英文、数字、英文符号、中文符号、数学符号、更多符号、布局页、样式入口、键盘中心。沿用内置布局的尺寸、手势和中英切换，悬浮候选、工具栏和单手布局配套使用。

## 材质与性能

- 按用户参考图设计的原生半透明键帽、中性磨砂底板、细白渐变亮边、轻内阴影和克制高光；按压时微缩下沉并有淡蓝涟漪，文字保持独立绘制。
- 自带原创静态柔色背景，整块底板模糊强度 40，键帽通过透明度透出已经磨砂的面板，避免逐键重复采样。系统允许跨窗口模糊时使用 8% 背景混入；系统关闭或未开放时自动恢复 100% 自带背景，不会透空。没有自行截取其他应用画面，不需要屏幕录制授权。
- 悬浮候选、编码区、选中候选及悬浮球统一为半透明中性色、白色细亮边、G2 圆角和深色文字。悬浮窗也会尝试系统模糊；系统不支持时保留可读的磨砂底色。
- 采用已有小图共享后台高斯近似滤波。动态背景变化时上限 10fps，静态背景不持续抓图；按键本身没有常驻动画。
- 内置版本升级到 19，以补齐新整套；现有键盘遵守已有保守迁移规则，不重置个人修改。材质包增加一张 1200×860 PNG，新增材质可自动补装，原有材质字节保持一致。
- `tools/generate_liquid_glass_theme.py` 生成十五页和背景；背景由 `tools/premium/liquid_glass.py` 的矢量路径绘制，无文字烘焙、无新增运行时依赖。原有材质生成器也包含该背景。

## 验证

145 项布局、主题与外观单元测试通过，涵盖十五页归属和跳转、几何、资产存在、原生半透明背景、浮窗文字对比、手势覆盖及 YAML 导出往返。真机结果见本轮验证附件。跨窗口模糊受设备与系统状态限制，参考 [Android 官方窗口模糊说明](https://source.android.com/docs/core/display/window-blurs)；不将本地图片磨砂宣称为跨应用动态模糊。


真机验证：Android 16 / ColorOS 调试手机通过内置目录发现、十五页模板、26键/九键/数字/符号/英文导航、真实按压状态、悬浮编码及三条合成候选、单手布局。已查看原生截图核对边缘、文字和布局。此主题沿用的隐藏局部接口返回 `unsupported`，自带背景磨砂回退正常；后续独立“液态玻璃·动态”已通过公开窗口路径实现，见[跨应用动态玻璃](跨应用动态玻璃.md)。原默认输入法及启用列表已精确恢复，测试包随后卸载。

完整 Lint 仍有 90 项既有错误；按错误类型、文件和消息对比无新增错误。最终 APK 保留原签名及 Android 13 窗口监听兼容检查。
