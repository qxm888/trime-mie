# V3.7.9 更新与验证

2026-11-15 经用户授权正式发布，标签 `v3.7.9`，版本码 20271123。包名 `com.osfans.trime.mie`，沿用原签名，正式 APK 面向 arm64-v8a，最低 Android 5.0。

## 更新

- 保留“液态玻璃”，新增独立“液态玻璃·动态”，各包含完整十五页。动态版使用 Android 12+ 公开窗口模糊接口，实时处理背后应用画面，按键和候选保持清晰；键盘与悬浮候选窗统一玻璃风格。
- 动态版不申请屏幕录制或悬浮窗权限，不通过 CPU 连续抓取其他应用画面；系统不支持或关闭窗口模糊时使用自带背景回退。实际效果取决于设备和背后应用绘制的内容。
- 修复自定义主题透明按键显示黑块，保留颜色自身透明度；图片和视频背景磨砂独立于系统模糊，改进透明边缘、预览及动态刷新限帧。
- 新增系统端侧语音入口、能力检测和支持设备上的语言模型状态查询。严格使用 Android 公开端侧接口，不自动回退联网识别；ColorOS 调试手机安装系统模型后仍未开放该接口，尚未接通 OPPO 专属 ASR。

主题入口：键盘样式 → 布局 → 内置布局 → 液态玻璃 / 液态玻璃·动态。

## 验证

透明按键与语音阶段完成 328 项相关测试；静态主题阶段 145 项，最终动态主题阶段 147 项通过。这些是不同阶段的重叠测试范围，不能累加为互不重复的测试数量。

Android 16 / ColorOS 调试手机：透明按键 252 组像素检查、静态主题主要页面和按压反馈、独立应用蓝色/橙色背景动态模糊、实际触屏输入、候选浮窗、单手、悬浮键盘、横竖屏、adjustResize、系统模糊关闭回退及恢复、主题切换、隐藏重开和窗口清理通过。只使用自建测试界面，没有读取真实聊天；测试后恢复原输入法与系统设置并移除测试应用。

跨应用格纹测试同一区域亮度标准差由约 35.91 降至 1.04，背景颜色变化能实时跟随；这是模糊效果证据，不是整机帧率、耗电或所有应用兼容性测量。完整 Debug Lint 有 90 项既有错误，新增错误 0。最终签名包的 API34 专属监听引用检查及 16KB 对齐检查通过；Android13 原机、其他全部系统版本未穷尽验证。

## 附件与复现

Release 提供原签名 APK、完整标签源码、V3.7.8 起增量补丁、验证记录及 SHA-256 校验值。附件不含签名私钥、账户凭据、手机输入法清单或真实聊天。调试测试组件仅在 Debug 源集，正式 APK 不包含测试入口。
