# 透明按键与动态玻璃

2026-11-15。V3.7.9，经用户授权随 `v3.7.9` 正式发布。

## 修复

主题中全透明按键显示黑块的原因是纯色快速绘制路径把 Paint.alpha 直接设为 Drawable 和外观不透明度，覆盖了颜色本身的 alpha。透明黑因此变成不透明黑。现通过乘法保留这三层 alpha，半透明颜色同样修复。

独立按键模糊的工作帧曾被创建为只读 Bitmap，随后写入像素会失败。现在仅发布的帧保持不可变，后台处理使用可写临时帧。按键模糊和底色整体参与不透明度合成，文字、符号与图标仍在其后清晰绘制；玻璃底色叠加强度独立控制着色，不再用不透明底色完全遮住模糊。

原实现把本地背景磨砂绑定到系统背板是否申请成功。现图片与视频磨砂独立运行，系统关闭或不支持跨窗口模糊时仍可使用。新设置可单独关闭“同时模糊背后的应用画面”。系统未开启模糊时不再记录申请成功。

## 使用

自定义键盘的“外观”设置仍按当前布局或整套编辑范围保存。

1. 为键盘选择图片或视频背景；在“整体 → 背景玻璃”开启图片/视频磨砂。只需要本地背景效果时，关闭“同时模糊背后的应用画面”。
2. 按“图片/视频模糊覆盖度”调节清晰与磨砂的混合，“图片/视频不透明度”调节原有背景显示比例。
3. 在“按键 → 背景、边框与模糊”调节独立模糊强度和按键不透明度；“磨砂效果 → 玻璃底色叠加强度”控制底色覆盖程度，调低可以露出模糊后的纹理。
4. 动态图片/视频背景变化时重新生成磨砂帧；刷新上限为5–24帧/秒，默认10，支持旧设置自动升级。静态背景复用缓存，隐藏键盘时不持续抓取。

模糊采用后台三组可分离滑动窗口滤波近似高斯，处理缩略图，共享给按键和工具栏。半透明边缘先预乘 alpha 再滤波，防止不可见颜色渗入边缘；内存缓存与半径无关的线性算法限制动态成本。没有新增模型、SDK、录屏权限或截图其他应用的流程。

## 系统背景与限制

模糊键盘本机图片/视频和模糊背后其他应用属于两个来源。Android 12+ 提供跨窗口模糊，但厂商、系统开关、省电模式及窗口布局都可能限制效果；系统背板区域沿用项目现有实现。软件磨砂路径不因此关闭，也不会伪造为系统背景模糊成功。

[Android 官方窗口模糊说明](https://source.android.com/docs/core/display/window-blurs)。当前验证设备为 Android16 / ColorOS16.1；其他用户反馈设备的同一主题仍建议复测。

## 验证

验证结果见本轮 BuildChecks。真实按键绘制与 Android Drawable 的独立参考合成器比较像素，覆盖透明黑、透明彩色、半透明和不透明颜色、普通/按下状态、Drawable alpha、外观透明度以及模糊开关。后台原生运行验证面板和独立按键帧、动态图像更新、静态不重算、隐藏后恢复和刷新限流。性能数字仅代表合成滤波基准，不代表视频解码、系统合成或所有设备的最终帧率。
