# V3.2.2 源码交接

源码标签 v3.2.2，补丁基于 v3.2.1。正式包 trime-mie-v3.2.2.apk，versionCode 20261227，arm64-v8a，沿用原正式证书。

新增 KeyboardModeBinding / KeyboardModeBindingController：持久返回点、串行切换与过期请求保护，模式切换前捕获原布局，绑定失败尝试恢复，不自动部署。

KeyboardSets 保存整套几何与英文功能继承基线。KeyboardBindingCopy 同步标签显示、符号注解及绑定，保留目标背景配色。KeyAppearance / KeyboardOptions 增加独立 hintAlign / hintAlignment，缺省兼容旧共享对齐。

内置模板版本 14，BuiltinBindingDefaults 仅从资源 mie_builtin_bindings.json 提供绑定及注解数据；无用户源文件路径或自定义功能 UUID 依赖。迁移按旧默认值比较保留用户编辑，七列尺寸在主布局迁移前保留。

KeyView 自定义标点视觉居中并缓存测量。KeyboardSetLayoutsWindow 提供键盘内两列主布局按钮。ThemeSelectionGate 避免编辑器后台刷新抢占主动切换。选项编辑器保存时不再清空英文/横屏关联，旧空英文关联按整套回退。

465 项 JVM 测试通过，真机检查见 docs/本轮键盘验证-20261103.md。ModeBindingsRunner 仅位于 debug 源集，正式 APK 不含测试入口。源码不含测试手机备份、密钥和登录凭据。构建方法见 BUILD.md。
