# V3.2.2 键盘绑定、模式恢复与显示修复

## 更新内容

- 单手键盘、悬浮键盘可分别绑定已启用方案与布局，退出恢复原方案、原布局和中英状态；支持两种模式互切及横屏自动悬浮，不自动部署。
- 整套键盘增加竖屏高度、横屏高度、行间距、行左右边距设置。内置非七列布局默认总高度 260dp、行间距 10dp，七列布局保持自身尺寸。
- 同套英文键盘继承中文 26 键的长按、滑动等功能、弹出备选与发送开关，支持英文页独立覆盖。
- 整套绑定复制纳入主标签、字号、偏移、前景图标及符号/注解显示设置；上方符号和下方注解可分别对齐。
- 按用户提供的雾凇配置统一内置主题八种主要布局的默认绑定、符号与注解。升级按旧默认字段比较，保留用户已修改字段及各套配色、图标。
- 修复编辑符号/绑定后功能键、回车强调色丢失；修复保存对齐设置时清空英文键盘关联，历史空关联按同套英文键盘回退。
- 修复编辑页后台刷新抢占主动布局切换；布局选择恢复键盘内两列主布局按钮，返回保持当前布局。
- 逗号、句号按实际字形视觉居中，保留自定义偏移；刷新菜单切换后的背景、阴影和按压状态。
- 造词管理直接显示“导出造词 · YAML / JSON / TXT”入口，沿用多格式导入导出。

## 使用位置

- 键盘 → 单手与悬浮键盘：分别设置模式绑定。
- 内置/自定义整套 → 整套设置 → 尺寸与间距。
- 布局与切换行为、单键外观：分别设置上方符号与下方注解对齐。
- 输入与候选 → 造词管理：多格式导出。
