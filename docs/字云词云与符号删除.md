## 输入统计

- 原“字词云”拆为两个独立卡片：字云仅展示单个 Unicode 字符的频次，词云仅展示多字上屏词条。
- 沿用现有 wordCounts 统计记录，按完整 Unicode 码点分类，旧数据直接分开显示；不补算旧版没有记录的历史输入，也不引入中文分词服务。
- 两个卡片均随方案及日、周、月、年切换，有独立空态与辅助功能描述。
- 图片分享增加为 8 个可选模块，字云、词云可分别勾选，也可以一起合并成一张图。
- 分享选择使用稳定模块名称保存；旧“字词云”勾选状态迁移给两个模块，其它模块保留原选择，避免插入模块后发生错位。分享偏好纳入整体设置备份。

## 符号、表情删除

适用于内置/自定义键盘使用的符号表情面板，以及传统主题的液态符号面板。

1. 点击面板“删除”，进入删除模式；每项右上显示 ×，点击符号或表情即可从当前分类移除，不会误上屏。
2. 点击“完成”回到正常输入。切换分类、离开面板会退出删除模式。
3. 普通模式长按单项，也可以选择“删除”。原内置面板的 Unicode 信息与输入入口保留，排序模式继续使用长按拖动。
4. 使用“恢复 → 恢复已删除的符号 / 表情”找回当前分类的内容；“恢复默认顺序”只恢复顺序，不撤销删除。

删除按来源和分类独立保存：其它分类中相同字符不会一起删除；传统主题之间互不干扰。同一分类内重复的同一项会一起移除。分类按钮本身仍用于选择和拖动排序，不属于本轮单项删除范围。

实现采用持久排除列表，不改动主题 YAML、内置目录或字典定义；重开面板、重启和更新目录后，已删除内容仍不会自动回来。排除列表放在默认偏好中，随整体备份保存、恢复。新增加但未删除的符号仍正常出现。
