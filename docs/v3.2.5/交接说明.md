## 实用限制

- 真机回归使用独立咩2，未覆盖安装正式版；不宣称做过全机重启、所有厂商/Android 版本或长期输入压力测试。
- 分享已检查一张 PNG 的生成与解码、模块选择界面；没有向外部聊天应用实际发送图片。
- 字词云自升级后积累，旧统计文件没有历史词云；最多保存每周期 512 项、显示 64 项，为有界常用词概览。沿用原统计的中文上屏口径。密码框仅排除新词云采集，不更改已有数字统计口径。
- 候选导出的权重是应用内顺序生成的权重，不能视为 Rime 原生学习词频。完整恢复应使用独立的完整 JSON 备份入口。
- 附带的 14 套主题文件沿用 v3.2.4 已导出的资产版本（本轮保留布局，统一更新了悬浮键盘图标）。外层 ZIP 是合集，先解压，再逐个导入 .mie-keyboard.zip；不是整合集直接导入。14 套合并打包/导入曾有内存不足，本轮未将这一方式视为通过。单套导出的生成已验证，批量导入及完整恢复仍建议维护者另行复测。
- 原生 Rime JNI / Sherpa 为仓库自带预编译依赖；本轮编译独立启动桥，不宣称已从源码重建整个原生引擎。

## 源码使用

方案一：解压 trime-mie-v3.2.5-source.zip，进入 repository/。不含 .git，使用随包构建属性与预编译依赖。

方案二：在 Git 仓库基点 b3f5067 新建分支，先检查补丁再应用：

```sh
git switch -c codex/v3.2.5 b3f5067ceae7fe7a873b9d47ae827417c8033dfa
git apply --check /path/to/v3.2.4-to-v3.2.5.patch
git apply /path/to/v3.2.4-to-v3.2.5.patch
```

不要在有其它未提交工作的目录直接覆盖。若其它会话已新增提交，先比较差异，避免回退别人的修复。

本机 JDK 21、SDK 37、Build Tools 36.0.0，NDK 28.0.13004108，CMake 3.22.1。构建命令：

```sh
JAVA_HOME=/usr/lib/jvm/java-21-openjdk ANDROID_HOME=/opt/android-sdk ANDROID_SDK_ROOT=/opt/android-sdk \
./gradlew --offline --no-daemon --max-workers=2 :app:testDebugUnitTest :app:assembleDebug -PvariantTag=v2 -PbuildABI=arm64-v8a

# 配置合法本地签名后构建正式版；不要带 -PvariantTag=v2
JAVA_HOME=/usr/lib/jvm/java-21-openjdk ANDROID_HOME=/opt/android-sdk ANDROID_SDK_ROOT=/opt/android-sdk \
./gradlew --offline --no-daemon --max-workers=2 :app:assembleRelease -PbuildABI=arm64-v8a
```

其它电脑首次构建需去掉 --offline 并下载依赖。签名配置参阅 BUILD.md；已有签名文件由用户在本机私下提供。无需为发布附件而重新签名已有正式 APK。
