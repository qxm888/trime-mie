# V3.1.11

2026-11-01，版本代码 20261218，arm64-v8a，沿用正式签名。包含此前未在 GitHub 发布的 V3.1.9、V3.1.10。

## 本轮修复

Q 主题数字页通过 __include 继承 default 的 lock: true；应用曾把 .default 统一优先指向最近锁定键盘，进入数字页后这个目标变成 number，因此返回无效。

现在主题模式的 .default 恢复原默认布局选择规则，自定义键盘仍返回最近选择的主键盘。.last_lock 的原含义保留。无需修改 Q 主题文件或背景、字体；现有旧 APK 的临时处理是在 number 下加 lock: false。

## 累积更新

- 五色内置键盘增加七列一、七列二；保留已有布局编辑。
- 内置工具栏悬浮键盘和中英文之间新增同风格表情入口；统一符号面板按分类滑动浏览。41 类、11998 个不重复条目，含 3972 个完整 Unicode Emoji 序列；修复三页截断与组合拆散问题。新字符显示取决于手机字体。
- 字体支持多个文件按顺序补缺字。键盘样式弹窗左上角可切换主题布局 / 自定义布局，名称与字体后台加载。
- 候选栏输入关闭并禁用悬浮球；悬浮窗输入可开关球，隐藏工具栏时自动开启。悬浮键盘临时强制显示工具栏，返回普通键盘恢复偏好。
- 普通主题直接读源文件及依赖；复杂 DSL 仅在内容变化时单独刷新当前主题配置。生成失败保留旧配置；普通切主题与切回输入法不再完整自动部署。

完整部署仍由用户手动执行。本版正式包与源码通过 GitHub Release 发布；调试包只供独立咩2使用。
