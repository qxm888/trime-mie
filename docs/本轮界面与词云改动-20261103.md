# 本轮界面、popup 与字词云改动

此为 V3.2.4 标签之后整理的 V3.2.5 工作区改动。现已完成 529 项单元测试、独立咩2真机功能专项及正式构建；详细检查范围和限制见 [V3.2.5 测试记录](v3.2.5/测试记录.md)。按用户要求只准备交接，不代发布 GitHub。

## 用户可见变化

1. 系统日夜变化时只应用一次自动配色。之后手动选择的配色直接生效，保留到下一次系统变化；暂时覆盖不会改写已配置的日夜配色对，也不退出已启用配色组。普通配置变化不会重复抢回自动皮肤。
2. 底部导航区域作为有背景的底部留白绘制，避免用透明 margin 留出一条未上色区域；独立工具栏背景保留。
3. popup 沿用主题写出的完整备选，不插入原按键动作。命名动作恢复简短标签；字面 emoji/组合字符完整显示与提交。行列命中按实际格子计算，不再将底行中央命中到上一行。主题和自定义均有非零尺寸/字号兜底。
4. 自定义按键编辑新增“长按 popup · 滑选符号与功能”，支持逐行输入、常用符号组和添加绑定动作；列表为空关闭。设置仍随外层按键的保存/取消生效，整套复制及备份沿用原有 popup 字段。
5. 造词数据表为字词/编码；候选数据表为字词/权重；词典草稿为字词/编码/权重。权重按应用内顺序递减，不能冒充 Rime 学习词频。YAML/JSON 以方案及编码分组，TXT 用注释区分上下文，数据行分别为 2/2/3 列。TXT 的特殊控制字符转义。完整备份入口仍保留原格式供恢复。
6. 编辑后的布局名称有独立显示标记，布局选择页优先采用它。保留页面角色用于导航，改名不改变中英/数字页角色；JSON 和 YAML 导出均保留显示名称。

## 字词云

- 输入统计增加字词云卡片，跟随当前方案与日/周/月/年周期。
- 根据上屏中文词条及单字生成；只记录本地频次，不保存整段输入日志，密码框和不允许个性化学习的输入框不记词云。
- 每周期最多保留 512 个字词；长文本的采样工作有上限。容量满时淘汰低频条目，因此是有界常用词概览，不是完整语料词频表。
- 字体大小按频次归一，稳定螺旋布局、实际字形边界避让、不重叠；最多显示 64 个词。布局在内容/尺寸变化时缓存，绘制不反复排版。
- 旧统计没有词云记录，显示空态；从更新后开始积累。新记录进入已有统计备份、Rime 同步及周期清除流程。

## 一张图分享

分享入口改为多选模块：概览、速度、字词云、字词分布、码长分布、键盘热力、生涯。记住上次勾选；至少选一项。选择的模块加标题、周期、方案及日期，输出一张 PNG；仍支持只选热力图或只选词云。

沿用分块 PNG 写入器，避免一次分配整张长图。生成期间显示真实进度状态，防止页面切换导致不同周期混入同一图。保留复制文字报告。

已通过的项目与未覆盖场景详见 [测试记录](v3.2.5/测试记录.md)；交接文件包括正式 APK、完整应用源码快照、从 b3f5067 的二进制补丁、日志/截图与内置主题导入合集。手机原有数据及默认输入法每轮测试后恢复并核对文件哈希。没有向外部应用发送统计图片。
