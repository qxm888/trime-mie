# 风景主题七套（导入包）

七套风景键盘，来自键灵输入法内置布局，转成咩版「导入布局」格式。每套 15 页 / 387 键：26 键中英、9 / 14 / 18 键、数字、符号、表情、七列，逐键玻璃键帽、整幅底图、圆头玻璃工具栏条。

| 主题 | 文件 | 特点 |
| --- | --- | --- |
| 墨金流纹 | `layouts/墨金流纹.yaml` | 黑金流纹、暗色金线 |
| 水墨荷烟 | `layouts/水墨荷烟.yaml` | 水墨留白、淡墨青莲 |
| 月海星澜 | `layouts/月海星澜.yaml` | 深蓝海面、星点微光 |
| 樱溪春影 | `layouts/樱溪春影.yaml` | 樱花溪水、浅粉 |
| 碧池锦鲤 | `layouts/碧池锦鲤.yaml` | 碧水锦鲤、青绿 |
| 春野白驹 | `layouts/春野白驹.yaml` | 草野白驹、暖绿 |
| 赤焰长城 | `layouts/赤焰长城.yaml` | 城墙红旗、赤红 |

## 导入

1. 把本目录的 `rime/.mie` 合并进咩版数据目录（默认 `/sdcard/rime`，改过数据位置则在对应目录）。
   完成后应有 `<rime>/.mie/键盘背景/keyling/crimson-wall/` 这样的目录。
2. 咩版 → 键盘编辑（自定义键盘）→ 菜单 → 导入布局 → 选 `layouts/<主题>.yaml`。
3. 回列表选中新导入的键盘，设为当前布局。一套里的各页（英文、九键、数字、符号）都随根键盘挂在一起。

如果只想用其中一套，可以只复制对应 `rime/.mie/键盘背景/keyling/<slug>/`，但 `keyling/icons/` 是公共图标，需要一起复制。

## 说明

- 素材按相对路径引用，以 `.mie/键盘背景` 为根；单独拷 YAML 而不放素材会显示空键帽。
- 键盘高度 251dp、行高 52dp、行距 8dp、行边距 1dp；26 键为四行，第二行 A–L 按网格宽度九等分（11.11%）。
- 工具栏 8 个按钮（菜单 / 收起 / 剪贴板 / 中英 / 表情 / 单手 / 布局 / 主题）与玻璃条随包还原。
- 导入走 `CustomKeyboardYaml.decode`，七套各 15 页 / 387 键均通过全量校验。
- 再次导入同一主题会覆盖该主题自身，不影响其它布局。

## 来源与许可

布局与素材为键灵输入法内置主题（同作者 qxm888），`layouts/*.yaml` 由键灵的
`custom_scenic_*.yaml` 转换而来：网格字段换成 `width` + `mie.row`、`keyling_metadata`
展开成 `mie:` 段、素材路径改为 `.mie/键盘背景` 相对路径。部分键帽前景图标源自咩版内置图标包。
