Built-in speech in Trime Mie includes code adapted from BiBi Keyboard (说点啥).
Copyright 2025 BryceWG. Licensed under Apache-2.0.
https://github.com/BryceWG/BiBi-Keyboard
Adaptations: provider settings and request protocols, local model catalog and integrity
metadata, sherpa reflection and configuration, download source configuration.
Trime Mie changes: integrated IME lifecycle, isolated sessions and recorder handling,
no external speech service binding. Model data is downloaded separately.
The bundled sherpa-onnx library is provided by https://github.com/k2-fsa/sherpa-onnx
under Apache-2.0. See bibi-upstream-NOTICE.txt for upstream notices.

V3.0.1 Tencent support: model catalog, HMAC-SHA1 WS/flash protocol and response
shape handling adapted from BiBi-Keyboard PR #134 and #135 (Apache-2.0):
https://github.com/BryceWG/BiBi-Keyboard/pull/134
https://github.com/BryceWG/BiBi-Keyboard/pull/135

Mie modifications: PCM-only engine adapter, bounded/paced sending, cancellation,
cumulative partial text by sentence ID, safe diagnostic metadata and backup exclusion.
