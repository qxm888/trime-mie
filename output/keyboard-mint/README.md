# 薄荷五色键盘 v8

五色：薄荷绿 / 樱花粉 / 浅天蓝 / 杏子橙 / 薰衣紫。
每色 **60 个键盘**，合计 **300 个键盘 / 4.1MB**。

## 一、工具栏（7 键，从左到右）

| # | 功能 | 交互 | 图标 |
|---|------|------|------|
| 1 | 功能菜单 | 点击 | `tb_menu.png` 四宫格（primary 槽位） |
| 2 | 主题切换 | 点击 → 主题列表 | `tb_theme.png`（原图 T恤） |
| 3 | 布局切换 | 26 / 9 / 18 / 14 | `tb_layout.png`（原图 列表） |
| 4 | 悬浮键盘 | 点击悬浮 / 长按单手 | `tb_onehand.png`（原图 悬浮） |
| 5 | 中英切换 | 中→英 26 键，英→中 | `tb_lang.png` |
| 6 | 剪贴板 | 点击 | `tb_clipboard.png` |
| 7 | 收起键盘 | 点击 | `tb_hide.png` 箭头 |

**同文工具栏的渲染顺序很反直觉**（源码 `ButtonsBarUi.applyToolbar`）：

```
显示 = [primary] + reverse(buttons.drop(1)) + [buttons[0]]
```

所以 YAML 里第 1 个（primary）在最左，第 2 个会被排到**最右**，第 3 个起从右往左排。
v8 已按这个规则写好，实际显示就是上表从左到右。

## 二、26 键主键盘

- 键高 52、圆角 6、描边 1dp；字母**锁定大写**显示。
- 底行 `14/12/45/12/17`：`123` / `,` / `空格` / `。` / `↵`。
- `123`：单击数字、长按符号。
- 长按：`,`→`？`、`。`→`！`、`m`→`、`、空格→语音。
- **Shift 键右上角有小号「大」**（静态角标；同文自定义键盘的角标不能随 Caps 状态变化，
  要真正「锁定才显示」需要改 App 源码）。

## 三、英文 26 键

- 小写标签，进键盘自动 `ascii_mode`；Shift 一下一个大写、长按 Shift 锁 Caps；标点全英文。

## 四、数字键盘

```
+ 1 2 3 ⌫
- 4 5 6 返回
* 7 8 9 符号
/ . 0 = 回车
```

## 五、符号（带翻页）

- 默认英文符号页：ASCII 全符号 + `⌫`，底行 `返回/英文/中文/数学/更多`。
- 中文 / 数学各一页。
- **更多**：24 个分类（5 列）。
- 每个分类页 **8 列 × 5 行**，超过一页时最后两个格子是 **`‹` `›`**，
  可以一直翻到第 3 页；颜文字 4 列长条。
- 底行：`返回 / 更多 / 空格 / 删除 / 回车`。

## 六、悬浮候选窗美化

每套键盘写入 `mie.floatingCandidates`：

- 面板：白底 + 主题色 1dp 边框 + 10dp 圆角；
- 候选词：主题文字色（同 Shift 键字色）；
- 选中项：**回车同色底 + 白字**，8dp 圆角；
- 页码箭头同文字色。

## 七、安装

1. 图标（已推）：`/storage/emulated/0/rime-mie/.mie/键盘背景/icons/`
   （`tb_menu / tb_theme / tb_layout / tb_onehand / tb_hide` 是 v8 更新）
2. YAML（已推）：`/sdcard/Download/薄荷绿键盘-五色方案.yaml`
3. 咩版 → 设置 → 键盘 → 布局管理与按键编辑 → 右上菜单 → 导入布局
4. 选 **「与现有定制合并」**
5. 点「薄荷绿键盘」设为当前；工具栏第 2 个（T恤）切颜色

## 八、文件

- `gen_kb_yaml_v8.py` —— 生成器（工具栏规则 / 分页 / 候选窗）
- `prep_symbols.py` → `symbols.json` —— 符号分类数据
- `make_icons.py` —— 图标（原图直用 + 自绘四宫格/箭头）
- `data/` —— Rime 符号源

## 九、已知限制

- 主题 / 布局是列表页，不是系统弹窗（同文 YAML 造不出弹窗）。
- Shift 的「大」是静态角标。
- 英文 Shift 只改输入，键面字母仍是小写（自定义键盘标签静态）。
- 分类每类最多 3 页（约 114 个符号）。
