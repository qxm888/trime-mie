# GPT 薄荷绿键盘 —— 五色方案（咩版自定义键盘）

按 GPT 设计稿制作的五色自定义键盘：薄荷绿 / 樱花粉 / 浅天蓝 / 杏子橙 / 薰衣紫。
使用正式版 V3.1 支持的全部功能：按键前景图标、按键底色、圆角、工具栏图标按钮。

## 文件

- `薄荷绿键盘-五色方案.yaml` —— 可导入的键盘定义（5 个键盘：薄荷绿默认 + 4 色）
- `icons/` —— 图标资源（16 个 PNG，透明底）
- `gen_kb_yaml.py` —— 生成脚本（rime 目录不在默认位置时用它重新生成）

## 安装步骤

1. 把 `icons/` 整个文件夹复制到手机的 `rime/.mie/键盘背景/` 下
   （即得到 `rime/.mie/键盘背景/icons/*.png`；其他存储位置把路径换成对应目录）。
2. 把 `薄荷绿键盘-五色方案.yaml` 复制到手机（如 Download）。
3. 咩版 → 设置 → 键盘 → 布局管理与按键编辑 → 右上菜单 → **导入布局** → 选择该 YAML → 合并或覆盖。
4. 布局列表里点选 **薄荷绿键盘** → 设为当前使用。

## 图标对应

| 图标 | 用途 |
|---|---|
| `<色>_shift.png / <色>_delete.png` | 各方案的 Shift / 删除键前景（配色随方案） |
| `enter_w.png` | 回车键前景（白色，用于实色回车键） |
| `tb_switch / tb_symbols / tb_clipboard / tb_lang / tb_float` | 工具栏：切换键盘 / 符号键盘 / 剪贴板 / 中英切换 / 悬浮键盘 |

## 说明

- 键位图标用相对路径（icons/...），换设备无需改动。
- 工具栏图标是绝对路径（默认 /storage/emulated/0/rime/.mie/键盘背景/icons/）。
  若 rime 目录不在默认位置，运行 `python3 gen_kb_yaml.py <你的rime>/.mie/键盘背景/icons` 重新生成。
- 工具栏动作：功能菜单、符号键盘、剪贴板、中英切换（Mode_switch）、悬浮键盘开关
  （__mie_toggle_floating_keyboard），均可在编辑器中修改。
- 五个方案共享布局与键位，仅配色不同；键盘列表中按颜色名切换。
